# Шрифты

U2 использует **Russo One Regular** (заголовки) и **Fira Sans Condensed Regular**
(текст, числа). Подключение — `scripts/ui/zera_style.gd`, правила — `design/UI_STYLE.md`.
Остальные кандидаты не используются; автоматическая проверка среды запретила их удаление (`blocked by policy`).

Все шрифты — SIL Open Font License 1.1 (файл `OFL.txt` в каждой папке), скачаны 2026-10-19 из официального
репозитория Google Fonts (github.com/google/fonts, папка `ofl/`). Разрешены в коммерческой игре; при распространении
OFL.txt должен оставаться рядом. Кандидаты для дизайн-системы U2 — выбирает исполнитель, неиспользованные удалить.

| Папка | Шрифт | Характер |
|---|---|---|
| russo_one | Russo One | тяжёлый техно-военный, крупные заголовки |
| fira_sans_condensed | Fira Sans Condensed (4 веса) | технический узкий текст, цифры |
