# ZERA — мир и фантазия игрока

**Решение автора (17.10.2026):** игрок — **не последний выживший**, а оперативник организации, которая
профессионально зачищает очаги заражения по всей Земле. Это работа: вылазка, задача, эвакуация, рапорт.

## Организация

**Рабочее название:** **Z.E.R.A.** — *Zone Eradication & Response Agency* (Агентство зачистки и реагирования).
Название игры и организации совпадают. (Название рабочее — легко заменить в одном месте: `SETTING.md` + тексты UI.)

- Международная служба с собственными штабами, авиацией и лабораториями. Работает там, где армии уже не справились.
- Отношение к делу — **холодное и профессиональное**, с лёгким цинизмом: очаг — это «объект», орда — «биомасса»,
  оперативники — «единицы». Без пафоса спасения человечества и без длинного сюжета.
- Голос организации — **Диспетчер**: короткие реплики по радио («Объект подтверждён. Работайте.»,
  «Эвакуация через две минуты», «Сигнал улья пропал. Хорошая работа, единица»).

## Как существующие системы ложатся на фантазию

| Система | В мире ZERA |
|---|---|
| База | **Форпост Z.E.R.A.** — штаб группы между операциями |
| Казарма / дерево класса | подготовка оперативника, специализация (Штурмовик — первая) |
| Мастерская | оружейный отдел: доводка стволов за образцы |
| Арсенал | оружейная: какие модели выдать на операцию |
| Склад / ящики | поставки снабжения и трофеи с операций |
| **ДНК** | **образцы мутаций**, сданные в лаборатории организации; на них финансируются исследования и снабжение |
| Забег | **операция**: высадка → зачистка → цель (босс) → эвакуация |
| Торговцы на 5:00 / 9:00 | полевое снабжение: сброс контейнера со склада форпоста |
| Кровавая тревога | всплеск активности биомассы; в конце — сброс снабжения (кровавый контейнер) |
| Смерть | оперативника выводят из строя и эвакуируют; операция провалена, образцы засчитаны (прогресс не теряется) |
| Экран итогов | **рапорт** об операции |
| Глобус кампании | **оперативная карта** организации: очаги, контракты, зоны ответственности |
| Классы будущего | другие специалисты отдела (Пулемётчик, Медик, Подрывник, Инженер…) |

## Тон текстов интерфейса

- Военно-служебный, короткий, по делу: «ОПЕРАЦИЯ», «ОБЪЕКТ», «РАПОРТ», «ЭВАКУАЦИЯ», «ЕДИНИЦА».
- Никаких «вы — последняя надежда». Вместо этого — работа и её цена: «Потери допустимы. Объект — нет.»
- Юмор допустим — сухой, служебный (как запись в журнале), не мемный.

## Что не меняется

Ядро и столпы (`CONCEPT_FULL.md` §2.2): драйв, gore, погружение, модульный билдкрафт. Организация — рамка, а не сюжет:
никаких обязательных кат-сцен и диалогов.
