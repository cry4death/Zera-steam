# GameZ — MVP (первый играбельный прототип)

> Цель MVP: проверить две гипотезы.
> 1. **Весело ли 10 минут крошить орду, когда каждое убийство взрывается кровью?**
> 2. **Цепляет ли сборка оружия из модулей сильнее обычного «+10% урона»?**
>
> Если да, всё остальное — контент поверх. Если нет, чиним ядро, а не добавляем фичи.
>
> Все цифры — в [BALANCE.md](BALANCE.md).

## 2. Игрок — Штурмовик

- Старт: 100 HP, **Автомат + Стандартные патроны**, без модулей.
- **Движение:** WASD / стик.
- **Рывок:** ~0.15 с, i-frames, кулдаун 2 с.
- **Тактическая перезарядка (R):** все неполные магазины сразу уходят на перезарядку.
- **Активка — граната:** кидается в направлении движения, кулдаун ~8 с, всегда рвёт на гибы.

## 3. Модульное оружие (MVP-набор)

```
ОРУЖИЕ = ОСНОВА + ПАТРОНЫ + МОДУЛИ
```
Максимум 4 оружия. Уровни основы 1–5; слоты модулей: ур.1 — 1, ур.3 — 2, ур.5 — 3.

### Категории и модели (4 категории × 2 модели)
У каждого ствола свой **магазин и перезарядка** (из SAS3).

| Категория | Паттерн | Серийная модель | Модель из ящика |
|---|---|---|---|
| Автомат | очереди в ближайшего | АК-С (универсал) | «Оса» — ПП, магазин 50 |
| Дробовик | веер в конус | «Мясник» (помповый) | «Шквал» — автоматический |
| Рейлган | луч насквозь | «Игла» | «Копьё» *(редкая)*: убийство усиливает следующий выстрел |
| Гранатомёт | снаряд с взрывом по площади | «Гром» | «Улей» *(редкая)*: гранаты прилипают |

Перед забегом в Арсенале выбираешь избранную модель каждой категории.

### Патроны (4) — каждый даёт свой тип смерти
| Патроны | Эффект | Смерть |
|---|---|---|
| Стандартные | +шанс крита | труп; крит: **голова лопается** |
| Экспансивные | урон по площади | **разрыв на гибы** |
| Зажигательные | поджог, огонь перекидывается | **обугливание** |
| Крио | замедление → заморозка | **ледяная статуя раскалывается** |

### Модули (6)
| Модуль | Эффект |
|---|---|
| Рикошет | отскок к следующей цели |
| Пробивание | проходит через 3 врагов |
| Сплит | при попадании делится на 3 осколка |
| Детонатор | убитые этим оружием взрываются |
| Сдвоенный ствол | +1 снаряд за выстрел |
| Цепь | убийство выпускает снаряд в соседа |

### Прототипы (2) — проверка механики
| Прототип | Рецепт (основа ур.5) |
|---|---|
| **Мясорубка** | Дробовик + Экспансивные + Детонатор |
| **Абсолютный ноль** | Рейлган + Крио + Пробивание |

### Стакинг и редкость
- **Стакинг:** тот же модуль или патроны на том же оружии повышают ранг I → II → III
  без нового слота. Ранг III даёт качественный бонус (проверяем хотя бы на Рикошете и Детонаторе).
- **Редкость в MVP — 2 уровня:** обычная (белая) и редкая (синяя, эффект +50%).
  Редкие выпадают из элиток и кровавого контейнера, продаются у торговца.
  При стакинге редкость берётся старшая.
- Экспериментальные детали — после MVP.

### Как детали попадают к игроку
- **Level Up:** 3 карты на выбор из пула: основа / патроны / модуль / +уровень основы / пассивка.
- **Модуль или патроны:** после выбора карты указываешь, на какое оружие их поставить.
- **Торговец:** покупка деталей + одна бесплатная перестановка модуля.

## 4. Пассивки (6)

| Пассивка | Эффект |
|---|---|
| Боевые стимуляторы | +урон % |
| Облегчённый затвор | +скорострельность % |
| Экзоскелет | +скорость движения |
| Бронежилет | +макс. HP |
| Сборщик образцов | +радиус подбора опыта |
| Быстрые руки | −время перезарядки |

## 5. Враги

| Враг | Поведение |
|---|---|
| **Шаркающий** | медленно идёт на игрока, огромные толпы |
| **Бегун** | быстрый, появляется пачками |
| **Толстяк** | медленный, много HP, **взрывается при смерти** (урон всем вокруг, зомби тоже) |
| **Плевальщик** | держит дистанцию, плюёт кислотой (лужа с уроном) |

**Элитка:** любой тип ×1.5 размер, ×5 HP, аура, гарантированный дроп кредитов, хит-стоп при убийстве,
10% шанс оружейного ящика.

## 6. Босс — «Объект-7»

Мутант-таран из лаборатории, появляется на 10-й минуте. Обычная орда продолжает идти (слабее).

**Фаза 1 (100–50% HP), в броне:**
- **Таран:** телеграф (красная линия) → рывок через экран, давит зомби на пути в кашу.
- **Удар по земле:** круговая волна, уходишь рывком.
- **Рёв:** призывает пачку бегунов.

**Фаза 2 (50–0% HP), броня сорвана:**
- Пластины брони отваливаются, обнажается мясо, из ран хлещет кровь.
- Быстрее, тараны идут сериями по 2–3.
- **Смерть:** огромный взрыв плоти, гибы на весь экран, кровь заливает пол-арены.

## 7. Gore — что входит в MVP

**Ядро:**
- [x] Брызги крови при попадании, направленные по вектору пули
- [x] **Постоянная кровь на полу** (запекание в текстуру)
- [x] Трупы и гибы после оседания запекаются в пол
- [x] **5 типов смерти:** обычная / голова лопается / гибы / обугливание / ледяной раскол
- [x] Гибы с простой физикой (разлёт, отскок, кровавый след)
- [x] **Раны на живых:** 2 состояния спрайта (целый → ранен на 50% HP) с отлетающим куском
- [x] Hit flash

**Драйв-полировка:**
- [x] Тряска экрана, хит-стоп, дульные вспышки, гильзы
- [x] Счётчик убийств

**Погружение:**
- [x] Ночь: затемнение + свет вокруг игрока + вспышки выстрелов и взрывов как источники света
- [x] Позиционные звуки орды (placeholder)

**Не в MVP:** электро/кислота, 3-е состояние ран, брызги на экран, следы игрока, динамическая музыка.

## 8. Кровавая тревога (MVP-версия)

Одна гарантированная тревога на **~7:00**.
- 3 с предупреждения (сирена, красный текст) → 30 с: красный свет, спавн ×3, опыт и кредиты ×2.
- Финал: **кровавый контейнер** с выбором 1 из 3 модулей + обычный оружейный ящик.

## 9. Структура забега (10 мин)

| Время | Событие |
|---|---|
| 0:00–2:00 | Только шаркающие, разгон |
| 2:00 | + бегуны |
| 3:30 | + толстяки |
| 5:00 | **Торговец** (дроп снабжения на 30 с) + плевальщики + первые элитки |
| ~7:00 | **Кровавая тревога** |
| 7:30–9:00 | Пик плотности |
| 9:00 | Затишье + **Торговец 2** (цены ×1.5, закупка перед боссом) |
| 9:30 | Предупреждение о боссе |
| 10:00 | **Объект-7** |

- **Опыт:** образцы падают с трупов → Level Up → выбор 1 из 3.
- **Кредиты:** падают с врагов, тратятся у двух торговцев (5:00 и 9:00).
- **Финал:** экран итогов (время, убийства, «литры крови», собранные стволы) → ДНК → база.

## 10. Мета-прогрессия (минимум)

Экран базы из трёх разделов:

- **Казарма:** дерево Штурмовика (3 ветки × 3 узла: Огневая мощь / Магазин / Выживание,
  см. [GDD.md](GDD.md) §12.1). Уровень класса растёт от заработанной ДНК, очко за уровень.
- **Мастерская:** прокачка 8 моделей (урон / скорострельность / магазин / перезарядка × 5 уровней) за ДНК.
- **Склад ящиков:** вскрытие ящиков из забега (обычный / военный с босса) с анимацией редкости.

**ДНК по прогрессу, смерть не наказывает:**
`минуты × 10 + убийства / 50 + элитки × 5`, победа над боссом ×1.5.
На экране итогов это выводится построчно, как чек.

## 11. Локация — «Карантинная зона»

- Ограниченная карта ~4×4 экрана.
- Препятствия: военная техника, бетонные блоки, ящики. Они образуют коридоры,
  где зомби скапливаются (идеально для дробовика, рейлгана и гранатомёта).
- Тайлсет: асфальт + бетон, на них кровь читается лучше всего.

## 12. Технические цели

- **60 FPS при 500 врагах на экране.**
- Враги — лёгкие объекты: пул + spatial hash + рендер батчами (не `CharacterBody2D`).
- Кровь, трупы и гибы запекаются в текстуру пола чанками.
- **Модули — композиция поведений снаряда** (`on_hit` / `on_kill` / `on_update`).
  Архитектуру закладываем сразу, чтобы новые модули добавлялись без переделок.
- Разрешение 640×360, целочисленное масштабирование.
- Арт: placeholder / готовые пиксель-ассеты, кастом только для гибов, ран и крови.

## 13. Этапы разработки

| # | Этап | Результат | Проверка |
|---|---|---|---|
| **M1** ✅ | Ядро орды | Игрок, рывок, автомат **с магазином и перезарядкой**, шаркающие, спавн | 500 врагов при 60 FPS |
| **M2** ✅ | Gore-ядро | Брызги, запекание крови и трупов, гибы, раны, hit flash, тряска | «Приятно ли просто убивать?» |
| **M2.5** ✅ | Gore v2 | Новые спрайты, приглушённая кровь, 4 стадии ран, распил, обезглавливание, следы, брызги на экран, комбо (GDD §6.5) | Кровь не мешает видеть зомби, а смотреть на неё приятно |
| **M3** ✅ | Модульное оружие | 4 серийные модели, 4 патрона, 6 модулей, 6 пассивок, Level Up с установкой на ствол | Билды реально разные |
| **M4** | Враги и экономика | 4 типа + элитки, кредиты, 2 торговца, граната, тревога | 10 минут не скучно |
| **M5** | Босс и финал | Объект-7, 2 фазы, экран итогов | Бой с боссом — кульминация |
| **M6** | Мета | Дерево класса, мастерская, ящики + 4 модели из них, прототипы | Хочется сыграть снова |
| **M7** | Атмосфера | Ночь и свет, звук орды и перезарядок, полировка | Погружение |

**Правило:** gore (M2) идёт сразу после ядра. Модули (M3) идут сразу после gore,
потому что патроны завязаны на типы смерти.

## 14. Критерии успеха MVP (плейтест)

1. Через 30 секунд игрок улыбается от убийств.
2. К 5-й минуте появляется ощущение «я становлюсь машиной смерти».
3. Игрок осознанно думает, **на какой ствол поставить модуль**.
4. Каждый тип патронов узнаётся по тому, как умирают зомби.
5. Найдя прототип, игрок хочет найти остальные.
6. После смерти или победы игрок сам нажимает «ещё раз».
