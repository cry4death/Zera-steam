# GameZ — концепт (рабочий документ)

> Статус: абстрактная проработка. Документ живой, дополняется по мере ответов.
> Объём первого прототипа описан в [MVP.md](MVP.md).

## 1. Питч

Пиксельный top-down roguelite в духе Vampire Survivors, только намного мяснее.
Игрок выживает на открытой локации, а со всех сторон на него стекаются орды зомби.
Оружие стреляет само, а игрок **собирает его из модулей прямо в бою**: основа,
патроны и модификаторы. Каждое сочетание по-своему рвёт, жжёт и морозит толпу.
К концу забега вся карта залита кровью.

**Без сюжета. Чистое мочилово.**

**Вдохновение:** Vampire Survivors (автострельба, билд за забег, орды) +
**SAS: Zombie Assault 3** (магазины и перезарядка, классы с навыками,
коллекция стволов и их прокачка).

## 2. Столпы

1. **Драйв.** Сотни врагов на экране, нарастающий темп, ощущение всемогущества к концу забега.
2. **Gore.** Кровь и расчленение служат главной наградой за каждое убийство, а не фоном.
3. **Погружение.** Темнота, свет, звук орды, ощущение, что тебя давят со всех сторон.
4. **Модульный билдкрафт.** Каждое оружие собирается из деталей, каждый забег даёт уникальный арсенал.

Любая фича проверяется вопросом: усиливает ли она хотя бы один столп?

## 3. Принятые решения

| Вопрос | Решение |

| Стрельба | Автострельба |
| Действия игрока | Движение + рывок (дэш) + 1 активная способность |
| Графика | Пиксель-арт, 2D |
| Платформа / движок | ПК, Godot 4 |
| Магазин | Двойной: торговец в забеге + база с мета-прогрессией |
| Сеттинг | Милитари sci-fi: только антураж, **без сюжета** |
| Длительность забега | 15–20 минут |
| **Уникальная фишка** | **Модульное оружие** (см. §5) |

## 4. Основной цикл

```
Старт забега → орда → убийства → опыт падает с трупов → Level Up
   → выбор 1 из 3: оружие / патроны / модуль / пассивка
   → собираешь стволы → орда сильнее → тревога / мини-боссы / торговец
   → финальный босс → эвакуация → ДНК → база → новый забег
```

## 5. ⭐ Модульное оружие (главная фишка)

### 5.1 Формула

```
ОРУЖИЕ = ОСНОВА + ПАТРОНЫ + МОДУЛИ (1–3)
         как стреляет   как убивает   что делает снаряд
```

- **Основа** задаёт паттерн стрельбы.
- **Патроны** задают тип урона и **тип смерти** (это прямая связь с gore-системой).
- **Модули** меняют поведение снарядов.

Игрок носит до **4 оружий**. Каждое настраивается отдельно, поэтому в одном забеге
можно собрать «ледяной рикошетящий дробовик» и «цепной электро-рейлган».

### 5.2 Основы (как стреляет)

| Основа | Паттерн | Сильна против |
|---|---|---|
| Автомат | Быстрые очереди в ближайшего | одиночных, универсал |
| Дробовик | Веер дроби в конус | толпы вплотную |
| Рейлган | Медленный луч насквозь по линии | колонн, бронированных |
| Гранатомёт | Навесной снаряд, взрыв | скоплений |
| Огнемёт | Непрерывная струя на короткой дистанции | окружения |
| Пусковая дронов | Дроны кружат и атакуют сами | тыла, флангов |
| Турель-пак | Ставит турели, которые стреляют сами | удержания позиции |
| Дисковая пила | Пилы-бумеранги, летят и возвращаются | линий врагов |

### 5.3 Патроны (как убивает) → тип смерти

У каждого оружия **1 слот патронов**. Новые патроны заменяют старые.

| Патроны | Эффект | Как умирает зомби |
|---|---|---|
| Стандартные | чистый урон, повышенный шанс крита | труп + лужа; крит: **голова лопается** |
| Экспансивные | +урон по площади при попадании | **разрыв на гибы** |
| Зажигательные | поджог (DoT), горящие трупы поджигают соседей | **обугливание**, рассыпается в пепел |
| Крио | замедление → заморозка | **ледяная статуя, раскалывается** на красные ледяные куски |
| Электро | урон перескакивает на соседей | **вспышка скелета**, дымящийся труп |
| Кислотные | снижают броню, оставляют лужу | **плавится** в лужу мяса |

### 5.4 Модули (что делает снаряд)

Количество слотов модулей растёт с уровнем оружия: ур.1 — 1 слот, ур.3 — 2, ур.5 — 3.

| Модуль | Эффект |
|---|---|
| Рикошет | снаряд отскакивает к следующей цели |
| Пробивание | проходит через N врагов |
| Сплит | при попадании делится на 3 осколка |
| Самонаведение | снаряды доворачивают к цели |
| Цепь | каждое убийство выпускает снаряд в соседа |
| Детонатор | убитые этим оружием взрываются |
| Сдвоенный ствол | +1 снаряд за выстрел |
| Перегрев | скорострельность растёт при непрерывной стрельбе |
| Оглушение | шанс сбить врага с ног |
| Вампиризм | шанс вылечить игрока при убийстве |

### 5.5 Прототипы (вместо эволюций)

Определённые сочетания на оружии ур.5 открывают **Прототип**: уникальный ствол
с новым спрайтом, звуком и эффектом. Игрок их не знает заранее, а найденные
заносятся в «Архив прототипов» на базе (стимул экспериментировать).

| Прототип | Рецепт | Эффект |
|---|---|---|
| **Мясорубка** | Дробовик + Экспансивные + Детонатор | каждая дробинка взрывается, цепная мясная реакция |
| **Драконье дыхание** | Огнемёт + Зажигательные + Сплит | струя разливается огненными реками |
| **Абсолютный ноль** | Рейлган + Крио + Пробивание | замораживает всю линию, через секунду она раскалывается |
| **Грозовой рой** | Пусковая дронов + Электро + Цепь | дроны связаны электрической сетью |
| **Кислотный дождь** | Гранатомёт + Кислотные + Сплит | кассетные кислотные бомбы |
| **Жнец** | Дисковая пила + Стандартные + Рикошет | пилы летают по экрану, срезая головы |

### 5.6 Откуда берутся детали

- **Level Up:** 3 карты на выбор, взвешенно: новая основа (если есть слот) /
  патроны / модуль / +уровень основы / пассивка.
- **Торговец:** продаёт детали за кредиты, позволяет **снять и переставить** модуль
  или продать ненужную деталь.
- **Кровавая тревога:** награда — гарантированный редкий модуль.
- **База (мета):** открывает новые детали в общий пул (в начале пул маленький).

Установка модуля — двухшаговый выбор: взял модуль → выбрал, на какое оружие его поставить.
Подсказка показывает, «тёплый» ли рецепт прототипа.

### 5.7 Стакинг: дубль = усиление

- Одинаковый модуль на том же оружии **не занимает новый слот**, а повышает ранг
  уже стоящего: **I → II → III** (максимум).
- Пример: Рикошет I — 1 отскок, II — 2 отскока, III — 3 отскока + отскок ищет
  ближайшую *непоражённую* цель.
- **Ранг III даёт качественный бонус**, а не только цифры, чтобы ради него хотелось стакать.
- Патроны стакаются так же: Зажигательные II — дольше горение, III — огонь перекидывается вдвое дальше.
- В карте Level Up дубль помечен значком «↑II» и подсветкой оружия, на котором он стоит.
- Можно поставить тот же модуль на **другое** оружие, тогда это новый модуль ранга I.
- Для рецепта прототипа ранг не важен, нужен только сам модуль.

### 5.8 Редкость деталей

Редкость есть у **патронов и модулей**. Основы не имеют редкости, они растут уровнями 1–5.

| Редкость | Цвет | Что даёт |
|---|---|---|
| **Обычная** | белый | базовый эффект |
| **Редкая** | синий | эффект +50% или +1 к ключевому параметру |
| **Экспериментальная** | ядовито-зелёный | мощный и необычный эффект, часто **с минусом**; **не стакается**, уникальна на оружие |

**Правило слияния:** при стакинге ранг растёт на 1, а редкость берётся старшая из двух.

**Примеры экспериментальных деталей:**

| Деталь | Плюс | Минус |
|---|---|---|
| Нестабильный детонатор | радиус взрывов ×2, взрывы поджигают | 5% шанс, что взрыв заденет и игрока |
| Сплит-Х | делится на 6 осколков | урон осколков −40% |
| Кровавые патроны | урон ×2, вампиризм при убийстве | каждый выстрел стоит HP |
| Сингулярность | убитые затягивают соседей в точку смерти | скорострельность −30% |
| Патроны «Ноль» | мгновенная заморозка | дальность −50% |

**Откуда берётся редкость:**

| Источник | Обычная | Редкая | Экспериментальная |
|---|---|---|---|
| Level Up | основное | шанс растёт со временем забега | очень редко |
| Элитки | — | дроп-шанс | — |
| Кровавая тревога | — | гарантированно | шанс при высоком числе убийств |
| Мини-боссы / боссы | — | — | гарантированно (выбор 1 из 3) |
| Торговец | дёшево | дорого | очень дорого, 1 слот в ассортименте |

### 5.9 Магазины и перезарядка (из SAS3)

- У каждого ствола свой **магазин** и **время перезарядки**. Опустел — ствол сам уходит
  на перезарядку, а остальные продолжают стрелять.
- **Тактическая перезарядка (R):** все неполные магазины сразу уходят на перезарядку.
  Это единственное «ручное» действие с оружием: перезарядиться в затишье перед волной.
- HUD: иконки стволов внизу экрана, под каждой полоска патронов и кольцо перезарядки.
- Ритм: дробовик и гранатомёт стреляют рывками, автомат почти непрерывно.
  Самый страшный момент — когда **все стволы перезаряжаются одновременно**.
- Звук: щелчки магазинов, лязг затвора, гильзы. Это важная часть ощущения «я воюю».
- Влияют на перезарядку: пассивка «Быстрые руки», ветка «Магазин» в дереве класса,
  стат «Перезарядка» в мастерской.

### 5.10 Модели стволов (коллекция, как в SAS3)

- Основа — это **категория** (Автомат, Дробовик...). Внутри категории есть **модели**
  с разным характером: «АК-С» — универсал, «Оса» — ПП с огромным магазином, и т.д.
- Серийная модель каждой категории доступна с начала. Остальные выпадают из
  **оружейных ящиков** и навсегда попадают в Арсенал.
- Перед забегом в каждой категории выбираешь **избранную модель**: именно её
  предлагает Level Up.
- Модели имеют редкость. Редкая или экспериментальная модель отличается **чертой**
  («гранаты прилипают к врагам»), а не только цифрами.
- Модели прокачиваются **в мастерской** на базе (урон, скорострельность, магазин,
  перезарядка). Это долгосрочная цель: любимый ствол становится сильнее от забега к забегу.

### 5.11 Расширенный арсенал

16 категорий, 48 моделей, по три модели на категорию. К прежним основам добавлены:
ленточный пулемёт (упор и раскрутка), миниган (долгая раскрутка и потеря подвижности),
огнемёт (короткий конус и передача огня между живыми носителями), цепная пила
(сектор в упор и рассечение), арбалет (медленный пробивающий болт и пригвождение тела),
самозарядный дробовик (непрерывная дробь без помпы), марксманская винтовка
(точный огонь с короткими интервалами) и разрядник (переброс между живыми целями).

У старых типов добавлена третья модель, у новых — серийная, обычная и редкая.
Различия — двойки, тяжёлый одиночный снаряд, контрольный патрон, трассеры, подхват
патрона после убийства, разрывной болт, форма струи и схема электрической цепи.
Пулемётчик быстрее раскручивает роторы; Инженер проводит разряд через дополнительную цель.
Несовместимые детали не предлагаются для установки, торговец не переносит их на такой
ствол. Числа и ограничения — BALANCE §3.5. Схема сохранения и четыре боевых слота сохранены.

## 6. Gore-система

### 6.1 Раны на живых (визуальные)
- У каждого типа зомби **3 состояния спрайта**: целый → ранен (оторвана рука, видны рёбра)
  → изувечен (полчерепа, кишки наружу).
- Переход при порогах HP (66% / 33%), с отлетающим куском и брызгами.
- На поведение не влияет. Это дёшево и масштабируется на тысячи врагов.

### 6.2 Смерть
Тип смерти задают **патроны** (§5.3). Плюс общие правила:
- взрывы (гранаты, толстяки, детонатор) всегда рвут на гибы;
- оверкилл (урон > 200% остатка HP) повышает «тяжесть» смерти.

### 6.3 Мир
- **Постоянная кровь на полу:** декали запекаются в текстуру земли, карта постепенно краснеет.
- Трупы и гибы после оседания тоже запекаются.
- Гибы оставляют кровавые следы при разлёте.
- Брызги на экран при близком взрыве.
- Следы игрока по лужам крови.

### 6.4 Gore v2 (решения после M2)

**Читаемость важнее количества.** Кровь не должна перекрывать зомби: пол темнеет и
краснеет приглушённо (тёмно-бордовый, полупрозрачный, с вариацией), а зомби остаются
контрастными (обводка, светлее пола).

**Арт:**
- Реалистичнее спрайты зомби и игрока: больше деталей, затенение, несколько вариантов
  зомби (одежда, телосложение, цвет кожи).
- Больше кишок и вариантов гибов: кишки-ленты, позвоночник, рёбра, куски разных размеров.
- Реалистичнее кровь: пятна с неровными краями и подтёками, тёмный центр и светлые
  брызги, свежая кровь блестит, а со временем темнеет.

**Новые смерти:**
- **Распил пополам** (пилы, лезвия, рейлган): верхняя половина ещё 1–2 с ползёт
  к игроку, тянет кишки и оставляет кровавую полосу.

**Мир:**
- **Кровь на препятствиях:** брызги на машинах, бетоне и стенах; гибы шлёпаются о стену
  с размазом и сползают.
- **Горы трупов:** последние N трупов лежат «живыми» физическими объектами: их
  расталкивают, взрывы рвут повторно, они складываются в кучи. Старые запекаются.
- **Кровавые следы:** игрок и зомби оставляют следы, пройдя по луже; раненые зомби капают на ходу.
- **Мухи и пар:** мухи над старыми кучами мяса, пар от свежих луж в холодной ночи.

**Экран:**
- **Брызги на экран** от близких взрывов и толстяков, стекают вниз.
- **Комбо-надписи** за серии убийств («МЯСОРУБКА!», «КРОВАВАЯ БАНЯ!»).
- **Игрок пачкается:** спрайт бойца за забег становится всё кровавее (несколько стадий).

**Механики на gore:** пока нет, gore остаётся чистой наградой для глаз.

**Раны на живых:**
- **4 стадии:** целый → ранен (кровь, дыры) → изувечен (нет руки, рёбра) →
  еле жив (полчерепа, кишки наружу, шатается).
- **Рана там, куда попали:** сторона попадания определяет, что отлетает (левая/правая
  рука, голова, грудь). У каждого зомби свой набор повреждений.
- **Кишки волочатся** у изувеченных и оставляют след.
- **Решето:** дробь и очереди оставляют накапливающиеся дыры, клочья одежды отлетают.

**Ещё смерти:**
- **Обезглавливание:** голова отлетает и катится, тело делает 2–3 шага с фонтаном из шеи и падает.
- **Раздавливание:** таран босса или тяжёлый враг — плоская лепёшка с брызгами вдоль пути.
- **Размазать о стену:** отброшенного взрывом зомби впечатывает в препятствие,
  остаётся клякса и сползающее тело.

**Время:**
- **Кровь сохнет:** свежая алая и блестит, за минуту темнеет до бурой. По карте читается история боя.
- **Лужи растекаются** под трупами первые секунды, соседние сливаются.
- **Трупы дёргаются** пару секунд перед тем, как затихнуть.
- **Покраснение карты:** чем больше залито кровью, тем багровее общий тон сцены.

**Разные враги:**
- **Разная кровь:** заражённые — тёмно-красная, мутанты/плевальщики — жёлто-зелёная,
  экспериментальные — чёрная.
- **Броня колется:** пластины, каски, подсумки отлетают с попаданиями, под ними мясо.
- **Лут из тел:** жетоны, телефоны, патроны, бейджи (визуально; можно связать с кредитами).
- **Разная анатомия:** у толстяка жир и жёлчь, у бегуна жилы и тонкие кости, у мутанта
  щупальца и наросты. У каждого типа свои гибы.

### 6.5 Порядок внедрения gore

## 7. Драйв и «сочность» (juice)

- Hit-stop на критах и убийствах элиток.
- Тряска экрана, дульные вспышки, гильзы.
- Счётчик убийств и комбо-множитель.
- Многослойная музыка: интенсивность растёт с плотностью орды.
- Цепные реакции (толстяки, детонатор, Мясорубка).

## 8. Погружение

**Решения (после M2):**

- **Свет:** без тёмной ночи, сцена светлая и всё читается (сумерки). Атмосфера идёт
  от цвета и деталей. Выстрелы, взрывы и огонь дают **вспышки света** поверх.
- **Живой мир:** много препятствий и мусора: машины (легковушки, военные грузовики,
  БТР), бетонные блоки, баррикады, бочки, ящики, мешки с песком, заборы, палатки,
  брошенное снаряжение. Препятствия формируют коридоры и пачкаются кровью.
- **Звук:**
  - орда слышна заранее: позиционные стоны и топот, гул растёт с числом зомби;
  - сочный gore-звук: хлюпы, хруст, шлепки гибов, шипение огня, звон льда, свой звук у каждой смерти;
  - тёмный эмбиент вместо музыки: гул, ветер, далёкие сирены и выстрелы.
    Музыка звучит только в кровавую тревогу и на боссе.
- **Угроза при низком HP:** красная виньетка по краям, сердцебиение, приглушённый звук, тяжёлое дыхание.
- **Погода:** пока нет.

## 9. Событие: «Кровавая тревога»

1–2 раза за забег в случайный момент (не раньше 4-й минуты и не во время босса).

1. **Предупреждение (3 с):** вой сирены, мигающий красный текст «⚠ КРОВАВАЯ ТРЕВОГА».
2. **Тревога (30 с):**
   - освещение становится красным, музыка переключается на агрессивный трек;
   - спавн ×3, больше элиток;
   - опыт и кредиты ×2;
   - счётчик убийств тревоги на экране.
3. **Финал:** в центре экрана падает **кровавый контейнер** с редким модулем
   (качество зависит от числа убийств за тревогу).

## 12. Классы

Три класса выбираются вкладками казармы перед вылазкой. Арсенал и мастерская общие. Уровень от накопленной `dna_earned` общий; каждый класс хранит собственную раскладку с тем же бюджетом `level − 1`. Очки нельзя переносить между деревьями ради усиления одного бойца. Смена класса не обнуляет прежний прогресс.

| Класс | Старт из общего арсенала | Пассивное правило | Q | Кластеры |
|---|---|---|---|---|
| Штурмовик | АК-С / избранный автомат | Попадание до 70 px сокращает КД рывка на 0,25 с, не чаще 1/с | Граната: 40 урона, радиус 50, КД 8 с | Штурм / Манёвр / Подрыв |
| Пулемётчик | ПП / избранная модель | За 1,25 с стоя набирает стабильность: до +8% урона и +35% отброса; движение плавно снимает бонус | Бастион: 3 с, фронтальные попадания наносят 25% урона, КД 18 с; можно двигаться | Рубеж / Бастион / Подавление |

### 12.1 Деревья и сохранения

Каждое дерево — 72 узла в трёх кластерах, небольшие кольца, перекрёстки и мосты. Доступ открывает любой взятый сосед; шесть входов связаны с центром. Взаимоисключающие пары запрещены независимо от маршрута. Ключевые узлы крупнее опор. У Штурмовика сохранены 48 узлов и 12 пар T1, добавлены 24 опоры; у специалистов по 24 общих опоры и 48 классовых узлов. Полный допустимый билд: Штурмовик 60 узлов / 84 очка, специалисты 66 узлов / 72 очка. «Полный» не включает обе стороны пар.

Колесо и LT/RT меняют масштаб, средняя кнопка и правый стик двигают поле; стрелки/D-pad следуют геометрии, E/A покупает с подтверждением, C/Y меняет класс, R/X сбрасывает бесплатно. Выбранный узел показывает название, численный эффект и цену внизу. Полоса опыта — внизу поля. Нейтральные замкнутые контуры, предметные пиксельные иконки; пути взятого билда выделены приглушённым цветом кластера.

Профиль v7 хранит `class_id`, `class_trees`, совместимое зеркало активного `tree`. v1–v6 становятся Штурмовиком: прежние id и стоимость сохранены, прежние связи добавлены к новой сети, чтобы ранее легальные покупки не стали сиротами. ДНК, накопленная ДНК, мастерская, модели, избранное, ящики, настройки и кампания сохраняются. Сброс возвращает стоимость только текущему дереву; уровень и общий банк не меняются. Подробнее: [UPGRADE_TREE.md](UPGRADE_TREE.md), числа: [BALANCE.md](BALANCE.md) §11.2.

## 13. Мета-прогрессия (база)

Валюта — **ДНК**.

### 13.1 Начисление ДНК (смерть не наказывает)

ДНК начисляется **по прогрессу** и сохраняется всегда, даже при смерти на первой минуте.
Даже плохой забег двигает вперёд, а это главный двигатель «ещё одного раза».

```
ДНК = минуты выживания × 10
    + убийства / 50
    + элитки × 5
    + мини-боссы × 25
    + новые открытия (первый прототип, первая экспериментальная деталь) × 20
→ победа над боссом: ×1.5
→ уровень угрозы: ×(1 + 0.15 × угроза)
```

Цифры — стартовые ориентиры для баланса. На экране итогов ДНК
показывается построчно, как чек, чтобы игрок видел, за что получил награду.

### 13.2 Разделы базы


- **Арсенал:** коллекция моделей стволов, выбор избранной модели в каждой категории;
  открытие новых патронов и модулей в пул.
- **Мастерская:** прокачка моделей за ДНК (урон, скорострельность, магазин, перезарядка).
- **Склад ящиков:** вскрытие оружейных ящиков, принесённых из забега.
- **Казарма:** классы, их деревья навыков, открытие новых классов.
- **Архив прототипов:** коллекция найденных рецептов.
- **Карта операций:** новые сектора и уровни угрозы.

## 14. Техническая заметка (Godot)

- Базовое разрешение 640×360 с целочисленным масштабированием.
- Сотни и тысячи врагов: никаких `CharacterBody2D` на каждого. Нужны пул объектов,
  своя сепарация через spatial hash и рендер батчами (MultiMesh).
- Кровь, трупы и гибы запекаются в текстуру пола (SubViewport без очистки, чанками).
- Модули реализуются как композиция: снаряд получает список «поведений»
  (on_hit, on_kill, on_update), и модули добавляют туда свои обработчики.

## 16. Бесконечная бойня

Отдельный режим с базы: кнопка под операциями, H / X. Игрок выбирает одну из трёх
карт и класс; рядом видны его рекорды. Кампания от забега не меняется. Повтор из итогов
сохраняет карту и класс, возврат на базу завершает выбор режима.

Бой продолжается до гибели: нет финала на 10:00 и запланированного босса. После
8:00 плотность не сбрасывается перед финалом; после 10:00 бюджет непрерывно растёт.
Директор сохраняет наступления и передышки, лимит живых — 500. Каждые пять минут —
20 секунд шторма с предупреждением за пять секунд; он заменяет прежнюю тревогу 7:00.
После 12:00 чаще приходят элитки и военные; HP и урон растут по общей минутной
формуле, скорость скрыто не меняется. Активности продолжаются и после десятой минуты,
без очереди пропущенных предложений.

Лучшее время (полные секунды) и убийства сохраняются независимо для каждой пары
карта/класс. Итоги отмечают каждый побитый рекорд и прежнее значение. Трофеи за
15/20/30 минут — постоянные отметки в таблице, без повторяемой выплаты.
Награда за время скромнее кампании: 4 ДНК за полную минуту, обычный ящик за каждые
10 минут, максимум три за забег. Убийства, элитки, подобранные ящики и бонус подготовки
не увеличивают выплату профилю в этом режиме; боевой опыт и расходники работают обычно.
