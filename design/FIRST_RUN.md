## Первый пакет

Свежий профиль сразу начинает вылазку на существующем «Блокпосте», без изменений карты и оружия.
Обычный стартовый автомат, без меты; автоогонь остаётся штатным. Первая видимая группа рядом с героем,
только шаркающие, штатные HP/урон. Детерминированная вводная длится 150 с игрового времени.

| Время | Действие / обратная связь |
|---|---|
| 0–5 с | WASD / левый стик рядом с героем; первые зомби сразу в досягаемости огня |
| После движения | ПКМ / правый стик: «Прицел»; автоогонь уже работает |
| 8 с | Крупный образец рядом: «Опыт»; его подбор даёт первый уровень и обычные карты |
| 18 с | Гарантированный ящик рядом: «Подойти»; забирается касанием |
| 25 с | Q / RB: граната; подсказка только при готовой способности |
| 65 с | Полевой ящик снабжения: E / A открывает обычного торговца, 60 кредитов на выбор |
| 120 с | У героя появляется физическая точка выхода; E / A → итоги → база |
| 150 с | Автоматический выход с сохранением заработанного, если игрок не нашёл выход |

На экране только одна подсказка, максимум два слова, тёмная подложка и значок управления.
Подсказки переживают перезапуск; исчезают после фактического действия, а не нажатия мимо цели.
Непройденные действия доступны в следующем обычном забеге в подходящем контексте.
Приоритет: выход → предмет/торговец → движение → опыт → готовая способность с 25 с → прицел.
Карты и пауза скрывают подсказку. Tab / Back — «Пропустить»: сразу обычная база со всеми вкладками;
это явное действие без подтверждения, без выдачи награды за вылазку.

После первой вылазки: арсенал + склад, отметки «новое» до посещения (арсенал посещён при входе). После второй — операции и мастерская;
казарма при первом очке навыка или третьем возвращении. Закрытые вкладки видны с замком и условием,
но недоступны любым способом ввода. «В бой» всегда позволяет продолжать свободную вылазку.
Настройки доступны сразу. Профиль v1–v8 мигрирует с завершённой вводной, всеми подсказками и вкладками;
ДНК, классы, дерево, мастерская, модели, рекорды и кампания сохраняются. Незавершённый новый профиль
повторяет короткую вылазку после закрытия игры, сохраняя уже выполненные подсказки.
