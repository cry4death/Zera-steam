## Что сделать (каждый экран — вокруг своей сути, по критике)
1. **Операции** — экран стратегического командования вокруг глобуса: глобус — главный объект, крупнее; смена
   оперативной обстановки — центральное событие (удар фронта читается как угроза: стрелка, зона, звук, а не строка
   «Наступление · Ход 3 · +8»); активный регион и доступные задания видны на карте; карточка операции — **только**
   когда операция выбрана (никаких «Операций здесь пока нет» для выбранного по умолчанию региона — по умолчанию
   выбрана первая доступная операция); последствия до старта (CP1) — компактно иконками и числами; главное действие —
   «Начать операцию».
2. **Склад** — получение снабжения: один крупный детальный ящик — главный объект (второй тип — вкладкой), рядом что
   внутри, возможные награды, признаки редкого оружия, как получить ящики; вероятности — отдельным свёрнутым блоком;
   журнал поставок раскрывается по необходимости. При нуле ящиков экран всё равно объясняет, зачем сюда возвращаться.
   Открытие ящика — значимое событие (вспышка/звук/показ модели ≤ 1–1,5 с, без долгой заставки).
3. **Мастерская** — модернизация: крупное оружие в центре, выбор характеристики — одна выделенная крупно (текущее →
   после, цена), остальные компактно; при улучшении параметр и оружие реагируют (короткая анимация/звук); DPS —
   сохранить; выбор ствола — компактной лентой.
4. **Казарма** — развитие бойца (дерево-сеть T2, 3 класса × 72 узла): обзор специализаций с различимыми кластерами,
   выбранный кластер — крупнее (масштаб/фокус), иконки крупнее и различимее (одинаковые замки → разные силуэты
   эффектов), подписи читаемы на 720p; закрытые узлы видны и интригуют, а не почти невидимы; описание узла — компактно
   рядом с узлом, без огромной пустой панели; открытие узла — значимое событие.
5. **Обратная связь вознаграждения** по всей базе (критика, п. 5): новое оружие, улучшение, навык, итог операции —
   заметно и коротко, в одном стиле (`zera_style.gd`).
6. Проверь каждый экран на **двух профилях**: нулевом и прокачанном (несколько забегов: валюта, ящики, модели, узлы,
   история операций) — не пусто и не перегружено; 1920×1080 и 1280×720; мышь, клавиатура, геймпад.
