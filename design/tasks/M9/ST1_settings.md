# ST1 — Настройки: управление, масштаб интерфейса, отдельные выключатели эффектов

**Исполнитель:** Codex (gpt-6.1-sol, high) · **Ветка:** `task/st1` · **Worktree:** `D:\zera-wt\zera-st1`
**Основание:** `design/tasks/GPT_REVIEW_BACKLOG.md` E5. Правила — [AGENTS.md](../../../AGENTS.md).

## Что сейчас
Настройки в [pause_menu.gd](../../../scripts/pause_menu.gd) и `Meta.settings` ([meta.gd](../../../scripts/meta.gd)):
громкость (master), тряска (shake), «меньше движения» (reduce_motion), жестокость (gore), полный экран, автоогонь.
Клавиши зашиты, масштаба интерфейса нет, вспышки/брызги на экране/тряска не разделены, на 720p возможны обрезания.

## Что сделать
1. **Переназначение клавиш** (клавиатура и мышь; геймпад — показ раскладки и, если просто, переназначение):
   движение, способность Q, рывок, граната, перезарядка, пауза, смена прицела. Конфликт клавиш — подсветка и
   обмен. «Сбросить по умолчанию». Подсказки по месту (FR1, `scripts/ui/hints.gd`) и строки подсказок интерфейса
   показывают **назначенную** клавишу, а не зашитую.
2. **Масштаб интерфейса**: 80–150 % для HUD, карт улучшений, торговца, паузы, базы — без обрезаний на 1280×720,
   1920×1080, 2560×1440 и ультрашироком 2560×1080.
3. **Отдельные выключатели/ползунки**: тряска камеры (уже есть — проверить, что действует везде), вспышки экрана,
   брызги крови на экране (`screen_blood.gd`), отдача камеры, мигание тревоги; громкость: общая, музыка, эффекты,
   интерфейс (шины — в `default_bus_layout.tres`, не менять порядок существующих).
4. **Экран настроек** в стиле Z.E.R.A. (`design/UI_STYLE.md`, `scripts/ui/zera_style.gd`): вкладки
   «Управление / Экран / Звук / Игра», работает с мышью, клавиатурой и геймпадом; доступен из паузы и с базы.
5. Сохранение в профиле (`meta.gd`): новые поля с безопасными значениями по умолчанию, старые профили (включая v9 из
   FR1) загружаются без потерь. Карта клавиш — через `InputMap`, восстановление при запуске.
