# W4 — Выстрелы звучат тяжело и живо, стрелять приятно

**Исполнитель:** Codex (gpt-6.1-sol, high) · **Ветка:** `task/w4` · **Worktree:** `Desktop\zera-w4`
**Основание:** запрос автора 2026-10-18 + [GPT_REVIEW_BACKLOG.md](../GPT_REVIEW_BACKLOG.md), блоки D1, D2, D5–D9.

## Проблема (слова автора)

> «Со звуком выстрелов что-то не так, они очень странные, хотя мы качали их с нормальных ассетов. Пластиковые какие-то,
> не чувствуется тяжести и живости. Стрельбу тоже приятную сделать надо».

Исходники хорошие: CC0 Still North Media, 96 кГц / 24 бит, стерео
(`C:\Users\Dev\Desktop\zera-assets\firearm_cc0\extracted\Prepared SFX Library`). Значит, портит обработка и микс.
Подозрения ревьюера (проверить и подтвердить/опровергнуть замерами):

1. **Хвосты обрезаны.** `tools/prep_sfx.py` → `SOURCES`: длительность выстрела 0.20 с у ППШ, 0.24 с у АК, 0.65 у пистолета;
   у smg/rifle ещё экспонента с τ = 65 мс после 35 мс и fade 40 мс. Без хвоста (отражения, «бум» помещения/улицы)
   выстрел превращается в щелчок — это и есть «пластик».
2. **Мастер давит атаку.** `default_bus_layout.tres`: компрессор на Master 6:1, порог −12 dB, **атака 50 мкс**, release 120 мс,
   потом hard limiter −1 dB. Такая атака срезает именно транзиент выстрела; при плотной стрельбе всё сжимается в кашу.
3. **Тихо и плоско.** Weapons bus −9 dB, RMS первых 100 мс −21…−27 dBFS. Нет отдельного низа («тела») выстрела.
4. **Странная вариативность.** `Sfx.play` ([sfx.gd:182](../../../scripts/sfx.gd:182)): pitch_jitter ±5 % и громкость ±1.5 dB на каждый
   выстрел; «лишние» варианты в prep_sfx сделаны из того же дубля сдвигом высоты 0.982/1.021 и наклоном EQ. ±5 % по высоте
   на огнестреле слышно как «игрушку».
5. **Выстрелы теряются.** Интервал одного ID 35 мс и не больше 6 одинаковых голосов, вытесняется самый старый голос,
   всего 24 голоса на всё (орда, gore, гильзы). ППШ/автомат быстрее 35 мс — часть выстрелов просто не звучит.
6. **Низкое HP режет оружие до 1100 Гц** ([sfx.gd:95](../../../scripts/sfx.gd:95)) — в самый напряжённый момент оружие становится глухим.

## Что сделать

### 1. Диагностика (сначала, с цифрами)
- Сравнить исходник и наш файл для каждого ствола: длительность, огибающая (график атака/тело/хвост), спектр, пик, RMS,
  crest factor. Сделать картинку-сравнение `w4_diag_<gun>.png` (огибающая + спектр, исходник vs игра).
- Отрендерить офлайн, что реально выходит из игры: серия 3 с для каждого ствола через ту же цепочку шин (можно
  через `AudioEffectRecord` в игре или симуляцию в Python с теми же параметрами компрессора).
- Вывод в отчёте: какие из пунктов 1–6 подтвердились и насколько.

### 2. Перепрепарировать выстрелы (`tools/prep_sfx.py`)
- Каждый выстрел — слои: **атака** (щелчок/crack, первые мс), **тело** (низ 60–200 Гц, вес), **хвост** (отражение
  окружения, 0.3–1.2 с в зависимости от калибра). Хвост брать из исходной записи, а не обрезать; для очередей хвост
  отдельным файлом/голосом, который не перезапускается на каждом выстреле (уже есть `burst_tails` — довести).
- Тяжесть по калибру: пистолет < ППШ < автомат < дробовик < винтовка Мосина; дробовик и Мосина — с ощутимым низом.
- Варианты — из **разных дублей** исходника (их там 2–5 на ствол, плюс есть другие файлы той же модели в библиотеке).
  Синтетические варианты сдвигом высоты — только если дублей не хватает, и не больше ±1.5 %.
- Не клиппинг: true-peak ≤ −1 dBFS, но и не пережимать — сохранить crest factor.
- Модели из ящиков (m4, shkval, guard, cowboy, osa, winchester) и спец-оружие (rail, launcher, spear, hive) — пройти
  тем же стандартом; синтетику (rail, launcher) — сделать плотнее и тяжелее по тем же правилам.
- **Не распаковывай** 3.3 ГБ архив целиком: на диске C ~5 ГБ свободно. Если нужен файл из архива — извлеки только его
  во временную папку и удали после.

### 3. Микс (`default_bus_layout.tres`, `scripts/sfx.gd` — функции воспроизведения и `_process`, **не `_scan`**)
- Мастер: атака компрессора не меньше 5–10 мс (в `attack_us` это 5000–10000!), мягче ratio, лимитер оставить
  страховкой. Сравнить A/B.
- Отдельная шина для выстрелов игрока с приоритетом; короткое приглушение мира/орды на несколько dB от выстрела
  (sidechain или ручной duck), чтобы выстрел пробивал кашу.
- Приоритет голосов: выстрел игрока и опасность не вытесняются ордой, гильзами и gore (зарезервированные голоса);
  дальние/повторяющиеся попадания объединять. Для очередей — не терять выстрелы: увеличить лимит для shot-ID или
  сделать «очередь» как один голос с перезапуском атаки.
- pitch_jitter для выстрелов ±1–2 %, громкость ±0.5–1 dB.
- Низкое HP: фильтр на Weapons не ниже ~4–5 кГц (или вообще не трогать оружие, глушить только мир).
- Громкость Weapons поднять так, чтобы выстрел был главным звуком боя, без перегруза мастера на 500 врагах.

### 4. Ощущение стрельбы
Что есть: отдача ствола (`recoil`, [weapons.gd:563](../../../scripts/weapons.gd:563)), тряска камеры на выстрел, свет вспышки, гильзы.
- Сделать каждый ствол «тяжёлым» по-своему, синхронно со звуком (одно игровое обновление):
  - вспышка 25–60 мс, размер по калибру, светлое ядро + один лепесток по направлению (без неона);
  - отдача ствола 50–120 мс назад и возврат (не сдвигает прицел); у дробовика и Мосины — заметный откат корпуса/плеч
    героя на пару пикселей;
  - тряска камеры — максимум из импульсов, а не сумма: автомат 0–1 px, дробовик/Мосина 2–4 px на 1080p; HUD неподвижен;
  - дым из ствола после очереди/тяжёлого выстрела (короткий, прозрачный);
  - гильза вылетает синхронно с выстрелом, звук гильзы тихо и позже.
- Настройка «тряска» и «вспышки» уже есть/будет — уважать её.
- Не трогать выбор цели (`_nearest_target` и рядом) — это задача Q1; не трогать кровь и попадания — это R1.
