# W6 — Тир со звуковым пультом: автор сам настраивает звук каждого ствола

**Исполнитель:** Codex (gpt-6.1-sol, high) · **Ветка:** `task/w6` (от `task/w5`) · **Worktree:** `Desktop\zera-w6`
**Основание:** отзыв автора 2026-10-19 на W5. Правила — [AGENTS.md](../../../AGENTS.md).

> «Хреновые вообще, у дробовика какой-то пук. Не годится такое. Можно ли сделать мне панель, чтобы я там для каждого
> оружия какие-то ползунки подёргал и выставил, что мне нравится?»

## Исходное
- Ветка начинается от `task/w5`: из W5 **оставить** исправления микса (шина Shots больше не режется на −7 dB в
  `meta.gd`, отражение в конце очереди, duck мира, 0 потерянных выстрелов, отдача/вспышка/тряска). Запечённые W5
  файлы `sfx/weapons/*/shot_*.wav` автор забраковал — их заменит пульт.
- Библиотека реальных записей CC0: `C:\Users\Dev\Desktop\zera-assets\firearm_cc0\` — `extracted/Prepared SFX Library/`
  (56 готовых файлов, 22 ствола: AK-47, AR-15, PPSh, Mosin Nagant, SKS, Mossberg, Nova, Model 12, 1911, Walther PPQ,
  Smith & Wesson 642, Carl Gustav M45 …), `raw_master_tracks.zip` (1505 файлов, 6,3 ГБ, разные микрофоны —
  см. `master_sheet.xlsx` / `Prepared Master Sheet.csv`). **На диске C ~3 ГБ свободно**: zip целиком не распаковывать,
  извлекать выборочно (`unzip` по именам) и только нужное.
- Звуковая система: `scripts/sfx.gd`, шины `default_bus_layout.tres`, подготовка `tools/prep_sfx.py`.

## Что сделать
1. **Набор исходников.** Для каждого ствола игры (пистолет, револьвер, ППШ, АК, дробовик, Мосин, рельса, гранатомёт)
   отобрать 4–8 кандидатов из библиотеки: разные стволы и микрофоны (близкий — для атаки, дальний/комнатный — для
   хвоста), обрезать тишину, моно 44,1 кГц, 16 бит. Положить в `sfx/gunlab/<ствол>/` с понятными именами
   (`mossberg_close_1.wav`, `nova_far_2.wav`), общий размер ≤ 150 МБ. Список и источник — в `sfx/gunlab/SOURCES.md`.
2. **Слоистый выстрел во время игры** (не запекать): у ствола 3–4 слоя — *атака*, *тело/низ*, *механика*,
   *хвост/отражение*; у каждого слоя — выбранный исходник (или «выкл»). Параметры слоя: громкость, высота тона,
   смещение начала и длина с затуханием, задержка относительно выстрела, разброс высоты/громкости между выстрелами.
   Параметры ствола: фильтр низа/верха, подъём низа (shelf), середина (peak EQ), drive/сатурация, жёсткость атаки
   (компрессор/транзиент), реверберация хвоста (размер, доля), общая громкость; плюс ощущение — тряска камеры,
   отдача, вспышка. Эффекты Godot — на отдельной шине ствола (создаются в коде), без нод на каждый выстрел.
3. **Пульт.** Открывается клавишей **F9** в любом забеге и кнопкой **«Тир»** на базе (режим: мишени-зомби, бесконечные
   патроны, все стволы, нет урона герою). Слева — стволы, справа — слои и параметры ползунками с числами; рядом с
   каждым исходником — кнопка «прослушать». Кнопки: **Выстрел** (одиночный), **Очередь** (2 с), стрелять можно и
   мышью прямо в тире под открытым пультом; **A/B** — сравнить с сохранённым; **Сохранить**; **Сбросить**;
   **Скопировать с …**. Меняешь ползунок — следующий выстрел уже звучит по-новому. Управление мышью, понятные
   русские подписи (это инструмент автора — текст здесь уместен), без технических сокращений.
4. **Сохранение.** `sfx/gun_tuning.json` в проекте (его будут коммитить — это и есть итог настройки) и копия в
   `user://` для собранной игры; игра загружает при старте. Нет файла — разумные стартовые пресеты.
5. **Стартовые пресеты — хорошие, а не «пук»:** собери для каждого ствола лучшее, что можешь, из реальных записей
   (дробовик — Mossberg/Nova/Model 12 близко + низ + длинный хвост; Мосин — резкий crack + длинное эхо; АК —
   плотная середина). Отрендери A/B-набор `design/tasks/reports/w6_ab/<ствол>_preset.wav` против W4/main.

## Можно трогать
`scripts/sfx.gd`, новые `scripts/gun_lab*.gd` (пульт, тир), `scripts/base.gd` (только кнопка «Тир»),
`scripts/game.gd` (режим тира, F9, тесты), `scripts/weapons.gd` (только вызов звука/ощущения выстрела),
`scripts/game_camera.gd`, `default_bus_layout.tres`, `scripts/meta.gd` (только громкости шин), `sfx/gunlab/**`,
`sfx/gun_tuning.json`, `tools/prep_gunlab.py`, `design/tasks/reports/W6*`, `design/tasks/reports/w6_*`.
Старые `sfx/weapons/*/shot_*.wav` — можно удалить, когда пульт их заменит (обязательные звуки `REQUIRED` в
`sfx.gd` — перевести на пульт).

## Проверки
Полный набор из AGENTS.md + `--audio-test` + новый `--gunlab-test`: каждый ствол играет все слои, параметры
применяются (сравни выход до/после изменения), сохранение → перезапуск → загрузка без потерь, F9 открывает и
закрывает пульт в бою без ошибок, тир запускается с базы, 20 выстрелов/с одного ствола без потерь и обрывов.
FPS боя не хуже 5 %. Оконные проверки, которые песочница не даёт снять, — перечисли, ревьюер прогонит сам.
