# EV2 — Ещё активности на карте и эпизод в операциях кампании

**Исполнитель:** Codex (gpt-6.1-sol, high) · **Ветка:** `task/ev2` · **Worktree:** `Desktop\zera-ev2`
**Основание:** продолжение EV1 (в main: груз, носитель, топливная ловушка; `design/ACTIVITIES.md`, отчёт
`design/tasks/reports/EV1.md`). Автор хотел, чтобы забег не был «10 минут просто бегаешь». Правила — [AGENTS.md](../../../AGENTS.md).

## Что нужно
1. **3 новые активности** из каталога `design/ACTIVITIES.md` (или лучше — обоснуй), разные по типу от EV1:
   - БТР/машина с багажником — взлом/удержание сбоку под натиском, награда — модуль/оружие;
   - генератор и турель — запустить, турель отстреливает орду 20 с (свои пули/вспышки, без новой тяжёлой системы);
   - корректировщик — пометить полосу, артудар по орде (сочно: взрывы, разлёт тел R1e);
   - гнездо под кузовом / военный ящик с сиреной / раненый на носилках — по выбору.
2. **Заполнить пустые отрезки** забега (EV1 оставил длинные паузы 3:00–5:20): 4–5 эпизодов за 10 минут, с учётом
   режиссёра орды HD1 (активность встраивается в фазы давления, не ломает пики/передышки).
3. **Кампания:** один необязательный эпизод в операциях «зачистка»/«возврат» (CP1/C6), не мешающий цели операции;
   в «извлечении» и «ударе по улью» — выключено.
4. Каждая — предмет в мире, указатель у края, иконка без текста, звук старта/успеха/провала из `sfx.gd`, арт —
   `tools/gen_art_ev2.py` в стиле игры.

## Можно трогать
`scripts/activities.gd`, `scripts/activities_test.gd`, `scripts/spawner.gd` (только вызовы волн активности),
`scripts/horde_director.gd` (только согласование с фазами), `scripts/pickups.gd`, `scripts/hud.gd` (указатель/иконка),
`scripts/campaign/*` (только включение эпизода в операции), `scripts/game.gd` (подключение, тесты), `scripts/sfx.gd`
(регистрация), `tools/gen_art_ev2.py`, `art/activity_*`, `design/ACTIVITIES.md`, `design/BALANCE.md`,
`design/tasks/reports/EV2*`, `design/tasks/reports/ev2_*`.
Не трогать оружие/эффекты/gore (W7b), экраны базы (U4). Взрывы артудара — через существующие `explosions.gd` вызовом.

## Проверки
Полный набор из AGENTS.md + `--activities-test --fresh-save` (расширить: каждая новая активность — успех/провал,
награда один раз, достижимость на всех картах, сид), `--director-test --fresh-save`, `--campaign-test`.
FPS не хуже 5 %.
