# B2 — Новые боссы ульев: Матка и Мясная гора

**Исполнитель:** Codex (gpt-6.1-sol, high) · **Ветка:** `task/b2` · **Worktree:** `Desktop\zera-b2`
**Основание:** выбор автора 2026-10-19 («новые боссы»). Правила — [AGENTS.md](../../../AGENTS.md).

## Что сейчас
Единственный босс — «Объект-7» ([boss.gd](../../../scripts/boss.gd), 450 строк: рывки, удар по земле, рёв, сброс
брони по фазам; без физических тел и нод на атаки). В каталоге кампании
([campaign_catalog.gd:57](../../../scripts/campaign/campaign_catalog.gd:57)) ещё четыре улья с `playable: false`:
Матка (Сибирь), Мясная гора (Восточная Азия), Генерал (Ближний Восток), Сердце Улья (Южная Азия, финал).
Задумка — [GDD.md:372](../../GDD.md:372), [CAMPAIGN.md:506](../../CAMPAIGN.md:506), `design/IDEAS.md`. CP1 сделал
кампанию с фронтом, форпостами, образцами и штурмом Объекта-7 (`design/CAMPAIGN_HOOKS.md`, отчёт `CP1.md`).

## Что нужно
1. **Матка** (лаборатория): почти неподвижная туша, **рожает зомби** (выводки из «родовых мешков», которые можно
   отстрелить заранее), бьёт щупальцами из-под земли по телеграфу (тёмное пятно → удар), плюётся биомассой, при
   потере мешков злится и ускоряет роды. Ситуация для игрока: держать дистанцию, чистить выводок, бить по мешкам и
   телу между волнами.
2. **Мясная гора** (коллектор): собрана из трупов, медленная и огромная, **разваливается по частям** — от урона
   отпадают куски (руки, слои трупов), которые встают и бегут как отдельные враги; катится/наваливается, оставляет
   лужи гнили (замедление), к концу — маленькое быстрое «ядро». Ситуация: кайтить, не дать окружить отвалившимся
   кускам, добить ядро.
3. У каждого: 2–3 фазы с заметной сменой поведения, все атаки **читаются по телеграфу** (форма/тень/звук, без
   текста), полоса HP как у Объекта-7, своя смерть с кровью и кусками R1c/R1d (река крови вокруг), свой рёв/звуки
   из существующих средствами `sfx.gd`. Без нод на снаряд/щупальце — как в boss.gd.
4. **Код:** не копировать 450 строк — вынести общее (HP, фазы, полоса, урон, хит-тест, телеграфы) в базу или
   хелпер, Объект-7 продолжает работать как раньше (его проверки/тесты не меняются по смыслу).
5. **Кампания:** сделать оба улья `playable: true` — операция «Удар по улью» в своём регионе со своим боссом;
   победа даёт эффект региона из CAMPAIGN.md (Матка — ослабляет мутации в связанных зонах, Мясная гора —
   прекращает выбросы биомассы; реализуй как простое правило/модификатор, если просто, иначе — число в брифинге и
   предложение в отчёте). Не ломать дугу CP1 (штурм Объекта-7, победа войны) — новые ульи необязательные
   кульминации середины; прогони ботов CP1, статистика не должна сильно поменяться.
6. **Арт** — генератор `tools/gen_art_b2.py`: крупные спрайты в стиле игры (органика, мясо, реалистично,
   приглушённо, как узел C6b), стадии повреждения, мешки/щупальца/куски. Без мультяшности и неона.
7. **Баланс:** время убийства каждым из трёх лоадаутов `--sim` (стартовый, W1, полный) — сравнимо с Объектом-7
   (±25 %); урон по игроку — сравним.

`scripts/sfx.gd` (регистрация), `tools/gen_art_b2.py`, `art/boss_*`, `design/BALANCE.md` (раздел боссов),
`design/CAMPAIGN.md`, `design/tasks/reports/B2*`, `design/tasks/reports/b2_*`.

HD1; зомби рождай через существующий `Horde.spawn`. Не трогать оружие и gore (впереди Z2).

## Проверки
Полный набор из AGENTS.md + новый `--boss-test`: каждый босс стартует, проходит все фазы, каждая атака срабатывает
и попадает по телеграфу, рождённые/отпавшие враги считаются в лимит живых, смерть босса завершает операцию ровно
один раз, Объект-7 ведёт себя как прежде. Бенч `--bench=500` и отдельно бой с каждым боссом — FPS не хуже 5 % от
боя с Объектом-7.
