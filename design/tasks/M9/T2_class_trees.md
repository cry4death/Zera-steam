# T2 — Классы и большое дерево-граф для каждого

**Исполнитель:** Codex (gpt-6.1-sol, high) · **Ветка:** `task/t2` · **Worktree:** `Desktop\zera-t2`
**Основание:** отзыв автора 2026-10-19 на T1. Правила — [AGENTS.md](../../../AGENTS.md).

> «Слишком простое древо. На скринах видел — что-то такое должно быть. Для каждого класса разное должно быть.»

Референс автора: [refs/t2_tree_reference.png](../refs/t2_tree_reference.png) — дерево способностей Assassin's Creed Origins:
**три кластера** (Hunter / Warrior / Seer) на одном поле, узлы — круглые иконки, **связаны линиями в сеть**
(не колонки), пути из центра расходятся и пересекаются, кластеры соединены мостами, взятые узлы и путь подсвечены,
внизу — очки и полоса опыта. Берём структуру и читаемость, **не** копируем арт/иконки/цвета AC (свой стиль игры,
без неона: `design/tasks/reports/U1_audit.md`).

## Что сейчас (T1, в main)
`scripts/class_tree.gd`: 48 узлов в 6 колонках-ветках, 12 развилок, ключевые узлы, сброс, казарма в `scripts/base.gd`,
сохранения v6. Класс один — Штурмовик. Идеи классов: `design/tasks/GPT_REVIEW_BACKLOG.md` H2 (Штурмовик «Пролом»,
Пулемётчик «Удерживать фронт», Инженер «Второй фронт»; класс = своё правило + кнопка Q + две доктрины; критерий —
при том же оружии различаются движение, момент кнопки, приоритет целей), GDD §12.

## Что нужно
1. **Три класса** (H2): Штурмовик, Пулемётчик, Инженер (названия/детали можно улучшить с обоснованием). У каждого —
   своё пассивное правило, активка на Q с перезарядкой, стартовый ствол из общего арсенала. Выбор класса — в казарме
   перед вылазкой; уровень и ДНК — общие или по классу (реши и обоснуй; не обесценивать уже набранное).
2. **Дерево-граф для каждого класса**, 60–90 узлов: 3 кластера-специализации класса (у Штурмовика, например,
   «Штурм», «Манёвр», «Подрыв»), узлы связаны рёбрами, открыть узел можно, если взят **любой** соседний (как в
   референсе), из центра несколько стартовых путей; мосты между кластерами; ключевые узлы на концах и перекрёстках
   меняют правило игры; развилки T1 сохранить как взаимоисключающие пары. Деревья классов **разные** по содержанию и
   форме; общие базовые узлы (HP, перезарядка) допустимы, но не больше трети.
3. **Экран дерева** в казарме: всё поле видно целиком (масштаб/прокрутка/панорама мышью и стиком), круглые иконки на
   линиях, подсветка взятых узлов и путей, доступные — контур, закрытые — тускло; подсказка при наведении (название,
   эффект числами, цена); очки и полоса до следующего очка внизу; переключение класса вкладками. Иконки — генератором
   `tools/gen_art_t2.py`, единый стиль, различимые силуэты (огонь, магазин, рывок, граната, броня, турель…).
4. **Миграция:** профиль v6 → v7, текущий Штурмовик и его взятые узлы T1 переносятся (очки возвращаются или узлы
   сопоставляются), ДНК/мастерская/кампания сохраняются.
5. **Баланс:** `--sim` каждым классом с деревом 0 / половина / полное — классы сопоставимы по силе (±15 %), но
   играются по-разному (в отчёте — чем). Полное дерево не делает игру тривиальной.

`scripts/hud.gd` (иконка и перезарядка Q), `scripts/game.gd` (подключение и тесты), `tools/gen_art_t2.py`, `art/tree_*`,
`art/class_*`, `design/UPGRADE_TREE.md`, `design/GDD.md` §12, `design/BALANCE.md` (классы и дерево),

## Проверки
Полный набор из AGENTS.md + `--class-tree-test` (расширить): у каждого узла каждого класса применяется эффект,
связность графа (каждый узел достижим из центра), правило «открыть можно при взятом соседе», развилки, Q каждого
класса срабатывает и перезаряжается, миграция v6 → v7 без потерь, сброс. Тест казармы `--base-test` (в окне) —
мышь и геймпад. FPS не хуже 5 %.
