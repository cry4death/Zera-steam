# O3 — Три новые карты: разные места войны

**Исполнитель:** Codex (gpt-6.1-sol, high) · **Ветка:** `task/o3` · **Worktree:** `Desktop\zera-o3`
**Основание:** в игре 3 карты (`maps/quarantine_checkpoint.json`, `old_town.json`, `open_perimeter.json`, задача O2 —
`design/tasks/M8/O2_authored_maps.md`, отчёт `O2.md`); кампания идёт по 8 регионам и 3 типам операций, забеги
повторяются по месту. Автор хочет, чтобы забеги не были однообразными. Правила — [AGENTS.md](../../../AGENTS.md).

## Что нужно
1. **Три новые карты**, разные по геометрии и настроению (подбери и обоснуй), например:
   - **Военная база / аэродром** — ангары, техника, бетонные капониры, открытые плацы и узкие проходы между ангарами
     (место для бронированных военных Z2 и будущего босса «Генерал»);
   - **Промзона / порт** — контейнерные лабиринты, краны, пирсы с водой по краю, длинные коридоры (колонны HD1);
   - **Спальный район / торговый центр** — дворы, парковки, остановки, обломки, много мелких укрытий.
   Каждая — своя палитра земли, свои объекты (машины, контейнеры, ограждения), свои сокеты для целей кампании (C6),
   активностей (EV1/EV2), спавна, извлечения.
2. Карты работают со всем, что есть: навигация PF1 (щели и проходы для разных радиусов), режиссёр HD1 (паттерны:
   колонна по коридору, клещи, засада из-за укрытий), активности EV2, цели и арена боссов, кровь R1e.
3. **Кампания:** привязать карты к регионам (`campaign_catalog.gd`) — разнообразие по миру, у каждой операции на глобусе
   своя карта; новые иллюстрации регионов в брифинге — если просто.
4. **Арт** — `tools/gen_art_map.py` / `tools/gen_art_obstacles.py` / новый `tools/gen_art_o3.py`: в стиле существующих
   карт (реалистичный пиксель-арт, приглушённо), новые объекты с коллизией O1.
5. **Производительность:** на каждой карте `--bench=500` не хуже 5 % от `quarantine_checkpoint`.

## Можно трогать
`maps/*.json` (новые карты; старые — только если нужен общий формат), `scripts/map_loader.gd`, `scripts/arena_layout.gd`,
`scripts/ground.gd`, `scripts/set_pieces.gd`, `scripts/obstacles.gd` — **только** новые виды объектов и их коллизия
(параллельно B3 правит визуал заражённой арены — не трогай его код), `scripts/campaign/campaign_catalog.gd` (привязка
карт к регионам), `scripts/game.gd` (выбор карты, тесты), `tools/gen_art_map.py`, `tools/gen_art_obstacles.py`,
`tools/gen_art_o3.py`, `art/map_*`, `art/obstacle_*`, `art/ground_*`, `design/tasks/reports/O3*`, `design/tasks/reports/o3_*`.
Не трогать HUD/меню (идёт U5), боссов (B3).
