# ZAI5 — Поле путей v2: видимость в поле, без колонн у стен, дешевле при беге

**Исполнитель:** Codex (gpt-6.1-sol, high) · **Ветка:** `task/zai5` · **Worktree:** `D:\zera-wt\zera-zai5`
**Основание:** аудит ZAI1 ([reviews/ZOMBIE_AI_REVIEW.md](../reviews/ZOMBIE_AI_REVIEW.md), находки С6, С7, З4;
рекомендации R10, R11). Правила — [AGENTS.md](../../../AGENTS.md).
**Зависит от:** ZAI2 (`--crowd-test`, бюджет лучей в `--pathing-test`) и ZAI4 (то же ядро движения — после него).
От ответов автора не зависит.

## Что сейчас (main)
- **Лучи у агентов.** Прямой подход: `body_clear` DDA до 700 px раз в 4 тика на агента (`horde.gd:867-877`).
  34–50 вызовов за тик, 0,49–0,76 мс/тик при 300–340 живых. Переключение «прямо ↔ поле» у 0,6–2,4 % замеров
  за 0,1 с.
- **Колонны у стен (З4, подтверждено облаком).** Метрика: доля идущих зомби в 16 px от стены, где рядом
  (24 px по нормали) открыто, к той же доле случайных проходимых точек кольца 90–600 px. Итог по режимам:
  - по полю путей: в 3,1–10,4 раза чаще равномерного, 32–96 % из них идут вдоль стены (в городах 77–96 %);
  - прямо к игроку: 0,1–1,5 раза.
  На старте в городе по полю у стен идут 80 % (old_town, ×10,4) и 49 % (residential, ×9,8). Причина — кратчайший
  путь 8-связного Дейкстры жмётся к углам без штрафа у стен, а у препятствий направление тянется к отрезку пути
  (`obstacles.gd:766-769`). Данные — [reports/zai1_data.md](../reports/zai1_data.md), раздел «облако / wall».
- **Цена поля.** Полный Дейкстра ×3 класса на каждую новую клетку игрока, пауза 0,05 с (`obstacles.gd:928-972`).
  При беге 2,7 ядра против 1,0 стоя. Поле одного класса 50–97 мс. Класс 2 (r 7,95) считается всегда.

## Что сделать
1. **R10 — видимость в задаче потока.** В слое класса считать флаг «видит игрока» для клеток (луч по сетке от игрока
   с учётом радиуса класса, один раз на пересчёт поля). Агент в такой клетке идёт прямо, иначе по полю. Лучей у
   агентов нет. Переход между режимами сглажен (смешивание направлений на 1–2 клетки).
2. **Штраф у стен.** В весах клеток — надбавка за близость к препятствию (по `obstacle_distance`, затухание до
   ~24 px), чтобы путь шёл серединой прохода. Притяжение к отрезку пути — только в щелях уже 2 диаметров класса.
3. **R11 — дешевле.** Класс 2 считается только при живых крупных (толстяк/тяжёлые/элитки). Классы 0 и 2 — реже
   класса 1. Волна Дейкстры — до максимума стоимости клеток с зомби + запас, а не по всей карте. Пауза между
   циклами ≥ 0,15 с. Корзины — на `PackedInt32Array`.
4. Вернуть в `--pathing-test` ожидание `queries == 0`.
