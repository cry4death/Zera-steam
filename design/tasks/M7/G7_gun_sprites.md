# G7 — спрайты стволов: найти пак или перерисовать 16 моделей

**Исполнитель:** Sonnet · **Уровень:** high (художественное качество + лицензии) · **Ветка:** `task/g7`
**Запрос автора:** «в игре должны быть модели оружия, а не просто текст; найти пак ассетов под наши стволы или нарисовать».

## Сейчас

`art/gun_<model>.png` (16 шт., ~50–90×20–33 px, вид сбоку) рисует `tools/gen_art_m6.py` (S6) — используются только на базе.
Они блочные: ППШ, М4, Страж, Шквал узнаются плохо. В бою стволов не видно (только текст в карточках).

## Шаг 1 — поиск пака (≤ 30 мин)

Ищи **пиксельные спрайты реального огнестрела, вид сбоку**, с лицензией для коммерческой игры в Steam **без обязательной
атрибуции или с атрибуцией** (CC0, CC-BY, «free for commercial use» с явным текстом лицензии). Источники: OpenGameArt
(фильтр лицензий), itch.io (бесплатные паки, читать страницу лицензии), Kenney. Нужно покрыть хотя бы большинство из:
AK-47, AR-15/M4, M1911, Walther-подобный 9мм, S&W J-frame (короткий револьвер), Ruger Single-Action, ППШ (диск),
Carl Gustav M45 / SMG, Mosin-Nagant, Winchester/Marlin (рычаг), помповый дробовик, Winchester M12, гранатомёт.
Стиль должен сесть рядом с нашей игрой (тёмный пиксель-арт, свет сверху-слева, приглушённые цвета — посмотри
`art/zombie_atlas.png`, `art/player.png`, скриншоты `design/tasks/reports/w2_*.png`, `s6_*.png`).

Если пак найден и подходит — **не качай его сам** без записи: в отчёт — ссылка, автор, точный текст/тип лицензии,
что покрывает, превью-картинка со страницы (описание), и почему подходит; ревьюер решит и скачает. Если не найден
или стиль/набор не тот — переходи к шагу 2 (это ожидаемый путь).

## Шаг 2 — перерисовать генератором

Новый `tools/gen_art_guns.py` (поверх `gen_art` как `ga`, детерминированно) → `art/gun_<model>.png` для всех 16 моделей
(`WeaponDefs.MODELS`, имена файлов как сейчас — база не ломается) + `art/gun_<model>_world.png` — та же модель в
**игровом масштабе** для боя (длина АК ~18–22 игровых px, пистолет ~8–10, Мосинка ~26–28; ствол вправо, точка хвата и
дульный срез — записать в `art/guns_meta.json`: `grip`, `muzzle` в пикселях спрайта).
Узнаваемость по силуэту — главное. Обязательные детали:

| Модель | Что должно читаться |
|---|---|
| АК-С | изогнутый «рожок», газовая трубка над стволом, деревянное цевьё, складной приклад |
| М4 | ручка переноски/планка, прямой магазин, телескопический приклад, пламегаситель |
| Мясник (помпа Nova) | трубчатый магазин под стволом, подвижное цевьё, пистолетная/прямая ложа |
| Шквал (Winchester M12) | классический помповик с длинным стволом, деревянное цевьё и приклад |
| Кольт (1911) | затвор с насечками, курок, рукоять с щёчками |
| Страж (9мм полимер) | угловатый затвор, полимерная рамка, без курка |
| Бульдог (S&W 642) | короткий ствол, барабан, скруглённая рукоять |
| Ковбой (Single Action) | длинный ствол, барабан, курок, изогнутая «сливовая» рукоять, латунная рамка-акцент |
| ППШ | дисковый магазин, перфорированный кожух ствола, деревянный приклад |
| Оса (Carl Gustav M45) | прямой магазин, кожух с отверстиями, складной приклад-рамка |
| Мосинка | длинный ствол, рукоять затвора вниз, длинная деревянная ложа, штык не нужен |
| Винчестер (Marlin) | скоба-рычаг, трубчатый магазин, деревянный приклад |
| Игла / Копьё | рельсотрон: катушки/кольца (у Копья — острое, оранжевые кольца) — единственные «фантастические» |
| Гром | ручной подствольный/барабанный гранатомёт (короткий толстый ствол) |
| Улей | барабанный многозарядный гранатомёт (кассеты) |

Стиль: тёмный металл с рампой (`ga` рампы), блик 1 px сверху-слева, дерево тёплое и приглушённое, выборочная обводка
как у остальных спрайтов. Без «игрушечной» яркости.

## Проверка
- `design/tasks/reports/g7_sheet.png` — все 16 моделей ×4 (иконки) и ×6 (боевые) на асфальте и на крови, подписи; посмотри сам,
  итерируй, пока каждая модель узнаётся по силуэту. Рядом — старые иконки S6 для сравнения.
- Детерминированность (`--out tmp` побайтово), `godot --headless --path . --import`, `--base-test` (база рисует новые иконки).

## Можно трогать
`tools/gen_art_guns.py` (новый), `art/gun_*.png` (+`.import`), `art/gun_*_world.png`, `art/guns_meta.json`, `tools/gen_art_m6.py`
(только убрать генерацию иконок стволов, если переносишь), отчёт `design/tasks/reports/G7.md`, `g7_*`.
**Не трогать** скрипты игры (идут P1 и C1).
