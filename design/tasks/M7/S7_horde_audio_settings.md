# S7 — звук орды и gore в игре, низкое HP, меню паузы с настройками

**Исполнитель:** Sonnet · **Уровень:** high · **Ветка:** `task/s7` (от main после A4 и S6)
**Контракты:** §10 (Sfx), §12 (Meta — сохранение), §14 (id звуков). **Дизайн:** GDD §2 (погружение), §6 (gore), §9; IDEAS §2.4, §7.

## Цель

Орда слышна со всех сторон и громче там, где её больше; каждое попадание чавкает; на низком HP
сердце колотится и мир глохнет. Игрок может настроить громкость и жестокость.

## Сделать

1. **Голоса орды** без нод на зомби: планировщик в `Sfx` или отдельном узле `HordeAudio` — раз в
   ~0.15 с выбирает 0–2 случайных живых зомби в радиусе слышимости (ближе — вероятнее) и играет
   `zombies/groan` в их позиции (позиционно, шина `World`); вид → свой голос (`runner`, `fat`),
   элитки громче и ниже. `attack` — когда зомби в радиусе касания игрока (лимит). Лимит голосов орды
   ~6 одновременно. **Луп** `ambience/horde_0/1`: громкость и смесь 0/1 по числу живых зомби вокруг,
   панорама — к центру масс орды относительно игрока (два плеера с кроссфейдом, без щелчков).
2. **Gore**: `enemy_hit` → `gore/hit` (лимит ~12/с, ближние приоритетнее), `enemy_killed` → `gore/splat`
   или `gore/gib` по типу смерти (+ `zombies/death` с шансом ~35%), обезглавливание/распил — `gore/bone`,
   `fat_burst` → `gore/gib` + `zombies/fat`, `spit_fired` → `zombies/spit`. Босс: `roar` → `zombies/boss_roar`,
   рёв при появлении и при фазе 2.
3. **Игрок**: `hurt` → `player/hurt` (+ лёгкая тряска уже есть); **низкое HP** (< 30%): `player/heartbeat`
   луп с громкостью по HP, ФНЧ на шинах `World`/`Weapons` (AudioEffectLowPassFilter, плавно), красная
   пульсирующая виньетка по краям (в стиле `alarm_overlay`/`screen_blood`, не перекрывать HUD).
4. **Меню паузы** (`Esc` / Start на геймпаде; в забеге): «Продолжить», «Настройки», «На базу»
   (с подтверждением; забег засчитывается как смерть → итоги). **Настройки** (тот же экран из меню
   базы — кнопка на базе): громкость Общая / Оружие / Мир / Интерфейс, **Жестокость** (Мало / Средне /
   Максимум — множители количества крови, гибов, брызг на экран, луж; «Мало» ещё отключает брызги на
   экран), Тряска экрана (0–100%), Полноэкранный режим. Хранение — в сохранении `Meta` (новое поле
   `settings`, версия схемы +1 с миграцией старого файла), применяется сразу.
5. **UI-звуки**: `ui/click`/`confirm`/`deny` в Level Up, лавке, итогах, базе, меню паузы.
6. **`--audio-test`** (новый, оконный): 30 с боя с ордой ~300, печать раз в секунду
   `AUDIO t=.. voices=.. horde_voices=.. hits_s=.. dropped=.. horde_mix=.. lowpass=..`, затем
   принудительно HP=20% на 5 с (heartbeat/ФНЧ), скриншот виньетки `_lowhp.png`, меню паузы `_pause.png`,
   настроек `_settings.png`. `--headless` тесты — без звука и ошибок.

## Критерии приёмки
- [ ] Орда звучит позиционно, луп меняется с плотностью; лимиты держатся (`dropped` растёт, а не голоса).
- [ ] Gore-звуки на попадания/смерти/гибы, рёв босса.
- [ ] Низкое HP: сердце, ФНЧ, виньетка — плавно входят/выходят.
- [ ] Меню паузы и настройки работают, сохраняются, «Жестокость: Мало» заметно чище (скриншоты Мало/Максимум).
- [ ] Производительность не хуже main >10%. Отчёт `design/tasks/reports/S7.md`.
