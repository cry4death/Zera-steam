# H1 — новый боевой HUD (тактический интерфейс Z.E.R.A.)

**Исполнитель:** Sonnet · **Уровень:** high (UX + горячая отрисовка) · **Ветка:** `task/h1`
**Запрос автора:** «сделать более хороший HUD для игры». Тон — `design/SETTING.md` (служебный тактический дисплей оперативника).

## Сейчас (`scripts/hud.gd`, ~240 строк, рисуется `_draw` в «игровых пикселях»)

Слева сверху — полоска HP, уровень, кредиты, иконка гранаты; по центру — таймер и «убито»; справа — **отладочные
цифры видны по умолчанию** (FPS, зомби, орда мс, пули…; `show_debug := true`); внизу — карточки стволов **текстом**
(имя, патроны, модули) с полоской; полоса HP босса; анонсы; прицел (S8); виньетка низкого HP (S7).

## Цель

С первого взгляда, не отрываясь от орды: сколько у меня HP, сколько патронов и кто перезаряжается, когда граната и
рывок, сколько до уровня и до босса, где опасность за краем экрана. Красиво, в стиле игры, ничего не перекрывает бой.

## Сделать

1. **Отладка — только по F3** (`show_debug := false` по умолчанию; в тест-режимах можно включать как сейчас) и
   подсказка F1–F10 — только в отладке.
2. **Здоровье**: сегментированная полоса (по 10 HP), «призрак» потерянного HP, вспышка при уроне, иконка бронежилета
   при бонусе дерева; число HP.
3. **Опыт**: тонкая полоса опыта во всю ширину сверху (или под HP) с уровнем; вспышка при Level Up.
4. **Стволы (низ экрана)**: панели 4 слотов с **иконкой модели** (`art/gun_<model>.png`, их сейчас перерисовывает G7 с
   теми же именами — бери по имени, не копируй), имя модели, патроны — **ряд патронов/«пипсов»** (для больших магазинов —
   счётчик + полоса), перезарядка — кольцо/полоса прогресса поверх иконки, «ПЕРЕЗАРЯДКА» мигает, уровень ствола
   звёздочками I–V, патроны и модули — маленькими значками-плашками (цвет патронов). Активный «в огне» ствол —
   лёгкая подсветка при выстреле. Всё компактно: панели не выше ~14% экрана.
5. **Способности**: граната и рывок (заряды рывка из дерева) — иконки с круговым кулдауном и клавишей; «Адреналин» — индикатор.
6. **Время и цель операции**: таймер, ниже — следующее событие («ТОРГОВЕЦ 5:00», «ТРЕВОГА 7:00», «ОБЪЕКТ-7 10:00»)
   с обратным отсчётом; убито и комбо. Если забег из кампании (`Campaign.pending()` не пуст) — строка операции
   «ОП: <имя> · угроза III» и значки модификаторов (C2 параллельно может добавить свою строку в `hud.gd` — при слиянии
   останется одна; сделай её у себя по `Campaign.pending()` — данные уже есть после C1).
7. **Указатели за краем экрана**: стрелки по краю к элиткам, торговцу/предметам (контейнер, ящик), боссу — с иконкой
   и дистанцией; **индикатор направления урона** (красная дуга со стороны удара).
8. **Кредиты/образцы**: счётчик кредитов с иконкой и «+N» при подборе; ДНК/образцы забега (прогноз ДНК по формуле) — мелко.
9. **Стиль**: тёмные полупрозрачные панели с тонкой рамкой и угловыми засечками (как тактический дисплей), акцентный
   цвет Z.E.R.A. (выбери один — янтарный/кислотно-жёлтый — и используй в HUD последовательно), шрифт проекта, тени текста
   для читаемости на крови. Масштаб: 1920×1080 и 1280×720 без налезаний.
10. **Производительность**: HUD рисуется каждый кадр — без аллокаций строк в горячем цикле где возможно, текстуры иконок
    кешировать; `--loadout --bench=500` не хуже main >3%.
11. **`--hud-test`** (оконный): скриншоты обычного боя, перезарядки нескольких стволов, низкого HP, тревоги, босса,
    операции кампании (если есть `--campaign-op`), 1280×720 (`_battle.png`, `_reload.png`, `_lowhp.png`, `_alarm.png`,
    `_boss.png`, `_720p.png`). Посмотри всё сам и итерируй.

## Можно трогать

`scripts/hud.gd` (основное), новый `tools/gen_art_hud.py` → `art/hud_*.png` (иконки рывка/гранаты/патронов/указателей,
если нужны), `scripts/game.gd` (только данные для HUD: следующее событие, прогноз ДНК — геттеры, без логики боя),
`scripts/player.gd` (только сигнал/поле направления урона, если нет), отчёт `design/tasks/reports/H1.md`, `h1_*`.
Параллельно: P1 (оптимизация — может трогать отрисовку `hud.gd`), C2 (может добавить строку операции в `hud.gd`), G7
(иконки стволов) — конфликты при слиянии разрешит ревьюер, держи изменения в `hud.gd` цельными.

## Проверка

```
godot --headless --path . --import
godot --disable-vsync --path . -- --hud-test --shot=.../h1.png
godot --disable-vsync --path . -- --loadout --bench=500   (×2 против main)
godot --headless --path . -- --sim=600 ; --disable-vsync --path . -- --boss ; --ui-test ; --aim-test
```

## Критерии приёмки
- [ ] Отладка скрыта по умолчанию; HP/опыт/патроны/перезарядка/способности читаются с первого взгляда.
- [ ] Иконки стволов, пипсы патронов, кольца перезарядки; следующее событие с отсчётом; указатели за краем; урон по направлению.
- [ ] 1080p и 720p без налезаний; производительность ≤ +3%. Отчёт `design/tasks/reports/H1.md`.
