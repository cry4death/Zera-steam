# A4 — звуки орды, gore, игрока, интерфейса

**Исполнитель:** Sonnet · **Уровень:** high (синтез gore — творческий) · **Ветка:** `task/a4`
**Контракт:** `CONTRACTS.md` §14 (все id, количества, лупы), формат и уровни — §9.

## Цель

Сейчас звучат только стволы. Орда должна стонать со всех сторон, каждое попадание — чавкать,
смерть — рваться, гибы — хрустеть. Это половина «погружения» (GDD §2, цель 3).

## Сделать

1. Раздел `horde()` в `tools/prep_sfx.py` (общие функции переиспользуй; прежние разделы и их файлы —
   байт-в-байт). Исходники только читать: `C:\Users\Dev\Desktop\zera-assets\zombies_cc0\extracted\`.
2. **Голоса** (§14): чистка (ФВЧ 60 Гц, обрезка тишины, фейды), нормализация, вариации питча/форманта
   (ресемплинг + лёгкий EQ), чтобы 24+18 исходников дали разнообразие без узнаваемых повторов.
   Бегун — выше и злее, толстяк — ниже и мокрее, босс — огромный (слои, питч 0.5–0.6, сатурация, суб).
3. **Луп орды** `ambience/horde_<0|1>`: наложение десятков стонов со случайным временем/панорамой/
   громкостью + низкий гул + шарканье (фильтрованный шум с огибающими шагов). Бесшовный: кроссфейд
   конца с началом, проверь разрыв на стыке (RMS последних/первых 50 мс и отсутствие щелчка).
   0 — редкая толпа, 1 — плотная.
4. **Gore — синтез** (главная сложность, качество важно): попадание пули — короткий «шлёп» (шумовой
   импульс через полосовой фильтр 300–1500 Гц + низкий «тук» 80–120 Гц + капли); смерть — мокрый
   всплеск (2–3 слоя, хвост капель); гибы — разрыв (рвущийся шум, хруст = серия коротких щелчков
   с резонансом 2–4 кГц, шлепки кусков с задержками 50–300 мс); кость — сухой хруст. Без «бипов»
   и чистых тонов. Можно подмешивать фрагменты зомби-исходников (мокрые призвуки).
5. **Игрок**: `player/hurt` — человеческий удар/хрип, не похожий на зомби; `player/heartbeat` — двойной
   удар «лаб-даб», луп 1 с. **UI**: щелчки из механики A2 (короткие, мягче), `deny` — глухой.
6. Метрики всех файлов + `design/tasks/reports/a4_waveforms.png` (+ спектрограммы) — посмотри сам.
   Отдельно склей `design/tasks/reports/a4_scene.wav` (20 с: луп орды + 30 стонов + очередь АК
   + 25 попаданий + 8 смертей + 2 гиба + сердцебиение) — чтобы человек мог послушать всё сразу.
   В репозиторий его не коммить: добавь в `.gitignore` строку `design/tasks/reports/*.wav`.
7. `sfx/CREDITS.md` — оба пака (авторы, ссылки, CC0) + таблица «файл ← исходник/синтез».
