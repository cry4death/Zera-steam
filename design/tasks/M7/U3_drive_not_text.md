# U3 — драйв вместо текста: меньше лишней информации, настоящие патроны в HUD

**Исполнитель:** Sonnet · **Уровень:** high · **Ветка:** `task/u3`
**Запрос автора (2026-10-18):** «убрать всякую реально ненужную информацию игроку, чтобы не было дохрена текста. Мы делаем
драйвовую, дофаминовую игру. Вместо блоков патронов — настоящие патроны, а не просто полоска».
Контекст: `design/tasks/M7/U1_unslop.md`, `design/tasks/reports/U2.md` (раздел «Спорное»), `design/GDD.md` (HUD, итоги).

## Принцип
Игрок в бою смотрит на орду, а не читает. На каждом экране оставь то, без чего **нельзя принять решение прямо сейчас**;
остальное — иконкой, числом, цветом, звуком или по наведению/в паузе. Награды и рост — ярко и коротко (крупное число,
отсчёт, щелчок), а не абзацем. Один экран — одна главная мысль.

## Параллельно идёт O2 — карты (ветка `task/o2`)
O2 правит `arena_layout.gd`, `obstacles.gd`, `ground.gd`, `spawner.gd`, `horde.gd`, `pickups.gd`, `game_camera.gd`,
`gen_art_obstacles.py` и подключение карт в `game.gd`. **Эти файлы не трогать**; в `game.gd` — только строки/тексты и
вызовы HUD, минимальными правками.

## 1. Настоящие патроны вместо полосы (`hud.gd`)
- В слоте ствола магазин — **ряд патронов-спрайтов**, по типу ствола: винтовочный/автоматный патрон, пистолетный, гильза
  дробовика (красная с латунью), батарея/заряд рейлгана, выстрел гранатомёта. Тип патрона (`s.ammo`: зажигательный,
  морозный и т.д.) — цвет пули/наконечника, редкий — свой отлив.
- Выстрел: крайний патрон **выщелкивается** (короткий подлёт и исчезновение, 0.15–0.25 с), не просто гаснет.
  Перезарядка: патроны **вщёлкиваются** по одному быстро слева направо (для дробовиков/револьверов — по одному с паузой,
  как настоящая зарядка; для магазинных — пачкой). Последние 20–25 % магазина — патроны краснеют/подсвечиваются.
- Большие магазины (30, 50, 71): плотный ряд мелких патронов в 1–2 строки или лента; отдельного числа «15/45» — только
  если ряд не читается (решай по скриншоту; число мельче, чем сейчас).
- Арт — новый `tools/gen_art_hud_ammo.py` (или в `gen_art_hud.py`) → `art/hud_round_*.png`, стиль игры; можно опереться
  на `art/casing_*.png`. Отрисовка — пакетом, без нод на патрон; FPS боя не хуже.

## 2. Текстовая диета
Пройди экраны и вырежи/сожми; каждое изменение — строка в отчёте «было → стало». Обязательно:
- **HUD:** коды пассивок «УРОН 2 / ТЕМП 1 / БРОНЯ 1» → значки с цифрой; плашка операции — крупно на 3–4 с при старте,
  потом свернуть в компактную строку «иконка угрозы + иконки модификаторов»; «ЦЕЛЬ: ОБЪЕКТ-7 64 %» — значок босса
  с полоской до его появления, без слов; метка «ТОРГОВЕЦ 5:00» → значок снабжения + время.
  Названия комбо («РЕЗНЯ!», «МЯСОРУБКА!»…) — оставить, это дофамин; сделать их сочнее (короткий удар масштаба/цвета),
  но без постоянной пульсации.
- **Level Up / снабжение / контейнер:** на карточке — пиктограмма, название и **одно** крупное число эффекта
  («+20 % урона»); описание и ранги — по наведению/стрелкам (уже частично в U1-14 — дожать).
- **Итоги/рапорт:** крупные числа с быстрым отсчётом и щелчками (убито, ДНК, время), множители — значками; блок
  последствий — 2–3 главных изменения иконками, полный журнал — по кнопке.
- **База:** описания стволов/черт/узлов дерева — одна строка, детали по наведению; убрать подсказки, которые повторяют
  очевидное.
- **Пауза:** зашитый «Карантинная зона · сектор 07» — убрать (или регион операции одной строкой).
- **Отладка:** строки «F1 +100 · F2 бессм. …» — только в отладочном режиме, не в обычной игре.
- Всё, что заметишь сам по этому принципу, — тоже.
