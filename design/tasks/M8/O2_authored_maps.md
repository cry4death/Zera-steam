# O2 — настоящие карты вместо случайной россыпи (система + первые 3 карты)

**Исполнитель:** Codex (при лимите — Sonnet) · **Уровень:** high · **Ветка:** `task/o2` (от main после U2 и C5)
**Запрос автора:** «надо сделать карты нормально, а не просто рандомно объекты на карте расставлять»; ранее — «потом разные
карты под регионы».
**Дизайн:** `design/CAMPAIGN.md` §5.2 (идентичность регионов), §11 (узлы); `design/IDEAS.md` §3–4; `design/tasks/M7/U1_unslop.md`
(без «ИИ-стиля»: никакой идеальной симметрии, повторяющихся шумов, игрушечной яркости).

## Сейчас

`scripts/arena_layout.gd` (O1) раскидывает объекты по сиду: машины в случайных точках двух полос, блокпосты в случайных
местах, 320 предметов мусора равномерно по всей арене. Пол — один тайл асфальта с разметкой крестом (`ground.gd`).
Нет ни зданий, ни тротуаров, ни логики «почему это здесь стоит». Любой регион — одна и та же арена.

## Цель

Каждая карта — **спроектированное место** с узнаваемой планировкой и ориентирами: игрок за 2–3 забега запоминает,
где заправка, где узкий проход, где можно увести орду по кругу. Сид меняет только детали (модели и состояние машин,
мусор, какие бочки стоят), **не планировку**.

## 1. Формат карты — авторские данные

- Карта — файл `maps/<id>.txt` (или `.json`; выбери и обоснуй): ASCII-план сеткой 32 px (80×45 для арены 2560×1440)
  слоем **земли** (`=` дорога, `-` разметка/переход, `.` тротуар, `,` трава, `:` грунт, `~` песок, `*` снег, `#` бетон
  площадок…) и слоем **твёрдых структур** (здания, стены, ограды — высокие, непроходимые), плюс список **сет-пьес** с
  позицией и поворотом и список **точек появления орды** (края улиц, проходы, ворота — а не кольцо вокруг игрока
  везде; кольцо остаётся запасным), точка старта игрока.
- Загрузчик `scripts/map_loader.gd` → тот же формат объектов, что сейчас отдаёт `ArenaLayout.generate` (машины, бочки,
  баррикады, мусор), плюс структуры и земля. `ArenaLayout` становится «расставить детали по сиду внутри сет-пьес».
- Размер карты — из файла (можно больше арены, если камера и орда это переносят; по умолчанию 2560×1440).

## 2. Сет-пьесы (готовые сценки) — `scripts/set_pieces.gd`

Каждая — маленькая осмысленная сцена, которую автор карты ставит одной строкой. Минимум:
- **пробка** (машины бампер к бамперу в полосе, часть дверей открыта, мусор вокруг);
- **авария** (2–3 машины под углом, одна горящая/сгоревшая, стекло и обломки);
- **КПП** (джерси в шахматку, мешки, будка, полицейская/военная машина, конусы, шлагбаум);
- **заправка** (навес, колонки, красные бочки/цистерна — взрывоопасная точка);
- **парковка** (ряды машин по разметке, пара пустых мест);
- **стройка** (забор-сетка, доски, козлы, конусы);
- **полевой пост** (мешки полукругом, военный грузовик, ящики);
- **автобусная остановка / киоск**;
- **контейнеры** (ряды морских контейнеров — высокие, проходы между ними).
Мусор кладётся **по смыслу**: у бордюров, вокруг аварий и контейнеров, у остановок — а не равномерно.

## 3. Земля и здания — арт

- `tools/gen_art_map.py` (поверх `gen_art` как `ga`, детерминированно): тайлы земли с **переходами** (бордюр
  дорога/тротуар, край травы/грунта/песка/снега), разметка, пешеходные переходы, люки, трещины, пятна масла;
  крыши зданий вида сверху (плоские крыши с парапетом, вентиляцией, кондиционерами, люками; разные размеры
  собираются из частей, без одинакового повтора), стены/ограды, будка КПП, навес заправки, морские контейнеры, цистерна.
  Сохраняй стиль арены: тёмный приглушённый пиксель-арт, свет сверху-слева. Повтор тайлов — не бросаться в глаза
  (варианты, поворот, декали).
- Отрисовка земли — **запечь один раз** при загрузке (чанки-текстуры), в кадре — несколько спрайтов, не тысячи.
- Здания и контейнеры — препятствия как в O1 (высокие, останавливают пули, кровь на стенах с краю).

## 4. Первые три карты (остальные — O3)

| Карта | Регион | Что это | Ориентиры |
|---|---|---|---|
| `quarantine_checkpoint` | Восточная Европа | трасса через КПП карантина, колонна военной техники, полевые укрепления, перелесок | КПП посередине, колонна грузовиков, разбитая заправка у дороги |
| `old_town` | Западная Европа | плотная застройка, узкие улицы, площадь с фонтаном/памятником, двор-колодец | площадь — единственное открытое место; переулки, где орда идёт гуськом |
| `open_perimeter` | Северная Африка | песок, разбитая дорога, редкие руины, длинные линии обзора, заброшенный лагерь | лагерь в центре, остовы техники по дороге, горизонт без укрытий |

У каждой — 2–4 зоны с разным характером (открытое / узкое / укрытие), минимум один «круг», по которому можно водить
орду, и никаких закрытых карманов (проверка связности как в O1). Свободная вылазка — `quarantine_checkpoint`.

## 5. Подключение

- `game.gd`: карта по `mission_config.region_id` (таблица регион → карта; регионы без своей карты пока — ближайшая по
  духу из трёх); флаг `--map=<id>` для тестов; сид операции → детали.
- Спавн орды — из точек появления карты, ближайших к игроку за краем экрана; кольцо — запасной вариант.
- Дроп/ящики/контейнер тревоги/граната — не в структурах (как в O1).

## Производительность

`--loadout --bench=500` на каждой из трёх карт против `--no-obstacles` того же билда (пара подряд через
`godot_exclusive.sh`): avg_fps не ниже −5 %, worst_ms не хуже, загрузка карты < 0.5 с. Попутно закрыть хвост O1b
(`reviews/O1.md`): `physics_avg_ms` с препятствиями +10 мс — профилировать `Obstacles.move_actor/resolve`, `ray_hit`.

## Проверка

- `--map-test` (headless): каждая карта грузится, связна, старт свободен, точки появления вне структур, один сид →
  одна раскладка деталей, разные сиды → та же планировка; 60 с с 500 зомби — 0 проникновений.
- Скриншоты (оконные, через блокировку): `o2_<map>_overview.png` (вся карта уменьшенно) и `o2_<map>_fight.png`
  (бой с ордой) для каждой из трёх; лист `o2_tiles.png`. **Посмотри сам**: карта должна читаться как место, а не как
  россыпь; повтор тайлов не виден.
- `--campaign-test`, `--meta-test`, `--sim=600`, `--fresh-save --obstacles-test` — без ошибок.
