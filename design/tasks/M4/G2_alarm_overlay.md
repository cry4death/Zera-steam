# G2 — alarm_overlay.gd: экран «Кровавой тревоги»

**Исполнитель:** ChatGPT · **Результат:** один файл `alarm_overlay.gd` → сохранить в `GameZ/tasks/inbox/G2/alarm_overlay.gd`

---

Ты пишешь один самостоятельный скрипт для игры на **Godot 4.7** (GDScript 2.0).
Игра — top-down пиксельный зомби-шутер (Vampire Survivors + много крови), экран 1920×1080.
Код проекта ты не видишь — ниже всё, что нужно. **Не выдумывай методы проекта.**

## Что это за событие

На 7:00 забега начинается **Кровавая тревога**: 3 секунды предупреждения (сирена), затем 30 секунд
мир заливает красный свет, зомби лезут втрое гуще, опыт и кредиты ×2. Это кульминация середины
забега — экран должен давить и пугать, но **не мешать играть**: центр экрана, где игрок и орда,
должен оставаться читаемым.

## Правила кода

- GDScript со статической типизацией, отступы — **табы**, комментарии по-русски коротко.
- Всё рисуется в `_draw()` одной нодой, без дочерних нод, без шейдеров (можно `GradientTexture2D`,
  созданную один раз в `_ready`). **Нельзя `draw_circle`** (очень медленный в этой версии).
- Не больше ~20 вызовов `draw_*` за кадр, без аллокаций в `_draw`.
- Текст в нашем проекте рисуется так (стиль HUD — скопируй этот подход):

```gdscript
var _ui := 3.0   # «игровой пиксель»: экран делится на ~360 строк по высоте

func _draw() -> void:
	_ui = maxf(1.0, roundf(size.y / 360.0))
	draw_set_transform(Vector2.ZERO, 0.0, Vector2(_ui, _ui))
	var w := size.x / _ui   # ширина в игровых пикселях (~640)
	var h := size.y / _ui   # ~360
	# ... прямоугольники и полосы рисуются в игровых пикселях ...

func _text(font: Font, p: Vector2, s: String, c: Color, fs: int) -> void:
	# текст — в полном разрешении (чёткий), позиция в игровых пикселях
	draw_set_transform(Vector2.ZERO)
	var k := int(_ui)
	draw_string_outline(font, p * _ui, s, HORIZONTAL_ALIGNMENT_LEFT, -1, fs * k, 2 * k, Color(0, 0, 0, 0.8 * c.a))
	draw_string(font, p * _ui, s, HORIZONTAL_ALIGNMENT_LEFT, -1, fs * k, c)
	draw_set_transform(Vector2.ZERO, 0.0, Vector2(_ui, _ui))

# шрифт: ThemeDB.fallback_font; ширина строки: font.get_string_size(s, HORIZONTAL_ALIGNMENT_LEFT, -1, fs).x
# размеры шрифта в игровых пикселях: обычный 10, крупный 16–20
```

- Только кириллица/латиница/цифры/обычная пунктуация в текстах — без эмодзи и спецсимволов (⚠ и т. п.
  в шрифте может не быть).
- Отдай **файл целиком**, одним блоком.

## Контракт (строго)

```gdscript
class_name AlarmOverlay
extends Control

func warn(seconds: float) -> void   # фаза предупреждения
func start(seconds: float) -> void  # фаза тревоги, seconds — длительность
func finish() -> void               # тревога отбита: надпись + плавное угасание ~1.5 с, потом скрыться
func stop() -> void                 # мгновенно скрыть всё (рестарт)
func is_active() -> bool            # идёт warn или start
```

- В `_ready`: на весь экран (`set_anchors_preset(Control.PRESET_FULL_RECT)`),
  `mouse_filter = Control.MOUSE_FILTER_IGNORE`, `visible = false`.
- Время считается в `_process(delta)` — пауза игры его останавливает (это и нужно).
- Скрыт, когда ничего не идёт (`visible = false` и не тратит кадр).

## Как должно выглядеть

**warn (3 с):**
- Сверху и снизу — полосы «опасность» (диагональные красно-чёрные полосы высотой ~10 игровых
  пикселей), медленно едут; въезжают за 0.25 с.
- По центру **верхней трети** (не в центре экрана!) — надпись `КРОВАВАЯ ТРЕВОГА` крупно,
  мигает в такт сирене (~2 раза в секунду, жёсткое мигание, не плавное), под ней
  `через 3`, `через 2`, `через 1` — обратный отсчёт целыми секундами.
- Края экрана коротко вспыхивают красным в такт миганию.

**start (30 с):**
- Красная виньетка по краям экрана: центр прозрачный, края — тёмно-красные (`Color(0.55, 0.0, 0.02)`
  с альфой ~0.45 у самого края). Пульсирует **как сердцебиение**: двойной удар «тук-тук… тук-тук»
  примерно раз в 1.1 с; последние 5 с тревоги — чаще (≈ раз в 0.6 с).
- Сверху по центру: `КРОВАВАЯ ТРЕВОГА` (не мигает, тёмно-красная с ярким контуром) и полоса
  оставшегося времени шириной ~160 игровых пикселей, под ней мелко `опыт и кредиты x2` и
  оставшиеся секунды `0:23`.
- Полосы «опасность» уезжают за 0.4 с в начале фазы.
- Первую 0.3 с — общая красная вспышка на весь экран (альфа до 0.25, спад).

**finish:**
- Виньетка гаснет за 1.5 с, надпись `ТРЕВОГА ОТБИТА` (золотистая `Color(1.0, 0.82, 0.35)`)
  в верхней трети, лёгкое увеличение и исчезновение за 1.5 с. Потом `visible = false`.

## Палитра

Тёмно-красный и чёрный, «засохшая кровь», не неон. Белый/золотой — только для текста результата.
Альфа элементов в центральной области 60% экрана — не больше 0.12.
