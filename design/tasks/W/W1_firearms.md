# W1 — настоящий огнестрел: новые стволы, звук, отдача, свет вспышек, гильзы

**Исполнитель:** Codex · **Уровень:** high (горячий код `weapons.gd`, несколько систем) · **Ветка:** `task/w1`
**Зависит от:** A1 (звуки выстрелов в `sfx/`), S3 (в main). A2 (механика) может прийти позже —
код должен заработать с ней без правок (по именам из контракта), а без неё — молча.
**Контракты:** `CONTRACTS.md` §9 (имена звуков), §10 (`Sfx` — создаёшь ты).
**Цифры:** `BALANCE.md` §3 (формула эфф. DPS и ориентиры).

## Цель

Стрельба должна ощущаться как настоящая: у каждого ствола свой голос (реальные записи),
своя отдача, вспышка света, которая на миг освещает орду, гильзы со звоном летят в сторону
и **остаются лежать** на асфальте. Плюс 4 новых ствола без футуристики.

## 2. Звук (`scripts/sfx.gd`, CONTRACTS §10)

- Узел `Sfx` в `main.tscn`, ссылка в `weapons`, `player`, `effects` (как остальные ссылки).
- `default_bus_layout.tres`: `Master` (Limiter/Compressor — 15 выстрелов/с не должны клиппить),
  `Weapons`, `World`. Подключи в `project.godot`.
- Выстрел игрока — без позиционирования; гильзы, магазины, взрывы — `AudioStreamPlayer2D` в точке.
- Пул голосов, лимиты: на `id` полифония и мин. интервал (ППШ — каждый выстрел, но не больше
  ~6 одновременных хвостов; гильзы — не больше ~10/с суммарно, остальные молча).
- Питч ±3–5% и громкость ±1.5 дБ на каждый выстрел, без повторения одного варианта подряд.
- Механика по действию ствола (если файлы есть — иначе тишина):
  - магазинные (пистолет, ППШ, АК-С): начало перезарядки → `mag_out` + **пустой магазин падает на
    пол и остаётся** (`casings/mag_drop`); ~70% → `mag_in`; конец → `rack`. Последний патрон → `dry`.
  - Мосинка: после каждого выстрела через ~0.3 с `rack` (затвор) и в этот момент вылетает гильза.
  - «Мясник» (помпа): после выстрела ~0.25 с `rack` (цевьё) + вылетает красная гильза;
    перезарядка — `shell_in` по одному патрону, равномерно по времени перезарядки.
  - «Бульдог»: при выстреле гильза **не** вылетает; перезарядка → `cyl_open`, `eject` + 6 гильз
    высыпаются у ног, `load`, `cyl_close`.
- Взрывы гранаты (активка) и «Грома» → `explosions/grenade`.
- Тесты и `--headless` — без звука и без ошибок.

## 3. Отдача

- `GameCamera.kick(dir: Vector2, amount: float)` — направленный толчок камеры **против** выстрела
  с пружинным возвратом ~0.1 с, отдельно от случайной `shake`; накопление ограничено
  (ППШ «дрожит», а не уезжает). Сила по калибру: ППШ < пистолет < АК < Бульдог < «Мясник» < Мосинка.
  Мосинка/«Мясник» — ещё короткая `shake`.
- `player.kick(strength)` — спрайт/ствол бойца откатывается назад по `-aim_dir` на силу отдачи и
  возвращается (сейчас `kick()` без параметров — сохрани совместимость).
- Разброс очереди: у ППШ и АК-С каждый выстрел подряд добавляет разброс (до предела), без стрельбы
  он быстро возвращается. Это должно быть видно по веру трассеров на скриншоте.

## 4. Вспышка и свет

- Дульная вспышка: процедурная (как сейчас в `_draw`), но своя форма по стволу — пистолет
  маленькая звезда, АК — с боковыми «ушами» дульного тормоза, ППШ — частые мелкие с кожухом,
  «Мясник» — широкий конус, Мосинка — огромная вспышка + кольцо дыма, Бульдог — короткий
  тяжёлый «блин». Форма/поворот случайны на каждый выстрел, жизнь 1–3 кадра (40–70 мс).
  Цвет по патронам (зажигательные — оранжево-красный, крио — голубой).
- **Свет:** пул `PointLight2D` (≤ 6, не нода на выстрел), радиальная текстура генерится в коде,
  тёплый свет (≈ 1.0, 0.78, 0.45), энергия и радиус по калибру, быстрое затухание с мерцанием.
  Свет реально освещает пол и зомби вокруг бойца (проверь на скриншоте: кадр со вспышкой
  заметно светлее вокруг). Взрывы — большой оранжевый свет ~0.15 с.
- Дымок: маленький клуб из ствола после выстрела, после длинной очереди ППШ/АК — тонкая струйка.

## 5. Гильзы и магазины на полу

- `Effects.casing(origin, dir, kind)` — гильза вылетает **вправо от ствола** (с учётом направления
  выстрела) и чуть назад, крутится, летит по высоте с гравитацией (тень на полу), 1–3 отскока
  с потерей скорости, проскальзывает и **ложится**: после остановки «запекается» в пол
  (`floor_decals.stamp`) и живёт до конца забега. Виды: `brass_small` (пистолет, ППШ, Бульдог),
  `brass_rifle` (АК, Мосинка — длиннее), `shell` (дробовик — красная с латунным донцем).
- Звук гильзы при первом касании пола (лимит из §2); на мокром полу (`floor_decals.is_wet`) —
  тише и ниже.
- Пустой магазин: тёмный прямоугольник, падает у ног, отскок, звук, запекается.
- Спрайты гильз/магазина — новый `tools/gen_art_w1.py` (поверх `gen_art`, как `gen_art_m4.py`) →
  `art/casing_small.png`, `casing_rifle.png`, `casing_shell.png`, `mag_*.png` (пара пикселей
  в масштабе игры, латунь с бликом, читаются на асфальте и на крови).
- Производительность: гильзы — Packed-массивы в `effects` (или своём узле), запекание пачками;
  при 15 выстр/с ППШ + 4 ствола одновременно не должно проседать (см. «Проверка»).
