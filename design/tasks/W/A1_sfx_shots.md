# A1 — звуки: выстрелы реальных стволов, гильзы, взрывы

**Исполнитель:** Codex · **Уровень:** high · **Ветка:** `task/a1` (worktree)
**Контракт:** `CONTRACTS.md` §9 (имена, формат — строго).

## Цель

В игре нет ни одного звука. Нужна основа «я воюю»: выстрелы шести настоящих стволов из
CC0-библиотеки, звон гильз, взрыв гранаты. Механику (магазины, затворы) делает A2 позже —
сделай скрипт так, чтобы A2 дописал свой раздел, не переписывая твой.

## Сделать

1. `tools/prep_sfx.py`: путь к исходникам — аргумент `--src` (по умолчанию папка выше), выход — `sfx/`
   рядом со скриптом (`--out` для проверок). Детерминированно (`random.Random(seed)`/`numpy` с seed).
   Структура: общие функции (чтение 24-бит, ресемплинг 96→48 кГц с антиалиасинговым FIR,
   нарезка по атакам, фейды, нормализация, запись 16-бит) + раздел «выстрелы» + раздел «синтез» +
   пустой раздел-заглушка `mechanics()` для A2 с комментарием, что туда пойдёт.
2. **Выстрелы** `weapons/<gun>/shot_<n>.wav`: 3–6 вариантов на ствол. Источник вариантов — разные
   выстрелы внутри near-файлов (у автоматов — отдельные выстрелы, вырезанные из очередей, если они
   чистые; у одиночных — дубли + лёгкая вариация: ±3% питча и EQ-наклон). Атака не срезана
   (0.5–2 мс предзахвата), хвост по контракту, мягкий фейд-аут, без щелчков, без DC.
   Для ППШ/АК вариант должен звучать хорошо, когда его повторяют 10–15 раз в секунду
   с наложением (короткий хвост, проверь сам «очередью» — склей тест-очередь в `tmp/`).
3. **Синтез** (качество важно — это не «бипы»):
   - `casings/brass_small_*`, `brass_rifle_*` — латунная гильза падает на асфальт: модальный синтез
     (3–6 неравномерных затухающих частот металлического цилиндра, 3–9 кГц у мелкой, ниже у
     винтовочной), 2–3 отскока с убывающей громкостью и сокращающимися интервалами, лёгкий
     шорох-«прокат» в конце. ≥ 6 вариантов каждого.
   - `casings/shell_*` — пластиковая гильза дробовика: глуше, «тук» с латунным донцем.
   - `casings/mag_drop_*` — пустой магазин о асфальт: тупой удар + дребезг.
   - `explosions/grenade_*` — взрыв: суб-удар (40–80 Гц), шумовой взрыв с огибающей, хвост-раскат,
     немного «осыпи». ≥ 4 варианта. Можно подмешать низ из записей выстрелов, замедленных.
   - `weapons/launcher/shot_*` — хлопок гранатомёта (замедленный/фильтрованный дробовик + «туп»).
   - `weapons/rail/shot_*` — рельса: электрический треск + хлыст, коротко.
4. **Громкость** по контракту §9 (пики ≤ −1 dBFS, порядок «калибров»). Напиши в скрипте таблицу
   целевых уровней.
5. `sfx/CREDITS.md` — лицензия CC0, авторы, ссылка https://opengameart.org/content/the-free-firearm-sound-library,
   таблица «файл ← исходник/синтез».
6. Импорт в Godot: `--headless --path . --import` без ошибок. Выбери настройки импорта WAV
   (`.import`): выстрелы и взрывы — сжатие QOA, без лупа; закоммить `.import` вместе с WAV.
7. **Прослушать по-честному**: ты не слышишь, поэтому проверь численно и визуально — для каждого
   файла выведи длительность, пик, RMS первых 100 мс, спектральный центроид, наличие клиппинга, DC;
   сохрани в `design/tasks/reports/a1_waveforms.png` осциллограммы + спектрограммы всех `shot_0`,
   одной гильзы каждого типа и взрыва. Посмотри картинку сам и поправь, если что-то не так
   (обрезанная атака, обрыв хвоста, тишина в начале, щелчок на конце).
