# S4 — Босс в игре и финал забега

**Исполнитель:** Sonnet 5.5 · **Уровень:** high · **Ветка:** `task/s4` (от main после S3, G4, G5, G6)
**Контракты:** `CONTRACTS.md` §6–8. **Цифры:** `BALANCE.md` §7.1 (строки 9:30, 10:00), §10, §11.1.

## Цель

Забег получает конец: предупреждение в 9:30, босс в 10:00, бой, огромный взрыв плоти, экран
итогов с ДНК — или смерть и тот же экран. «Ещё раз» перезапускает забег.

## Сделать

1. **Появление:** 9:30 — анонс «ОБЪЕКТ-7 ПРИБЛИЖАЕТСЯ» + тряска + низкий гул (звука пока нет — только
   визуал); спавнер по BALANCE §7.1 (4/с, лимит 150, 70/30). 10:00 — босс выходит из-за края экрана
   на стороне, противоположной движению игрока. Нода `World/Boss` (над ордой).
2. **Оружие бьёт босса:** все виды урона из `weapons.gd` — пули (с пробитием/рикошетом), рельса,
   гранаты/взрывы, цепь, осколки, огонь (горение босса — тиками, без статуса орды) — проверяют
   `boss.hit_test` и зовут `boss.take_damage`. Автоприцел: босс — цель с приоритетом, если ближе
   ближайшего зомби ×1.5. Не сломать поведение против орды. Это горячий код: замерь `--bench`.
3. **Сигналы босса:** `roar` → бегуны вокруг босса; `crushed` → декаль `crushed_N` по направлению
   + брызги; `armor_plate` → гиб-пластина в `gore`; `charge_telegraph`/`slam_started` → тряска.
4. **HUD:** полоса HP босса внизу над слотами оружия: имя, полоса, отметка 50%, вспышка при фазе 2.
5. **Смерть босса:** хит-стоп 0.15 с, медленное время 0.6 с, гибы `boss_gib_*` + пластины + обычное
   мясо на весь экран, 6–8 больших луж, `screen_blood.splash` сильный, орда в радиусе 200 — в кашу.
   Через 2.5 с — экран итогов (победа), военный ящик `military_crate` падает на месте смерти
   (засчитывается сразу, подбирать не нужно — отметь анимацией).
6. **Итоги и ДНК (MVP §10):** `минуты × 10 + убийства / 50 + элитки × 5`, победа ×1.5 — строки
   `dna_lines`. «Литры крови» — из уже существующей статистики крови (если её нет — оценка по
   числу пятен/луж, опиши формулу). Смерть игрока → тот же экран (`victory = false`).
   `restart_requested` → `get_tree().reload_current_scene()`.
7. **Тест-режим `--boss`:** старт в 9:55 с `--loadout`, бессмертие, автопилот; печать раз в секунду
   `BOSS t=.. hp=.. phase=.. fps=..`, скриншоты `_phase1.png`, `_phase2.png`, `_death.png`,
   `_results.png` по `--shot`. Должен доходить до победы сам.

## Критерии приёмки
- [ ] `--boss` доходит до победы; время боя с `--loadout` 50–90 с (BALANCE §10: ~79 с без меты).
- [ ] Оружие против орды не изменилось: `--bench=500` horde_ms/physics_ms в пределах +10% от baseline.
- [ ] Худший кадр в смерти босса < 33 мс.
- [ ] Скриншоты фаз, смерти и итогов — читаемые, мясные.
- [ ] Отчёт `reports/S4.md`.
