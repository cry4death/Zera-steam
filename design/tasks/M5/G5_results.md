**Контракт:** `CONTRACTS.md` §8 — строго. **Замысел:** `MVP.md` §10 («ДНК выводится построчно, как чек»).

## Прочитай (только чтение)

`zera/scripts/level_up.gd` и `zera/scripts/trader_ui.gd` — стиль экранов (игровые пиксели `_ui`,
текст в полном разрешении с обводкой, палитра, ввод на паузе). Делай так же.

## Как выглядит

Полупрозрачное тёмное затемнение мира, по центру — «чек»-панель ~260×300 игровых px:
1. Заголовок: **ОБЪЕКТ-7 УНИЧТОЖЕН** (золото) при победе / **ВЫ ПОГИБЛИ** (тёмно-красный) при смерти.
2. Блок статистики (подпись слева, значение справа, точки-лидеры между ними):
   время `9:42`, убито, элиток, лучшая серия, литров крови (`%.1f л`), ящиков (обычных / военных).
3. Собранные стволы — строки из `weapons`.
4. Разделитель «— ДНК —», затем `dna_lines` по одной строке **с задержкой ~0.25 с** (печать чека,
   значения «досчитываются» от 0 за 0.3 с), строка `× 1.5 победа` если `dna_mult > 1`, жирная
   итоговая строка `ИТОГО ДНК`.
5. Кнопка **ЕЩЁ РАЗ** + подсказка `R / Enter`. Пока чек печатается, Enter/клик сначала мгновенно
   допечатывает, второе нажатие — рестарт.

Длинный список стволов/строк не должен вылезать за панель (уменьшение шрифта или две колонки).
