# C5 — экран «Операции»: разгрузить интерфейс и довести глобус

**Исполнитель:** Codex · **Уровень:** high (UI + шейдер, художественное качество) · **Ветка:** `task/c5`
**Запрос автора:** «сделай лучше интерфейс и карту, что там задумывалось по ней. Интерфейс очень плотный».
**Дизайн:** `design/CAMPAIGN.md` §4 (глобус, компоновка, семантика цвета, анимации), §14 (брифинг), §22.2–22.3 (визуал
глобуса); `design/tasks/reports/U1.md` и `U1_audit.md` — **что автор считает «ИИ-стилем» и уже убрал; не возвращать**.

## Что не так сейчас (скриншот автора — как `design/tasks/reports/c4_globe_east_europe.png`, после U1)

- Глобус маленький (~55 % высоты центра), вокруг пустая чернота; пятна заражения — размытые круги, а не области.
- Подписи всех 8 регионов сразу, с выносками — каша вокруг шара.
- Правая панель — стена текста из 10+ строк в 5 цветах (красный, зелёный, оранжевый, белый, серый): угроза,
  реплика, модификаторы, награда, эффект, перерасчёт, провал, улей — всё одного веса.
- Левая панель дублирует: сводка + 4 фильтра + 3 карточки заданий, каждая в 3 строки.
- Нижняя строка подсказок по всей ширине; верхняя полоса базы тяжёлая (оставить как есть — общая для всех вкладок).

## Сделать

### 1. Компоновка (base.gd, вкладка OPERATIONS)
- **Глобус — главный.** Заметно крупнее: по высоте почти всё поле между вкладками и нижней кнопкой, может уходить
  под края боковых панелей. Боковые панели уже и легче (меньше рамок, больше воздуха).
- **Слева** — только список операций: компактные строки «[1] Зачистка · II — Восточная Азия» (название операции
  одной строкой мельче/по наведению). Сводка хода — одна строка над глобусом или над списком: «Ход 0 · очагов 1 ·
  критических 1». Фильтры — убрать из постоянного вида (оставить клавиатурой/геймпадом или маленьким переключателем,
  если без них теряется функция; обоснуй в отчёте).
- **Справа — брифинг по §14, но иерархией, а не стеной:**
  - заголовок операции, под ним регион и состояние одной строкой;
  - тип + угроза: угроза — 5 делений (заполнено N), а не «IV / V» текстом;
  - реплика Диспетчера — одна строка, приглушённо;
  - «Условия» — модификаторы списком по одной короткой строке;
  - «Итог» — 2–3 строки: победа (эффект + награда), провал; «обстановка обновится во всех регионах» — мелкой
    подписью или подсказкой, не отдельной строкой цвета;
  - журнал причин региона — свернут, открывается кнопкой/клавишей.
  - Цвета: один акцент для важного (состояние/угроза), остальное — 2 оттенка нейтрального текста. Зелёный/красный —
    только для «победа/провал», и то приглушённо.
  - Кнопка «Начать операцию» — внизу панели, как сейчас.
- Нижняя строка подсказок — короче (глифы клавиш, только то, что нужно на этом экране), или показывать по наведению.
- Всё должно влезать в 1920×1080 и 1280×720 без наложений; шрифты — существующие, размеры — не меньше текущих мелких.

### 2. Глобус (scripts/ui/globe_view.gd + шейдер)
По §4.1: «стилизованный военный тактический дисплей: тёмно-серый материк, глубокий океан, полупрозрачные зоны
заражения, локальные пульсы и простые метки». Из §22.3 сделать:
- **Области вместо кругов.** Заражение — мягкая область, повторяющая сушу региона (маска регионов: каждому пикселю
  карты — ближайший центр региона по сфере среди суши, граница с шумом; можно запечь `art/globe_regions.png`
  генератором `tools/gen_art_campaign.py` из Natural Earth), цвет стадии, плотнее к центру очага. Океан не
  закрашивается. Тонкие границы регионов.
- **Маршруты распространения** между соседями (`neighbors` в `campaign_catalog.gd`): дуги по поверхности сферы,
  видны только от заражённых/критических к более слабым; спокойные, без «неоновых» бегущих огней (допустимо медленное
  смещение штриха).
- **Ульи** — отдельный знак и тёмно-пурпурная область, без свечения-ореола.
- **Ночная сторона** — лёгкое затемнение с огнями уцелевших городов (точки на суше удерживаемых регионов,
  меньше в заражённых); читаемость меток не страдает.
- **Свет и край шара** — мягкий объём (ламберт + тонкий край атмосферы), без bloom.
- **Подписи:** постоянно видны только регионы с операциями (номер + короткое имя) и выбранный; остальные — на
  наведении/выборе. Выноски — только если без них подпись уходит от метки.
- **Приближение к операции:** при выборе — доворот и небольшой зум к региону (пропускаемо, §4.5).
- Холостое медленное вращение, когда игрок не трогает глобус (выключается настройкой «Анимации глобуса» / уже
  существующей, если есть; иначе — константа).

### 3. Картинки вместо текста (уточнение автора: «больше картинок, а то один текст»)
Новый генератор `tools/gen_art_ops.py` (поверх `gen_art` как `ga`, детерминированно, стиль игры: тёмный
приглушённый пиксель-арт, свет сверху-слева, без неона) → `art/ops_*.png`:
- **Иконки типов операций** (зачистка, удар по улью, остальные из `campaign_catalog.gd`) — в списке слева и в брифинге
  вместо слова или рядом с коротким словом.
- **Иконки модификаторов** (плевальщики/кислота, броня босса, бегуны, элитки и все прочие из каталога) — строка
  «Условия» = иконка + 2–4 слова. Где модификатор про врага — силуэт этого врага из `art/zombie_atlas.png`/босса.
- **Иллюстрация региона** в шапке брифинга — небольшой пиксельный кадр-«снимок разведки» (≈ 160×64 в масштабе
  базы) по характеру региона (`traits`/`asset`: мегаполис, лаборатории и мороз, промзона, пустыня/открытый периметр,
  автомагистрали, транспортный узел, полевые укрепления, город) с тоном заражения по стадии. 8 штук.
- **Портрет Диспетчера** (маленький, у его реплики) — вместо слова «Диспетчер:».
- **Награда и эффект** — иконками: ДНК (`dna`-иконка из HUD/базы), ящик (`hud_crate`/`military_crate`), стрелки
  заражения вниз/вверх с числом, иконка соседних регионов.
- **Угроза** — 5 делений-черепов/шевронов, а не текст.
- Лист `design/tasks/reports/c5_icons.png` (×4) — посмотри сам, каждая иконка понятна без подписи.
Текст остаётся только там, где без него не понять (название, числа, короткие подписи).

### 4. Чего НЕ делать (U1, решение автора)
Неон, градиенты и свечение без причины, стеклянные панели, сканлайны, декоративные уголки, бесконечно мигающие
элементы, хроматическая аберрация. Пульс — только у критических (как в §4.4), редкий.
