# C3 — глобус: вкладка «ОПЕРАЦИИ» на базе, брифинг, сводка после боя

**Исполнитель:** Codex / Sonnet · **Уровень:** high (3D в 2D-интерфейсе, UX) · **Ветка:** `task/c3` (от main после C1)
**Дизайн:** `design/CAMPAIGN.md` §4, §14, §15, §22, §24. **Контракт:** `CONTRACTS.md` §15, §17.

## Цель

Открываешь базу — видишь вращающуюся заражённую Землю, три мигающие операции, выбираешь одну за секунды, читаешь
коротко «что, насколько опасно, что дадут, как изменится мир» и уходишь в бой. После боя — видишь, как мир изменился.

## Сделать

1. **Текстура Земли** — новый `tools/gen_art_campaign.py`: из `C:\Users\Dev\Desktop\zera-assets\naturalearth\ne_50m_land.geojson`
   (public domain, `SOURCE.md` рядом) — равнопромежуточная карта 2048×1024: тёмный океан, тёмно-серые материки с
   тонким светлым контуром, лёгкая сетка широт/долгот; без фото. Вывод `art/globe_land.png` (+ `art/globe_credits.txt`).
   Natural Earth упомянуть в `sfx/CREDITS.md`-подобном файле `art/CREDITS.md` (создать).
2. **Глобус** — `scenes/globe_view.tscn` + `scripts/ui/globe_view.gd`: `SubViewport` со `SphereMesh`, камера, мягкий свет;
   шейдер поверх текстуры рисует **зоны заражения** — мягкие пятна вокруг центров регионов цветом этапа (§4.4),
   пульс у критических, у живого улья — свой знак/свечение. Вращение ЛКМ-перетаскиванием и левым стиком, колесо —
   масштаб, доворот к выбранному региону (метка с обратной стороны автоматически поворачивается к зрителю).
   Метки операций — 2D поверх (проекция lat/lon → экран), экранный hit-test без коллайдеров, отсев за горизонтом,
   форма метки + текст, не только цвет (§4.4, §24). Пока вкладка не открыта и в бою — глобус не рендерится.
3. **Вкладка «5 ОПЕРАЦИИ»** в `base.gd`: слева — ход, «очагов активно», «регионов в критическом», фильтры (Все/Критические/
   Доступные/Ульи); центр — глобус; справа — карточка выбранного региона и **одной** раскрытой операции (брифинг §14.1:
   цель, особые условия, угроза I–V, награды, «Прямой эффект: −28; затем перерасчёт фронта», цена ошибки текстом).
   «НАЧАТЬ ОПЕРАЦИЮ» → `Campaign.start_operation` → бой. Кнопка «В БОЙ» внизу базы остаётся — это **свободный забег**
   (подпиши «свободный забег — мир не меняется»). Геймпад: крестовина по меткам, A — выбрать/начать, B — назад.
4. **Сводка после боя** (`run_results.gd`): если забег из кампании — блок «ПОСЛЕДСТВИЯ»: 2–3 главных изменения
   (`Campaign.last_report()`), «Активных ульев: N», кнопки «К КАРТЕ ОПЕРАЦИЙ» / «БАЗА». На глобусе при возврате —
   короткая подсветка изменённых регионов (пропускаемая). Журнал причин — по клику на регион в карточке (§15.2).
5. Звук: щелчки UI — существующие `ui/*`; «сигнал» при выборе критической операции — переиспользовать механику/синтез,
   новых файлов не делать. Настройка «уменьшить движение» (пульсы/автоповорот) — в экран настроек S7.
6. **`--globe-test`** (оконный, временное сохранение): скриншоты `_globe.png` (вид Земли с зонами), `_card.png` (брифинг),
   `_back.png` (регион с обратной стороны после автоповорота), `_results.png` (сводка после симулированной операции).
   Посмотри все сам — читаемо, не налезает, в стиле игры (тёмный военный дисплей, не «синий шарик из учебника»).

## Критерии приёмки
- [ ] Вращаемая Земля с зонами заражения и метками операций, доворот к выбранной, мышь и геймпад.
- [ ] Брифинг честно показывает цель, риск, награды, прямой эффект и перерасчёт.
- [ ] Запуск операции → бой → сводка последствий → глобус с подсветкой изменений.
- [ ] Свободный забег остаётся; бой не теряет FPS из-за глобуса. Отчёт `design/tasks/reports/C3.md`.

## Тон (решение автора)

Игрок — оперативник организации **Z.E.R.A.**, а не последний выживший: тексты интерфейса, названия операций,
брифинги, баннеры и сводки — в тоне `design/SETTING.md` (Диспетчер, «операция», «объект», «рапорт», коротко и сухо).
