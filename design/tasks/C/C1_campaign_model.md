# C1 — модель глобальной кампании: регионы, заражение, операции, единое завершение

**Исполнитель:** Codex · **Уровень:** high (детерминизм, миграция сохранения, транзакция) · **Ветка:** `task/c1`
**Дизайн:** `design/CAMPAIGN.md` (§5–8, §13, §17, §18, §19, §20, §26.1–26.2). **Контракт:** `CONTRACTS.md` §15–17.
Это **этап А + В** плана §25: чистая модель без глобуса + единый commit. UI (глобус) — C3, бой — C2.

## Сделать

1. `scripts/campaign/campaign_catalog.gd`, `campaign_rules.gd`, `campaign_director.gd`, `campaign.gd` по §15.
   Все стартовые числа — в одном словаре `CampaignCatalog.BALANCE` (рост, давление соседей/улья, подавление,
   эффекты исходов, пределы, веса угрозы, бонусы наград). Граф соседства — только явные рёбра (§5.3), проверка
   симметрии в тесте.
2. **Правила хода** — строго §7.2–7.3, одновременный пересчёт из снимка, независимость от порядка обхода,
   `clamp 0..100`, предел роста за ход, подавление без ошибки на единицу (определи соглашение и задокументируй
   в комментарии + тест ходов 1/2/3), уничтоженный улей не даёт давления и не воскресает.
3. **Генератор предложений** §8.1–8.3: 3 операции, квоты разнообразия, всегда хотя бы одна доступная (угроза ≤ II),
   детерминированно из `seed`/`turn` (перезагрузка не перекатывает набор), предложения живут до следующего
   завершённого забега, улей `object_7` (пока жив) всегда доступен отдельной операцией типа `nest`.
   Брифинг ≤ 2 фраз, названия операций из списков, модификаторы ≤ 2, совместимые (§10.4), угроза I–V.
4. **Сохранение**: поле `campaign` в `Meta` (схема 3), миграция v1/v2 → v3: ДНК, модели, избранное, дерево, ящики,
   настройки, число забегов — без изменений; корректное старое сохранение **не** считается битым. Битый блок
   `campaign` → резервная копия + новая кампания + запись в лог, профиль цел (§20.1). Валидация §20.1.
5. **`start_operation` / `complete_operation`** §17: `pending_operation` с `run_id` сохраняется до смены сцены;
   `complete_operation` идемпотентна по `run_id` (повтор — тот же отчёт, без двойной ДНК/ящиков/хода), одна запись
   `Meta.save()`. Отчёт: изменения регионов (до 3 событий по приоритету §15.1 + полный список изменений с причинами
   §15.2: «соседняя критическая +2; улей +2; подавление −3»). Висящий `pending` при старте базы — снять без commit
   (§17 контракта). Бонусы наград операции применяются к `dna_total`/ящикам **до** `Meta.add_run`-части транзакции.
6. **`RunResults`**: если `Campaign.pending()` — вызвать `complete_operation(stats)` вместо `Meta.add_run` (UI сводки — C3;
   сейчас достаточно, чтобы итоги показывали ДНК как раньше и отчёт был доступен через `Campaign.last_report()`).
   Тест-флаги обходят кампанию (`Meta.is_test_run()`).
7. **`--campaign-test`** (headless): юнит-тесты §26.1 (все 10) и интеграционные §26.2 №1–3, 5–7, 8 (через симуляцию
   висящего pending); **симуляция баланса** §18.1 — 8 стратегий × 200 кампаний × 40 ходов (без Godot-сцен боя:
   исход операции — вероятность по угрозе и стратегии), печать таблицы: ходов до первого «потерянного», средняя доля
   критических, сколько ходов до уничтожения `object_7` при охоте за ульями, были ли тупики (нет доступной операции) —
   должно быть 0, есть ли бесконечный обвал. Итог `CAMPAIGNTEST ok=true`. Таблицу — в отчёт.
8. Если симуляция показывает обвал или «всё зелёное без усилий» — поправь числа в `BALANCE` (в пределах духа §7.4),
   каждую правку — строкой в отчёте с причиной.

## Критерии приёмки
- [ ] `CAMPAIGNTEST ok=true`, все тесты §26.1 и перечисленные §26.2 — зелёные.
- [ ] Детерминизм: одинаковые seed/исходы → одинаковые снимки мира и предложения.
- [ ] Миграция v2 → v3 без потерь; битый блок кампании не убивает профиль.
- [ ] Идемпотентный commit: двойной вызов не дублирует награды и ход.
- [ ] Симуляция: 0 тупиков, нет бесконечного обвала; таблица в отчёте.
- [ ] Отчёт `design/tasks/reports/C1.md`.

## Тон (решение автора)

Игрок — оперативник организации **Z.E.R.A.**, а не последний выживший: тексты интерфейса, названия операций,
брифинги, баннеры и сводки — в тоне `design/SETTING.md` (Диспетчер, «операция», «объект», «рапорт», коротко и сухо).
