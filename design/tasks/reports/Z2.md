# Отчёт Z2 — военные в броне

**Исполнитель:** Codex · **Ветка:** `task/z2` · **Коммит:** не создавался.

## Сделано

- Продолжена заготовка прошлого запуска. Пехотинец отличается каской и сегментным жилетом; щитоносец — широким стальным щитом; тяжёлый — увеличенным корпусом, забралом/противогазом и наплечниками. Это отдельные боевые типы. Под бронёй 18 / 22 / 65 HP; скорости 20 / 18 / 16. Основную живучесть первых двух даёт снимаемая защита.
- Каска, жилет, наплечники и щит имеют отдельные packed-запасы и биты наличия. Поглощённое попадание даёт искры, обратный след рикошета и металлический звук без крови. Избыток/пробитая доля ранят тело через геометрию R1e. Сбитая деталь один раз попадает в общий физический пул Gore; при смерти остатки брони падают рядом с телом. Стадии ран также снимают мешающие детали; живой атлас содержит все сочетания брони и ран.
- Щит закрывает переднюю дугу, поворачивается медленно; сзади открыт. Пехота защищена спереди, тяжёлый — кругом. Снятая каска оставляет уязвимую голову. Радиусы 4,6…5,4 / 5,4 / 6,9 используют прежние классы PF1; снятие деталей не меняет физическое тело.
- AP задан отдельно от числа пробиваемых целей для всех 16 типов и уточнён у моделей/жаканов; модуль добавляет AP. Ближняя дробь, Мосинка, рельса и взрывы работают по броне; АК постепенно разрушает защиту. Огонь/пила/тесла имеют свои значения для жара, реза и проводящего металла.
- С 5:00 военные заменяют часть обычной массы: 1% обычная карта, 2% блокпост/периметр. Толстяки сохранены, чтобы не терять их цепные взрывы по орде. Пехота составляет большинство, щиты идут в первом ряду колонны/прилива, тяжёлые доступны с 7:00. Общие геометрия, бюджет и ограничения ролей HD1 сохранены; spawner/активности EV2 не менялись. Награды выше шаркуна, 8% патронный ящик пополняет магазины. Как аптечка, он собирается ботом по пути, а не отвлекает от наград прогрессии.

### Баланс и производительность

Парные SIM используют `--headless --fixed-fps 60 --sim=600 --fresh-save --arsenal-loadout=…`, seed 81073–81075, карту `quarantine_checkpoint`. Контроль взят из неизменённого HEAD `39c7bc7` во временном каталоге ресурсов с общими неизменёнными PNG/звуками. Ранние исходные журналы прошлого запуска сохранены; у комплекта АК/Кольт/ППШ/Мясник тот запуск не воспроизвёлся текущей командой, поэтому для сравнения используется повторённый HEAD. Для двух остальных комплектов контроль точно повторяет прежние цифры.

Баланс оценивается по медианам трёх фиксированных seed, с той же идеей парных прогонов, что в HD1. Все девять пар, включая выбросы: [z2_sim_balance.csv](z2_sim_balance.csv).

| Комплект | Медиана урона HEAD | Медиана Z2 | Δ |
|---|---:|---:|---:|
| АК-С / Кольт / ППШ / Мясник | 728,02 | 795,03 | +9,20% |
| Мосинка / Игла / Скиф / СВД | 324,75 | 276,18 | −14,96% |
| ЛПО / Дуга / Дружба / Сайга | 1038,69 | 1179,83 | +13,59% |

На медианах допуск +15% выполнен. **Он не выполнен в каждой отдельной паре:** пробивающий комплект на 81075 +193,78% (304,41 → 894,31), ближний на 81073 +80,20% (866,77 → 1561,90). Новые смерти меняют сбор опыта, путь бота и дальнейшее давление; три seed не доказывают отсутствие таких всплесков у игрока. Это ограничение приёмки, а не скрытая успешная одиночная SIM.

Чистые контрольные FPS HEAD: 17,4 / 12,1 / 24,6, медиана 17,4. Третий результат — секция `z2_bench_before_3_final.log` в [общем журнале](z2_checks.log), EXIT=0, `other_godot_processes=0`; во время запуска был только его процесс движка и консоль. Прогон `z2_bench_before_3.log` на 7,5 FPS исключён: при освобождении зависшей блокировки одновременно стартовали три Godot.

Первая серия Z2: 17,7 / 14,7 / 13,1, медиана 14,7 (−15,52% к окончательному контролю). Она снята до оптимизации AP: теперь пробитие рассчитывается только для цели с бронёй, без новых вызовов для обычной массы. Итоговая серия после оптимизации и последних правок баланса: **17,4 / 18,6 / 13,4, медиана 17,4 FPS (0% к контролю)**. Все три результата получены через общую блокировку с `other_godot_processes=0`, EXIT=0; третий завершён при продолжении 20.10 в 04:07. Медиана `horde_ms` — 6,67 против 6,49 контроля (+2,77%). ## Критерии приёмки

- [x] Три военных типа с различимыми силуэтами, останками и отдельными деталями.
- [x] Направленный щит; отдельная броня, металл вместо крови, отлёт один раз, открытая голова, воспроизводимость.
- [x] Пробитие 48 моделей/16 типов и модулей; автомат сохраняет возможность снять защиту.
- [x] Состав HD1 с середины забега, военные карты, повышенные награды и патроны; классы PF1 сохранены.
- [x] Оконные FX/weapon-FX проверки и исправленная пересъёмка стендов, EXIT=0; PNG лично просмотрены.
- [ ] SIM ≤+15%: выполнено на медианах трёх seed, но не во всех отдельных парах (выбросы указаны выше).
- [x] FPS ≥95% контроля: медианы 17,4 → 17,4 FPS; все три итоговых запуска чистые, EXIT=0.

## Отступления от задачи и контракта

- `tools/gen_art_z2.js` продолжает сохранённый генератор вместо `.py`: указанный Python возвращает «Отказано в доступе». Node без сторонних пакетов; рисунок и PNG детерминированы.
- `scripts/pickups.gd` вне списка: добавлены только вид/метаданные существующего пула и исключение расходника из приоритетных целей бота. Новых сцен/нод/формата сохранения нет. Патронный ящик пока использует рисунок оружейного ящика.
- В `game.gd` необходимы подключение новых сигналов/дропа и расширение существующих счётчиков по типам, помимо тестов. Новых обходных флагов/подмен путей сохранений нет. Для запусков использован внешний APPDATA внутри worktree.
- CONTRACTS стоит дополнить новыми Kind, сигналами `armor_hit`/`armor_detached`, последним необязательным параметром `Horde.damage(..., armor_pen)` и кодом военной внешности (бит 16384, тип в битах 15–16). Старые enum/параметры/визуальные коды сохранены.
- Исходные оконные замеры прошлого запуска были пустыми из-за ожидания общей блокировки. Доизменённый HEAD восстановлен отдельно для контроля; хронологического игрового кадра «до» не было. Солдат Z1 остаётся точным исходным образцом в парном ряду.

## Найденные проблемы вне задачи

- Модификатор кампании «Военная зона» оставлен следующей задаче: сейчас частоту задаёт карта, без изменения генерации операций и сохранений.
- Общий `godot_exclusive.sh` иногда попадает в гонку удаления каталога в `stat` (пустое время, ошибка арифметики); пересёкшийся замер исключается. Общая блокировка не изменялась.
- Движок сообщает ошибку чтения системных сертификатов и утечку одного ObjectDB при выходе также на исходном HEAD.
- При продолжении исправлена отправка нового кадра перед PNG (`await get_tree().process_frame`): устранены остатки предыдущего стенда и старых объявлений HUD. Пересъёмка `--armor-shots --fresh-save` завершилась с EXIT=0; новые фланг/тела/попадания/бой лично просмотрены.
- После прерывания третьего замера оставался пустой каталог общей блокировки от 03:36:30, без соответствующего запуска. При продолжении он удалён после проверки; очередь продолжена через прежний общий скрипт, без его изменения.
- Автоматическая проверка отклонила рекурсивное удаление временных каталогов с причиной `blocked by policy`. `design/tasks/reports/z2_baseline`, `design/tasks/reports/cp1_userdata`, `z2_runtime` оставлены для удаления ревьюером; в сдаваемые ресурсы не входят. Пять junction в `z2_baseline`, ведущих к исходным ресурсам worktree, безопасно сняты, сами ресурсы сохранены.
- При последнем продолжении игровой код и баланс не менялись: завершён третий FPS, повторно лично просмотрены все шесть игровых PNG. 76 отдельных журналов сведены с исходными именами секций в `z2_checks.log`; дубли журналов и 11 ненужных `hd1_trace_z2*.json` удалены. Рекурсивная очистка после прежнего отказа политики не повторялась. Полная приёмка остаётся открытой только по выбросам отдельных SIM; подгонка под отдельный seed не выполнялась.
