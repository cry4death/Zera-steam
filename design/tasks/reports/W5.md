# Отчёт W5 — атака, плотность и отклик выстрела

**Исполнитель:** Codex · **Ветка:** `task/w5` · **Коммит:** не делался по AGENTS.md.

## Сделано

- Пересобраны 31 shot и 6 tail WAV: шесть тех же CC0-стволов, рельса и гранатомёт. Разные записанные дубли сохранены. Слои: исходный crack с параллельной сатурацией, моносовместимый записанный низ, короткий затухающий импульс давления, контролируемое затухание уличных отражений. ППШ/АК оставляют короткий shot 0,18 с; отражение отдельно. PCM16 stereo, 48 кГц; импорт PCM вместо QOA. Механика/гильзы в игровых событиях сохранены.
- Причины тишины: RMS100 в Master был −24,55…−30,67 dBFS у шести реальных стволов; ранний пик ограничивал линейный подъём плотности в старом генераторе. Shots теряла ещё 7 dB, и `Meta.apply_settings()` возвращала этот trim при каждом изменении настроек. Теперь trim −1 dB согласован в layout и Meta; настройки пользователя, включая mute, действуют. Master: порог компрессора −2 dB, ratio 1,6, attack 10 мс, release 100 мс. Лимитер −2,3 dB оставляет запас для межсемпловых пиков. У рельсы дополнительно проверяется true peak ×4 до Master.
- Прижатие World раньше начиналось через `_process`, после атаки. Теперь оно начинается в том же `play`, глубина 3,5 → 7 dB, удержание 90 → 120 мс; восстановление плавное, база берётся из ползунка World. Ближний мясной удар получает до +4 dB, пространственное затухание и предел 12 событий/с сохранены.
- Хвост раньше терялся у 1–2 выстрелов и добавлялся при смене цели внутри стрельбы. Теперь он завершает короткую/длинную очередь, включая burst3, после паузы или перезарядки; смена цели сама его не запускает. Повторная пауза молчит.
- Камера раньше теряла часть импульса до первого отображения (`exp(-30*delta)`: на 60 FPS оставалось около 61 %). Теперь сначала выводится полный толчок, затем применяется возврат. Импульсы различаются по калибру; прежние ограничения 3,5 px kick / 4 px суммарно, деление на zoom и ползунок shake сохранены. Плечи сразу получают откат в кадре выстрела, предел 2 px сохранён. Отдача модели 1–2 px по калибру. Вспышка держит яркую атаку и гаснет только последние 8 мс вместо 25 мс.

### Выход Master: до → после

Сырой выход `AudioEffectRecord` после эффектов Master, стандартные настройки 1,0. True peak — sinc ×4 / Blackman 129 taps; RMS100 отсчитывается от первого пересечения 3 % пика; RMS3 включает тишину до выстрела и дополнение нулями до 3 с. Низ — доля энергии 60–200 Гц по двум каналам; активный хвост — до последнего окна 10 мс выше −60 dBFS. Физическая длина shot/tail-файлов 0,18/0,65–1,20 с, поэтому активная длина ниже длительности WAV. Все значения — измерения, без нормализации A/B.

Доказательства: [CSV](w5_master_metrics.csv), [JSON](w5_master_metrics.json), [просмотренные графики](w5_waveforms.png).

Бой 5 с: true peak **−1,45 → −1,66 dBTP**, RMS первых 3 с **−23,59 → −17,75 dBFS**. После — **95/95** выстрелов; в стрессах ППШ и АК **600/600** каждый, до и после. В исходном battle-счётчике до правок считался только несуществующий ID `weapons/battle/shot`, поэтому количество потерянных выстрелов именно в `battle_before` не измерено; в итоговом стенде это исправлено суммой всех `/shot`. Число `all_dropped` включает намеренно прореженные gore/гильзы/голоса орды, оно не равно потерянным выстрелам. По всем 22 WAV **clipped=0**, максимальный финальный true peak −1,36 dBTP (очередь ППШ).

Шесть основных headless-прогонов выше завершились кодом 0. Стенд W5 проверяет принятые выстрелы, четверть громкости Weapons, mute Master/Weapons, duck относительно World, предел камеры/zoom и shake=0, короткий хвост и отсутствие хвоста при смене цели. Финальная запись завершается без утечки ресурсов после явного освобождения плееров/record.

**Не пройдены из-за среды:** импорт ресурсов завершён без Parse/SCRIPT ERROR, но редактор возвращает 1 на записи `C:/Users/Dev/AppData/Roaming/Godot/editor_settings-4.7.tres`. `--meta-test` возвращает 1: недоступен `user://test_save.json`, затем null в `_write_text`. `--audio-test`, `--guns-test`, `--fx-test`, бенч прерываются на `_save_to_cache`: `Condition "f.is_null()" is true.` Первый `--weapons-test` был ошибочно запущен с `--loadout` и упал на отсутствии новых карточек; корректный повтор без `--loadout` подтвердил `WTEST checks recoil_direction=true recoil_cap=true new_cards=true missing_sfx_silent=true`, затем также прервался на shader cache до проверки хвостов. На старте выводится `Failed to read the root certificate store.`; успешные headless-проверки от этого не падают.

**FPS до/после не получен.** Три исходных D3D12-прогона и три Compatibility-прогона завершились до строки BENCH из-за shader cache; заключительный D3D12-прогон имеет тот же отказ. Все оконные старты: `other_godot_processes=0`. После подтверждения одинакового отказа повторные финальные серии не запускались. Утверждать регрессию менее 5 % нельзя. Не менялись исходники тестов/пути `user://` ради песочницы.

**Игровые скриншоты не получены** по той же причине. Просмотрен только `w5_waveforms.png`: общий масштаб, первые 150 мс реального Master. Он не заменяет визуальную приёмку в игре. Аудиовход для прослушивания инструментами этой сессии не поддерживается; различимость вслепую, агрессивность и музыкальность/естественность низа субъективно не подтверждены. Автору подготовлен [A/B-набор](w5_ab/index.md).

## Отступления от задачи и контракта

- Необходимая строка в `scripts/meta.gd`: иначе любое применение настроек снова делало бы Shots −7 dB, отменяя исправление layout. Формат сохранений не менялся.
- Вместо нового Python-генератора добавлен `tools/prep_sfx_w5.mjs`: Python по пути из AGENTS.md возвращает «Отказано в доступе», других доступных Python не найдено, Node 24.15 доступен. Источники/лицензии прежние CC0; актуальная W5-обработка и SHA-256 файлов перечислены в [w5_sources.json](w5_sources.json), исторический `sfx/manifest.json` с рецептом W4 не переписан. Для воспроизведения W5 запускать новый генератор после старого.
- A/B — одинаковый сценарий звукового стенда, не живой бой с 500 врагами; у рельсы последняя одиночная запись выполнена отдельно. Из-за timing Dummy driver фактическая длительность записи около 3/5 с немного варьируется; метрики считаются по отсчётам WAV.
- Очистка не закончена: campaign-test создал `design/tasks/reports/cp1_userdata/`. Автоматическая проверка отклонила составную команду очистки, затем точечное `Remove-Item -LiteralPath 'C:/Users/Dev/Desktop/zera-w5/design/tasks/reports/cp1_userdata' -Recurse -Force`, причина в обоих случаях только `blocked by policy`. Абсолютный путь проверен внутри этого worktree. Обход удаления не выполнялся; каталог и дубли исходных логов остались. В коммит нужны `W5*`/`w5_*` доказательства, не `cp1_userdata`.
- Баланс, кровь, движение орды и API `Sfx.play` не менялись. Гильзы используют прежние события и пулы. В `CONTRACTS.md` требуется согласовать прежнее правило «хвост только ≥3/при смене цели» с новой семантикой, если оно описывается в связанных задачах W2/W4.
