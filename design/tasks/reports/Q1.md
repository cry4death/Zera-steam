# Отчёт Q1 — баги этапа A

**Исполнитель:** Codex (gpt-6.1-sol, high) · **Ветка:** `task/q1` · **Коммит:** не создавался, коммитит ревьюер.

## Сделано

- A1/A2: `Sfx` перечисляет логические ресурсы через сортированный `ResourceLoader.list_directory`; пакетная потоковая загрузка и ID сохранены. Обязательные ID проверяются при загрузке; пропуск предупреждается один раз. Известные необязательные `rail/dry` и `launcher/dry` остаются тихими.
- Добавлен Windows Desktop preset. Включены все прочитанные в рантайме JSON: `maps/*.json`, `art/guns_meta.json` (фильтр `art/*.json`), `sfx/manifest.json`. Музыка загружается по явным `.ogg` через ResourceLoader, арт — по явным путям; другой зависимости от обхода физических исходников не найдено.
- Реальный `--export-pack` работает без шаблонов. Проверен PCK через `--main-pack`: 89 категорий, 290 вариантов, 15 ключевых ID, три карты. SHA-256 упорядоченных ID/путей совпадает с рабочим проектом.
- A3: кандидаты из существующей сетки, ближайшие восемь с расширением пакета при закрытых целях. Закрытые враг/босс не выбираются; перед выстрелом проверяется линия от дула. Гистерезис требует выигрыша дистанции 15%; исходный интервал 0,08 с сохранён, смерть допускает немедленный поиск. Для рейлгана и навесного гранатомёта линия не нужна: коллизии рейлгана/A7 не менялись. Ручной прицел не менялся.
- A4: общий `ChoiceInput`, фокус и значки последнего устройства; D-pad/левый стик, A, B, защита от удержания и начальная задержка. Работают установка/возврат, товары, установка покупки, лечение, реролл, перестановка и закрытие. Дополнены ввод паузы/итогов, настройки базы на Back вне операций. В операциях Back сохраняет журнал. B в обязательном Level Up возвращает с установки к картам, как прежний Esc; сам уровень требует выбора.
- Реальные события геймпада проходят полный цикл кампании, включая брифинг, установку, торговца, паузу/настройки, итоги, повтор операции и возврат на базу. Найдена и локально исправлена гонка: отложенное закрытие торговца могло снять уже открытую паузу; видимый `PauseMenu` сохраняет владение паузой.
- A5: патроны фильтруются по допустимым слотам до розыгрыша. Остальные типы уже имели фильтры; проверены пустой билд, четыре максимальных ствола со стандартными III и максимум пассивок, заполненные модули III. В текущем каталоге совместимость модулей определяется местом/рангом, отдельного запрета по основе нет. Добавлен защитный вариант снабжения на 20/25/30 кредитов, если пул исчерпан; применение и описание поддержаны.
- A10: тестовые каталоги создаются до проверок. Logger фиксирует SCRIPT ERROR/ошибки движка после установки защиты; ошибка даёт `TESTRESULT ok=false` и код 1. Выходы game/base проходят через `Meta.finish_test`. Проверены 13 тестовых флагов с намеренным assertion и отдельная проваленная проверка. Настоящий профиль не используется.
- A11: ползунок применяет значение сразу, запись — по отпусканию, после 0,5 с без изменений, при закрытии/выходе. Повторное закрытие не пишет ещё раз. Проверен настоящий временный JSON на диске, а не только счётчик вызовов.

## Отступления от задачи и контракта

- Шаблоны не скачивались. Самостоятельный Windows EXE без шаблонов не собирался; реальный PCK собран и запущен штатным Godot через `--main-pack`.
- `tmp/` перед проверкой отсутствовал благодаря обратимому переносу, а не удалению. Проверка отсутствия записана в журнал.
- Исходный meta-test стреляющих моделей зависел от живой карты: после правильного LOS один манекен мог оказаться за препятствием. Фикстура моделей теперь очищает препятствия; проверки стен выполняются отдельно настоящими препятствиями, без ослабления проверок числа попаданий.
- Старые base-test и aim-test имеют оконные проверки мыши/системного курсора. В headless они честно дают failed>0; финальные требуемые проверки этих режимов выполнены оконно, а отдельный Q1/цикл геймпада — headless. Это не превращено в фиктивный PASS.
- Пробный FX-запуск со служебным `--quit-after 5000` завершился кодом 139 до итоговой строки. Полный штатный повтор без этого ограничения завершился `FXTEST ok=true`, EXIT=0; оба журнала сохранены. Финальный FX не писал поверх чужих снимков.
- Публичные сигнатуры прежних вызовов сохранены; третий аргумент `Meta.set_setting(..., deferred_save=false)` необязателен. Для CONTRACTS §10 ревьюеру стоит уточнить: обязательный отсутствующий ID предупреждает один раз, известная необязательная механика остаётся тихой. Сам CONTRACTS не редактировался.

## Найденные проблемы вне задачи

- Системная ошибка чтения Windows root certificate store остаётся; сетевые загрузки/изменение сертификатов не выполнялись.
- Рейлган и взрывы по-прежнему не экранируются стенами (A7), как оговорено задачей. Навигация босса/A6 и файлы R1 не менялись.
- Окна и фоновые циклы своих запусков завершены; блокировки снимает штатный wrapper. Чужие процессы R1 не завершались.
