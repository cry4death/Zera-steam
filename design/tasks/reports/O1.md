# Отчёт O1 — препятствия на арене (+E1b)

**Исполнитель:** Codex (E1b, obstacles.gd, arena_layout.gd, арт; остановился на лимите) → доведено Sonnet 5.5 (оптимизация навигации, замеры; сжатые сроки) · **Ветка:** task/o1

## Сделано
- Codex: E1b (взрывы подключены), `Obstacles` (packed-массивы, сетка 16 px, OBB/круги, пули высокие/низкие, рельса пробивает, машины дым→огонь→взрыв CAR→остов, бочки красная/зелёная с цепью, баррикады, мусор, кровь на объектах), `ArenaLayout` (профиль quarantine, сид, связность), `--no-obstacles`, `--layout-seed`, арт `obst_atlas.png`, таран босса, свободные точки спавна/дропа/гранат.
- Sonnet (навигация, главный пик):
  - Убрана трассировка прямой видимости на клетку (после каждого свопа поля все клетки пересчитывались лампой — пик кадра). Теперь «идти прямо», если расстояние по сетке равно манхэттенскому и две точки впереди (20/40 px) свободны; иначе — направление поля. O(1).
  - Поле пересчитывается, когда игрок ушёл > 2 клеток от цели поля (не по каждой клетке), BFS размазан (400 клеток/тик, развёрнутый цикл), двойная буферизация distance/flow; при разрушении старое поле остаётся в работе.
  - Горда: направление обхода кэшируется на зомби и обновляется раз в 4 тика, у игрока (<90 px) — всегда прямо; проверка «рядом препятствие» — инлайном по массиву сетки.
  - Кровь на объекты ищет через сетку, а не по всем объектам (радиус 30). Огонь/дым — отдельный слой (корпуса не перерисовываются каждый кадр анимации).
  - Тест ускорен (проверка проникновений раз в 4 кадра).
- Убран мусор из коммита Codex (логи 22 МБ, runs/, o1_run.py).
