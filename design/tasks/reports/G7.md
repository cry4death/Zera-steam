## Шаг 2. Что нарисовано

`tools/gen_art_guns.py` (новый, поверх `gen_art` как `ga`: `Canvas`, `ramp`, `hnoise`, `outline`).

Файлы в `art/`:
- `gun_<model>.png` — 16 иконок, те же имена, что у S6. Ствол вправо, обрезка по контуру. База (`base.gd`) читает их по имени, скрипты не менялись. Размеры 45–105 px по длине, как у старых, сильнее вытянуты только Копьё (105) и пистолеты стали чуть ниже (45–49 px).
- `gun_<model>_world.png` — 16 боевых спрайтов, те же детали в масштабе 3 px арта = 1 игровая единица. Длина: АК-С 20.3 ед, М4 19, Мясник 23, Шквал 25, Игла 22, Копьё 24.3, Гром 20, Улей 20, Кольт 9, Страж 9.7, Бульдог 8.3, Ковбой 13, ППШ 20, Оса 18.3, Мосинка 27, Винчестер 23.3.
- `guns_meta.json` — для каждой модели `icon` и `world`: `size`, `grip` (задняя рука), `support` (передняя рука), `muzzle` (дульный срез) в пикселях соответствующего спрайта, плюс `length_units`. В `world` добавлено `length_units`. Это моё расширение: в задаче были только `grip` и `muzzle`.

Как нарисовано. Каждая модель — набор деталей (многоугольник, прямоугольник, эллипс, полоса вдоль кривой) в координатах иконки. Затенение — по вертикальному «забегу» пикселей детали: верхний пиксель — блик, нижний — тень, левый край чуть светлее (свет сверху-слева). Дерево — рампа с горизонтальным зерном (`hnoise`). Мелкие детали (насечки, отверстия, рёбра магазина) помечены `fine` и в боевом масштабе (< 0.8) пропускаются. Выборочная обводка — `ga.Canvas.outline`. Боевой спрайт — та же растеризация с коэффициентом `длина_боевая / длина_иконки` и подвыборкой 3x3.

## Детерминированность и проверки

- `gen_art_guns.py` без `random`, шум только `ga.hnoise`. Три прогона `--out tmp/…` совпали побайтово между собой и с файлами в `art/`.
- `gen_art_m6.py` не пишет `gun_*` (удалены функции стволов и их цикл в `sprites()`, обновлён докстринг; остальные примитивы остались). Ящики из `gen_art_m6.py --no-bg --out tmp` побайтово совпали с `art/base_crate*.png`.
- `godot --headless --path . --import`: без ошибок. Файлы `.import` для 16 боевых спрайтов созданы. `default_bus_layout.tres` импорт трогает сам, я откатил `git checkout`.
- `godot --disable-vsync --path . -- --base-test --shot=...`: `checks=50 failed=0`, `ok=true`. Иконки арсенала, склада и карточки нового ствола рисуются новыми спрайтами (`g7_arsenal.png`).

## Отступления и замечания

- Пак не взят: ни один не покрывает набор, лицензию/стиль надо проверять по превью (я их не видел).
- Иконки Мосинки больше нет прицела (в S6 он был): по таблице задачи Мосинка — карабин с открытым прицелом.
- Иконки пистолетов и револьверов в среднем чуть ниже/уже S6 (45–49 px по длине против 52–54). Раскладка арсенала от этого не страдает.
- На тёмном асфальте (61,63,67) сам по себе тёмный полимер (Мясник, М4, Оса) читается слабее светлых стволов; металл и полимер подняты на пару пунктов яркости, дальше светлить значит выпасть из тёмной палитры игры. В бою контраст добавит обводка и блик.
- Боевые спрайты и `guns_meta.json` пока нигде не используются (скрипты игры не трогались по условию). Для подключения: `grip` — точка приложения задней руки на спрайте, `support` — передняя рука, `muzzle` — откуда вылетает выстрел/вспышка; у пистолетов и револьверов `support` равен `grip`.
- Лист создаётся командой `python tools/gen_art_guns.py --sheet <png> --old <папка со старыми gun_*.png>` (старые иконки брались из `git show main:art/gun_*.png`).
