# Отчёт U3 — драйв вместо текста, настоящие патроны

**Исполнитель:** Sonnet 5.5 · **Ветка:** task/u3 · Работа свёрнута по требованию координатора: часть пунктов не сделана (см. ниже).

## Сделано
- **Патроны в HUD** (`scripts/hud_rounds.gd`, `tools/gen_art_hud_ammo.py`, `art/hud_round_*.png`): 7 видов спрайтов (винтовочный, пистолетный, гильза дробовика, револьверный, снайперский, батарея рейлгана, граната), по 2–5 размеров под ёмкость магазина (от крупной гильзы на 6 штук до «чёрточек» на 71). Цвет наконечника — тип патронов (обычные/экспансивные/зажигательные/крио), редкие — синий отлив. Последние 25 % краснеют, «заряд» Копья красит наконечники в янтарь. Пакетная отрисовка, без нод.
  - Выстрел: крайний патрон выщелкивается (подлёт, кувырок, затухание 0,22 с). Перезарядка: магазинные стволы — пачкой на 70–90 % (как звук mag_in), дробовик — по одному по порогам звука, револьвер выбрасывает остаток и заряжает барабан, гранатомёт — по одной. Число рядом — только для магазинов больше 12; «/макс» убрано; полоска перезарядки — тонкая линия по низу слота.
  - Лист патронов: `u3_ammo_sheet.png` (все виды × полный/пустеет/мало/перезарядка 45 и 85 %, типы патронов и редкость), рисуется флагом `hud.ammo_sheet` в `--hud-test`.
- **HUD, было → стало:** «УРОН 2 / ТЕМП 1 / БРОНЯ 1» → значок+цифра; «ТОРГОВЕЦ 5:00 / 4:59» и «ТРЕВОГА …» → значок события + отсчёт + полоска, которая заполняется к событию; «ЦЕЛЬ: ОБЪЕКТ-7 64 %» → череп + полоска; «УБИТО / СЕРИЯ» → череп + число, пламя + ×N; плашка операции «Диспетчер: операция / имя / регион / модификаторы» → крупное имя + угроза делениями + значки модификаторов с короткими именами (3,6 с), затем компактная строка «череп угрозы + деления + значки»; полоса босса без текста и чисел (череп, жилет пока броня цела, сегментная полоса); «ОБЪЕКТ-7 ПРИБЛИЖАЕТСЯ» → череп + «ОБЪЕКТ-7»; подсказка управления короче и 12 с вместо 28; мультикилл-метка с ударом размера (18→15→12) и цвета белый→оранжевый; клавиши F1–F10 работают только при включённой отладке (F3).
- **Level Up / снабжение:** карта = пиктограмма, название, ОДНА крупная цифра («+10 % крит», «5 урон ×6», «+2 урон»), у нового ствола — ряд настоящих патронов его магазина; описание, черта, ранги I–III — по наведению / ← →. Убраны «выбери улучшение», «подробнее: наведи», длинные подсказки. Цифры — поля `big` в `weapon_defs.gd`, `level_big()`.
- **Итоги:** крупные «убито» и «время» с щелчками, плашки значок+число (элитки, серия, кровь, ящики), стволы иконками с уровнем и значком патронов, слагаемые ДНК значками, множитель «★ ×1,5», итог с отсчётом; последствия — 2–3 события крупными числами (падение заражения зелёным), ульи и критические регионы значками, полный журнал по кнопке «Журнал [J]».
- **База:** убраны подписи «ЯЩИКИ/ВОЕННЫЕ», «доступно», «Выбор моделей — в Арсенале [3]» (клик по стартовому стволу ведёт в Арсенал), справка склада, строки магазин/перезарядка/вложено в мастерской, редкость под названиями в Арсенале, длинные подсказки внизу; «СТОИМОСТЬ: 1 ОЧКО» → «1 очко».
- **Пауза:** убран «Карантинная зона · сектор 07» (теперь регион операции, в вылазке — ничего), «Изменения сохраняются сразу», нижняя строка клавиш; подсказка про прицел — к строке «Автострельба».
