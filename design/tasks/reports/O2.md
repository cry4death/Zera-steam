# Отчёт O2 — авторские карты

**Исполнитель:** Codex · **Ветка:** `task/o2` · **Коммит:** не создавался, по инструкции автора.

## Сделано

- Три постоянных плана 2560×1440: `quarantine_checkpoint`, `old_town`, `open_perimeter`. Планировка и коллизии не зависят от сида; меняются кузова, повреждения и мусор внутри сценок.
- Карантин: змейка КПП на трассе, колонна грузовиков, заправка с колонками и цистерной, складской двор с контейнерами, перелесок. Круг проходит вокруг складского двора.
- Старый город: кварталы разного размера, узкие улицы, единственная большая площадь с сухим фонтаном, проходной двор, остановка и парковка. Круг проходит вокруг северного квартала; двор имеет выходы на две улицы.
- Открытый периметр: песок и длинная косая трасса, лагерь на старой площадке, остовы техники, разнесённые руины и контейнеры. Вокруг лагеря остаётся широкий обход.
- Сценки: пробка, колонна, авария, КПП, заправка, парковка с пустыми местами, стройка, полевой пост, остановка с киоском, контейнеры, лагерь и фонтан. Стекло лежит у аварий, бумага и мешки — у остановки, доски — у стройки, отходы — у торцов контейнеров; равномерной россыпи нет.
- Земля собирается при загрузке в четыре текстуры. Есть бордюры, края грунта/травы/песка/снега, разметка, переходы, парковочные места, люки, трещины, масло и колея. Асфальт берётся из большого бесшовного полотна U2; квадратный повтор случайных фрагментов устранён после просмотра снимков.
- Крыши: парапеты, тёмный южный фасад, вентиляция, лестничные надстройки, трубы, ремонтные заплаты; три варианта каждого размера. Отдельные навес, будка, колонка, цистерна, палатки, ящики, контейнеры, фрагменты руин и густые древесные кроны.
- Структуры используют высокие OBB-препятствия O1: блокируют движение и пули, получают кровь у края. Существующие `free_point` для предметов, контейнера тревоги и гранаты распространяются на них без изменений этих подсистем.
- Выбор по `mission_config.region_id`, свободная вылазка — карантин. Для регионов O3 задана явная таблица временных соответствий. Размер читается из файла и передаётся существующим `setup` камеры, игрока, орды и декалей.
- Спавн использует ближайшие входы карты за экраном с запасом под ширину волны; кольцо остаётся запасным. Дальние входящие группы не телепортируются обратно на вход каждый тик.
- Машины: разные пропорции салона/стёкол, кузова и швы, открытые двери у части повреждённых машин, локальные группы брызг вместо равномерных пятен, разные положения огня. Новый атлас назван `map_vehicles.png`, чтобы соблюсти разрешённый список `art/map_*`.
- Оптимизации O1b: одна узкая фаза движения после расталкивания обычной орды, подшаги для быстрого отброса, консервативная сетка перед коллизией, AABB перед OBB, проверка объекта лучом только один раз, один MultiMesh для машин и мусора. В пакете пересчитываются только изменившиеся строки, а не все машины при каждом попадании. Узлы на отдельные сущности не добавлены. `--obstacle-profile` отдельно считает вызовы и время `move_actor`, `resolve`, `ray_hit`.
- Добавлен `--map-test`: загрузка, связность, старт и входы, детерминизм, неизменность геометрии между сидами, свободный дроп, авторский круг радиусом 8 px, высокие структуры, 60 секунд с 500 зомби на каждой карте и рывок через сплошную стену.

## Формат карты

Выбран **JSON с двумя ASCII-слоями**: план остаётся видимым при чтении файла, а координаты, списки и дополнительные поля не требуют собственного парсера секций. Одна клетка — 32 px; ширина и высота определяются длиной/числом строк, сейчас 80×45.

| Поле | Формат |
|---|---|
| `ground` | Массив строк: `=` асфальт, `-` разметка, `.` тротуар, `,` трава, `:` грунт, `~` песок, `*` снег, `#` бетон |
| `structures` | Массив строк той же формы: пробел свободен; `B` корпус, `R` руина, `W` ограда, `T` непроходимый перелесок. Соседние клетки объединяются в прямоугольники без перемещения плана |
| `set_pieces` | `{ "type": "checkpoint", "at": [40,17], "angle": 0 }`; `at` в клетках, поворот в градусах |
| `entries`, `player_start` | Пары координат в клетках; не индексы с неявным смещением на полклетки |
| `zones` | Авторские названия зон для чтения плана |
| `loops` | Замкнутые ломаные в клетках; тест реально проводит по ним актёра радиусом 8 px |
| `markings` | `[x,y,width,height]` в мировых px, запекаемые линии парковки |
| `decals` | `[x,y,type]` в мировых px; 0 масло, 1 люк, 2 трещина, 3 колея |
| `road_path` | Необязательная уточняющая ломаная в клетках для косой трассы. Контур генерируется из тех же авторских данных, чтобы край не шёл ступенями по 32 px |

`MapLoader.layout(data, seed)` возвращает прежние словари O1 плюс `STRUCTURE` с `half`, `skin`, `angle`; горячие данные затем переводятся в packed-массивы. При изменении размеров корпусов/земли сначала выполнить `tools/gen_art_map.py`, затем Godot `--import`. Генераторы используют локальные RNG и не расходуют RNG боя.

## Проверка

Итоговые команды, дословные строки и таблица замеров дописываются после завершения серии проверок.

## Критерии приёмки

- [x] Карты — авторские данные; сид меняет детали, не планировку.
- [x] Сет-пьесы, мусор по смыслу, земля с переходами, здания/контейнеры.
- [x] Три карты с ориентирами и разными зонами; подключение к регионам; спавн из точек карты.
- [x] Машины O1 не шаблонные: разные салоны, повреждения, позиции огня и группы брызг.
- [ ] Замеры и окончательная регрессия — серия выполняется.

## Отступления от задачи и контракта

- Для CLI `--map-test`, `--map-shots` и отдельного `--map=<id>` нужен `--fresh-save` либо прямой запуск `scenes/main.tscn`: список тестовых флагов базы/Meta не входит в разрешённые файлы. `--campaign-test` запускается **без** `--fresh-save`: этот флаг отключает фасад кампании и ломает её интеграционные проверки.
- `--bench` сохраняет кольцо O1 для одинаковой плотности настоящего ближнего боя на всех картах и в варианте без препятствий. В обычной вылазке, операции и `--sim` работают входы карты. Иначе 13-секундный замер измерял бы преимущественно подход орды с далёких входов.
- Земля — 2 пикселя арта на мировую единицу, уточняющий контур косой дороги — 1; старые машины — 3. Все фильтруются nearest. Контур дороги генерируется заранее, остальные слои земли объединяются при загрузке.
- Новые карты не наследуют плотности случайного профиля O1: объекты поставлены по назначению мест. Старый профиль оставлен неизменным для `--obstacles-test`.

## Найденные проблемы вне задачи

- В этой песочнице Godot при старте печатает `ERROR: Failed to read the root certificate store.` (`platform/windows/os_windows.cpp:2582`). Это было и в первоначальном импорте/исходном бенчмарке. Ошибки парсера и GDScript проверяются отдельно.
- В оконных запусках встречается исходное предупреждение `WARNING: 1 ObjectDB instance was leaked at exit (run with --verbose for details).`; оно было и в исходном бенчмарке O1.
- Даже при одном сиде существующий боевой бенчмарк даёт разный `kills`/gore между запусками: глобальный RNG расходуется также визуальными системами по кадрам. Поэтому сопоставляем последовательные пары и показываем все итоговые прогоны, не только удачный кадр.
