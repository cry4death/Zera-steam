# Отчёт W7c — правдоподобный огонь

**Исполнитель:** Codex · **Ветка:** `task/w7c` · **База сравнения:** `25a338c` · **Коммит:** не создавался, коммитит ревьюер.

## Сделано
- Продолжена работа предыдущего прогона: сохранены исходные кадры, проверки и замеры; работа заново не начиналась.
- Одинаковый атлас костров заменён четырьмя процедурными языками от плеч, спины и рукавов. Привязки поворачиваются с телом; размеры, скорость, изгиб и фазы различаются. Есть восходящие угли, пятнистое обугливание через существующий канал и сохранённые метания W7b.
- Один экземпляр MultiMesh содержит четыре узких прямоугольника языков и один уголь. Пиксель считает один язык, без цикла по четырём. Три общие партии пламени/дыма/света используют один буфер; нод на каждого зомби нет. За экраном эффект отсекается; при 300+ тел дальше 100 игровых единиц остаются один выбранный по seed язык и уголь, дым/отсвет — у четверти тел. Ближний эффект полный.
- Струя имеет узкое светлое ядро, расширяющиеся оранжевые клубы, рваный край и дым. Есть падающие капли, низкое пламя над топливом, затухание и существующая копоть. Тёплый отсвет — мягкие аддитивные пятна. Существующие источники поджога используют общий канал горения.
- После крупного просмотра укрупнён шум струи/дыма, уменьшена завеса над дальней толпой. Убраны расчёт горения/обугливания на прозрачных пикселях тела и повторный нулевой трансформ каждого напольного пятна. Дым использует одну выборку общего детерминированного шума (seed 7107).
- Урон, распространение огня, баланс и формат сохранений не менялись.

### Производительность
Сравнение с исходными scripts/shaders `25a338c` во временном `w7c_baseline/`, тот же стенд, карта/seed, D3D12 Forward+ / встроенная AMD. Все оконные запуски выполнены через общий `godot_exclusive.sh`; у всех шести итоговых измерений `other_godot_processes=0` на старте. На время замеров отключался недоступный для записи дисковый кэш шейдеров; временный `override.cfg` после проверки удалён, штатная настройка восстановлена.

|---|---|---:|---|
| `--loadout --bench=500 --fresh-save` | 13,8 / 9,1 / 13,2 | 13,2 | 108,2 / 83,5 / 114,1; **108,2** |
| `--fire-bench --fresh-save`, 500 тел / 499 горящих | 215,2 / 239,9 / 247,5 | 239,9 | 351,3 / 283,6 / 230,9; **283,6** |

Итоговые тройки после LOD языков: `w7c_bench_lod_final_1/2/3.log` и `w7c_firebench_lod_final_1/2/3.log`. Последний захват — `w7c_shots_lod_final.log`; все его кадры, обновлённый контактный лист и серый вариант просмотрены. Оконные режимы завершены, чужие процессы не останавливались.

В зафиксированных медианах просадки >5% нет. **Ограничение сравнения:** к последнему огненному запуску общий helper был изменён извне и вывел `mode=parallel other_godot_processes=0` (10:52:35). Поэтому строгую эксклюзивность всей итоговой тройки огненного стенда не заявляю. Общий скрипт и его `parallel.on` мной не менялись. Масштаб прироста обычного стенда также нельзя приписать одной оптимизации: вместе с FPS существенно изменились `horde_ms` и время загрузки карты.

Худшие кадры обычного стенда до: **150,00 / 148,13 / 150,00 мс**, после: **58,08 / 75,56 / 84,12 мс**; медиана `physics_avg_ms` **29,70 → 16,03**. Огненный стенд `worst_ms` до: **12,65 / 10,10 / 8,58**, после: **7,54 / 9,60 / 12,19**. Полные итоговые строки дословно сохранены в `w7c_checks.log`.

Промежуточные версии давали просадки >5%, поэтому потребовались оптимизации геометрии и LOD языков; их результаты не смешаны с итоговой серией. Нечистые запуски (старый с `other_godot_processes=5`, `w7c_bench_lod_1.log` с `=2`) исключены. Все принятые итоговые режимы завершились с кодом 0, без ошибок скриптов/шейдеров. Исходные журналы промежуточных версий сохранены для проверки.

## Отступления от задачи и контракта
- Растровый генератор не требуется: огонь, дым и струя считаются шейдерами, шум — детерминированный `NoiseTexture2D` / `FastNoiseLite`. Указанный Python недоступен (`Access is denied`). Общие API/контракты не менялись.
- Временный `override.cfg` использовался только для отключения недоступного кэша при измерениях; после серии удалён, штатная настройка восстановлена.

## Найденные проблемы вне задачи / уборка
- Запись логов/тестовых сохранений в `user://` ограничена средой; обходы путей и специальные флаги под W7c не добавлялись.
- Автоматическая проверка дважды отклонила очистку: сначала рекурсивное удаление `w7c_before_code/`, затем более узкое поэлементное удаление `w7c_before_code/` и `w7c_baseline/` с предварительным снятием junction без рекурсии: **`blocked by policy`**. Обе команды не выполнялись, ссылки и ресурсы не затронуты. Ревьюеру убрать эти две служебные папки (в baseline junction на `.godot`, art/fonts/maps/music/sfx); они не часть игры. Временный `override.cfg` удалён успешно.
