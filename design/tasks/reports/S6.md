# Отчёт S6 — экран базы и поток сцен

**Исполнители:** начал Claude Sonnet 5.5, продолжил и завершил Codex. **Ветка:** `task/s6`, worktree `C:\Users\Dev\Desktop\zera-s6`. **Дата:** 2026-10-17. Изменения оставлены в рабочей копии, без коммита по указанию пользователя. Другие `Desktop\zera*` не изменялись.

## Сделано

- Сохранена и доведена реализация Sonnet: `base.tscn`, `base.gd`, генератор и весь созданный им арт. Исправлены две ошибки вывода типов (`rare`, `fav`) и очередь «вскрыть все»: первый элемент теперь извлекается ровно один раз, работает и единственный военный ящик.
- Обычный запуск открывает базу. Шапка показывает тратимую ДНК, уровень класса, прогресс до следующего, очки навыков и оба вида ящиков. Внизу — избранные модели восьми категорий и крупная кнопка «В БОЙ».
- Казарма: 3×3 узла из `Meta.TREE`, порядок веток, три состояния, описание и цена. Добавлено модальное подтверждение расхода очка с отменой; под ним нельзя случайно открыть другой узел или уйти в бой.
- Мастерская: только открытые модели, четыре параметра по пять уровней, цена, отказ при нехватке ДНК/максимуме, текущие и будущие значения, эффективный DPS и вложения. Превью учитывает мастерскую и постоянные бонусы дерева; временные черты стрельбы в DPS не включаются, как в S5.
- Арсенал: восемь категорий по две модели, силуэты закрытых, черты, звезда избранного, сравнение эффективного DPS L1 с серийной. В бою стартовый автомат берётся из `Meta.model_for`; Level Up использует существующий API S5.
- Склад: обычные/военные ящики, остатки и вероятности, журнал текущего визита. Тряска 0.8 с → отлетающая крышка → вспышка редкости → карточка новой модели/пачки ДНК/дубликата. «Вскрыть все» обрабатывает очередь, ускоряет следующие анимации, даёт общую сводку; Enter/клик пропускает, Esc останавливает очередь. Уже начисленная добыча не теряется.
- Щелчки/покупки используют `weapons/pistol/dry`, `mag_in`, `rack`; ящик — `casings/mag_drop` и тихий `explosions/grenade`. Новых звуков и музыки нет; `Sfx` не менялся.
- Итоги: основная кнопка «НА БАЗУ», вторая «ЕЩЁ РАЗ [R]», новый сигнал `base_requested`. Сброс паузы и скорости времени при обоих переходах; повтор сразу открывает `main.tscn`. Награды начисляет прежний `RunResults.open` через Meta, до выбора кнопки.
- Маршрутизация использует `Meta.is_test_run(args)` и дополнительно `--meta*`, `--save-file*`; `--fresh-save` уже входит в `Meta.is_test_run`. Аргументы остаются в `OS.get_cmdline_user_args()` и без изменений читаются игрой. Возврат из итогов имеет одноразовую отметку в SceneTree, чтобы CLI не отправлял игрока с базы обратно в бой автоматически.
- `--base-test` изолирован в **Meta._ready**, до загрузки любого файла. Состояние только в памяти, включая сочетание с `--save-file`, `--fresh-save`, `--meta-preset`. 46 проверок: маршруты, ввод, подтверждение/отмена, покупки/отказы, ящики/редкая модель/пачки/дубликаты, избранная и реальные переходы база → бой → поражение → R → новый бой → победа → клик «НА БАЗУ». Проверяются применение мастерской, награды и отсутствие повторного начисления.

## Управление

- Разделы: **1–4**, **Tab / Shift+Tab**, **PgUp/PgDn**, клик, **LB/RB**.
- Выбор: стрелки / WASD / D-pad / левый стик. В мастерской ↑↓ выбирают модель, ←→ параметр. В арсенале перемещение по сетке.
- Действие: **E/F**, **A** геймпада, клик по кнопке. Казарма запрашивает подтверждение; **Esc/B** отменяют.
- Склад: **E/A** — вскрыть выбранный тип, **R/X** — все. **Enter/Space/E/A/клик** — пропустить анимацию/дальше; **Esc/B** — остановить очередь после текущего результата.
- На базе **Enter/Space/Start** или кнопка «В БОЙ» начинают забег; при открытом подтверждении подтверждают его, при вскрытии показывают результат.
- В итогах **←→ / D-pad** выбирают кнопку, **Enter/Space/A/Start** активируют; по умолчанию «НА БАЗУ». **R/X** — «ЕЩЁ РАЗ». Первый ввод во время печати допечатывает чек; ↑↓/PgUp/PgDn/колесо прокручивают длинный чек.

## Отступления от задачи и контракта

- **`scripts/meta.gd` вне исходного списка S6:** необходима ранняя проверка `--base-test`, иначе autoload загружает настоящее сохранение ещё до `_ready` базы. Добавлен только изолирующий ранний выход; API, баланс и остальные режимы S5 не менялись. Требование изоляции явно подтверждено текущим поручением пользователя.
- **`art/gun_*.png` и иконки 16 моделей:** уже созданы Sonnet до продолжения. Сохранены и используются для арсенала, мастерской, результата ящика и нижней панели. Перегенерация в tmp дала побайтовое совпадение всего арта.
- Временное сохранение S6 реализовано в памяти, как тесты S5, без создания файла на диске. В `--base-test` явно игнорируются внешние данные/путь сохранения, чтобы fixture не затронул никакое сохранение.
- В сквозном тесте поражение запускается штатным обработчиком смерти, победа — штатным открытием итогов с заданной статистикой; отдельный `--boss --boss-hp=300` проверяет настоящую смерть босса. Сам `--sim=600` заканчивается при появлении босса, как до S6.
- Коммита нет по указанию пользователя и ограничению записи `.git/worktrees`; ревьюер может закоммитить рабочую копию.
