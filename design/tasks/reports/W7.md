# Отчёт W7 — расширение арсенала

**Исполнитель:** Codex · **Ветка:** task/w7 · **Коммит:** не создавался, коммитит ревьюер.

## Сделано
- 48 моделей вместо 16, 16 типов вместо 8; по три модели на категорию. Старые enum/ID сохранены.
- Пулемёт с упором и раскруткой; миниган с раскруткой/замедлением; огнемёт с сектором и передачей огня живыми носителями; пила с BISECT; пробивающий арбалет с PIN; автодробовик; DMR; дуга по живым целям без условия убийства.
- Совместимость модулей/патронов проверяется при предложении, установке и переносе у торговца. Четыре слота ограничены в Weapons.add_weapon. Карты, ящики, избранные модели и четыре стата мастерской используют каталог.
- Пулемётчик раскручивает оба типа быстрее; Инженер получает дополнительную цель дуги. Запрета оружия для других классов нет.
- 32 новых силуэта, боевые PNG/HUD, крупные изображения всех 48 моделей. Восемь дополнительных моделей прежних категорий перерисованы после просмотра первой линейки. Струя/дуга вынесены над толпой; снимки очищают предыдущий стенд.
- Для U2: art/gun_<id>_large.png; новые метаданные art/gun_meta_w7.json. Старые боевые PNG не перезаписаны.
- Продолжение после лимита: исправлена очистка стенда (маски крови сохраняются), тир W6 выбирает серийную модель категории независимо от порядка словаря; струя рисуется перекрывающимися языками, кадры пулемётов показывают очередь после раскрутки.

## Производительность
До: чистые прогоны other_godot_processes=0: 9.7 / 19.9 / 17.3 FPS, медиана **17.3 FPS**. physics_avg_ms: 28.86 / 25.77 / 26.42. Первый прогон медленнее остальных, сохранён без отбрасывания.

После: чистые прогоны `other_godot_processes=0`: **120.2 / 82.6 / 154.6 FPS**, медиана **120.2 FPS**; physics_avg_ms **14.99 / 19.85 / 14.13**, медиана **14.99 мс** (до 26.42 мс). Все три — код 0, команда `--loadout --bench=500 --fresh-save` через общую блокировку, одинаковые карта/seed и D3D12 Forward+ на AMD.

По записанным замерам регрессии нет. Очень большой разрыв FPS и разброс до/после не позволяют приписать ускорение одной W7: температура, питание и прочая нагрузка машины не фиксировались. Минимум после (82.6) выше максимума до (19.9); исходную серию не перезапускал и медленный первый замер не отбрасывал.

Отдельно М134 + ЛПО, оба L5, без дополнительных модулей: `--loadout --bench=500 --fresh-save --arsenal-loadout=m134,lpo`. **155.6 / 138.9 / 134.2 FPS**, медиана **138.9 FPS**, physics_avg_ms **8.73 / 9.25 / 11.08**, медиана **9.25 мс**; 499–500 живых в среднем, worst_frame_ms **43.75 / 73.22 / 63.23**. Все три через общую блокировку, `other_godot_processes=0`, код 0. Эта сборка из двух стволов показывает нагрузку новых механик, а не выигрыш относительно четырёх старых стволов.

## Отступления от задачи и контракта
- Генератор арта — tools/gen_art_w7.js (Node без пакетов), а не .py: запуск указанного Python в песочнице возвращает «Отказано в доступе». Генерация детерминирована.
- Минимально за списком «Можно трогать»: gun_lab_audio/range — доступ новых голосов W6; hud_rounds — новые enum не помещаются в старые таблицы; meta_test/cp1_test — жёсткие количества 8/16 и старая фикстура owned отвергали корректное расширение. Продакшен meta.gd уже дополняет серийные модели и читает каталог динамически; его не менял.
