# Отчёт W6 — звуковой пульт и тир

**Исполнитель:** Codex · **Ветка:** `task/w6` · **Коммит:** не делался по AGENTS.md.

## Сделано

- 48 кандидатов (по 6 на ствол), **5 470 526 байт WAV**, моно PCM16 / 44,1 кГц. Близкие/средние записи, отдельные позиции микрофона из ZIP и механика A2. Архив читается выборочно в памяти, библиотека не изменялась. Источники — [SOURCES.md](../../../sfx/gunlab/SOURCES.md). Антиалиасинг sinc/Blackman, удаление DC/тишины, короткие края; синтетический низ не добавлялся.
- Четыре слоя собираются при выстреле. Все параметры слоёв действуют сразу; обрезка с затуханием кэшируется отдельно для каждого слоя. 160 заранее созданных голосов, без нод/таймеров на выстрел. Восемь шин оружия: фильтры, низкая полка, середина, насыщение, компрессор; отдельные шины отражений с реверберацией. Глобальная громкость и mute через Shots сохранены.
- Русский пульт: F9, исходники с прослушиванием, ползунки/числа, одиночный выстрел, очередь 2 с, A/B с сохранённым, сохранение, сброс, копирование между стволами. Камера освобождает левую часть экрана. Ползунки ощущения подключены к настоящим вспышке, отдаче и тряске с прежними ограничениями.
- «Тир» на базе: восстанавливаемые мишени-зомби, бесконечный магазин, бессмертие, все восемь стволов. Мышь стреляет в свободной части экрана; клики по пульту не стреляют. Возврат/выход через паузу не выдают награды, пользовательские настройки управления не меняются.
- Версионированный JSON, проверка типов/границ/исходников, атомарная запись проекта и копии профиля с явным сообщением о недоступном месте. Без файла настройки берутся из каталога стартовых пресетов. Модели одного семейства используют один пресет. Исправления W5 сохранены, включая отражение ППШ/АК в конце очереди.
- Дробовик: атака близкого Mossberg, плотное тело близкой Nova, механика, длинный Model 12. Мосин: близкая атака и длинный записанный хвост; у АК поднята середина. [A/B: 16 WAV](w6_ab/index.md), [измерения](w6_metrics.json).

### Как пользоваться

1. На базе нажать «Тир»; в бою открыть/закрыть пульт клавишей F9.
2. Слева выбрать ствол, справа — один из четырёх слоёв и исходник; «Прослушать» играет исходную запись.
3. Настроить громкость, высоту, начало/длину/затухание и задержку; «Выкл» отключает слой.
4. Во вкладке «Обработка и ощущение» настроить фильтры, низ, середину, насыщение, атаку, отражение и ощущения.
5. Нажимать «Выстрел»/«Очередь» или стрелять мышью слева от пульта; следующий выстрел использует правки.
6. A/B переключает настройку и последнее сохранённое; изменение ползунка возвращает текущую настройку. «Сбросить» возвращает стартовый пресет выбранного ствола, «Скопировать с…» переносит все его параметры.
7. Нажать «Сохранить», проверить сообщение. Для коммита нужен `sfx/gun_tuning.json`; в сборке используется копия профиля.

## Проверка

Команды и итоговые строки — [w6_checks.log](w6_checks.log). `--gunlab-test --gun-range --fresh-save` проверяет выход после изменения громкости/фильтра, четыре слоя всех стволов, PCM-импорт, F9, битый JSON, запись → новый процесс → точную загрузку и 40 выстрелов с темпом 20/с без вытеснения голосов. Отдельный `--script res://scripts/gun_lab_entry_test.gd -- --fresh-save` проходит кнопку базы, восемь реальных выстрелов и возврат без изменения Meta.

Импорт завершил обработку, `IMPORT_EXIT=0`, Parse/SCRIPT ERROR нет. Среда сообщает ошибки записи `user://logs/godot.log`, `editor_settings-4.7.tres` и чтения сертификатов. `--meta-test` не прошёл: недоступен `user://test_save.json`, затем `_write_text` обращается к null. Headless `--audio-test` завершён, но его звуковые проверки при headless пропускаются; слышимый выход проверяет отдельный W6-стенд.

Выход дробовика W4/main → W6: true peak **−9,02 → −2,23 dBTP**, RMS100 **−25,38 → −18,39 dBFS**. Все восемь пресетов: **clipped=0**, максимум **−2,23 dBTP**. WAV записаны после Master, без последующей нормализации; true peak — sinc ×4. Это измерения, не субъективная оценка тяжести/естественности. Прослушивание в этой сессии недоступно.

**Скриншоты и FPS до/после не получены.** Оконные команды через обязательный `godot_exclusive.sh` не получили блокировку за ограниченное время (`WINDOW_EXIT=124`). Исходный оконный бенч не стартовал; чистой медианы из трёх до/после нет, регрессию ≤5 % подтвердить нельзя. Ревьюеру нужны оконные `--gun-range --gunlab-shots --fresh-save` (пульт/тир), `--gunlab-shots --fresh-save` (F9 поверх боя), `--fx-test --fresh-save`, оконный `--audio-test` и бенч из AGENTS.md. Визуальная приёмка пульта в реальном окне остаётся открытой.

## Критерии приёмки

- [x] По 4–8 записанных кандидатов для восьми стволов, источник указан, размер ≤150 МБ.
- [x] Живые слои, эффекты и ощущения; пульт, A/B, сброс, копирование, сохранение и стартовые пресеты.
- [x] Тир с базы, все стволы, бесконечный магазин, бессмертие; F9 проверен headless.
- [x] Выход реагирует на параметры, загрузка в новом процессе без потерь, 20 выстрелов/с без обрывов; A/B отрендерен.
- [ ] Авторская слуховая оценка, три игровых скриншота и визуальная проверка пульта — требуется оконный запуск.
- [ ] FPS ±5 %, оконные fx/audio и полный meta-test — ограничения среды выше.

## Отступления от задачи и контракта

- Оконные итоговые попытки также не стартовали за ожидание блокировки: `BENCH_EXIT=124`, `FX_EXIT=124`.
- Очистка не закончена: автоматическая проверка отклонила составную команду удаления временных логов и `cp1_userdata/fixtures/c1_migration.json.campaign-bad-4873196`, причина — только `blocked by policy`. Повторные логи `w6_*.log` и эта тестовая копия остались. Основные результаты сведены в `w6_checks.log`; обход удаления не выполнялся.
- Вместо `tools/prep_gunlab.py` — `.mjs`: указанный Python возвращает `Access is denied`, доступен Node. Как в W5, обработка остаётся детерминированной, без зависимостей.
- Минимальное изменение вне списка: `export_presets.cfg`, только include-filter для `sfx/gunlab/library.json` и `sfx/gun_tuning.json`. Без этого каталог/настройки могли не попасть в собранную игру.
- Обрезка/затухание кэшируются для отдельных слоёв; итоговый выстрел не запекается. Середина — широкая полоса EQ10. Файлы W5 оставлены для истории/старого банка, новые выстрелы их не проигрывают.
- Баланс, формат Meta и существующие сохранения не менялись. Новые API изолированы в GunLab-классах; `Sfx.play` сохранил сигнатуру.

## Найденные проблемы вне задачи

- Недоступный профиль мешает meta-test и пользовательской копии настроек. Старые отслеживаемые `R1b_runtime`/`cp1_userdata` из базовой ветки не удалялись.
