# Отчёт UX1 — ясность выбора и стрельбы

**Исполнитель:** Codex (high) · **Ветка:** `task/ux1` · **Коммит:** не создавался, коммитит ревьюер.

## Сделано
- Карты и торговец используют общий прогноз через `Weapons.refresh` на отдельном слоте: уровень,
  мастерская, дерево, пассивки, модули, прототип и крит текущих патронов. Сборка при просмотре не меняется.
- Новый ствол: роль, паттерн, DPS с перезарядкой и дальность. Улучшение: фактические «до → после»;
  у деталей видны совместимые стволы, при установке — ранг, изменение параметров и заменяемые патроны.
  Ухудшение отмечено красным и явными числами до/после; редкий сдвоенный ствол показывает фактическую прибавку.
- Гарантия на уровнях 2/4 выбирает допустимый ствол по весам; фиксированный seed воспроизводится.
- У слотов появились «нет цели» и «линия закрыта». Полоса перезарядки сохранена.
  Проверка состояния — раз в 125 мс, появление после 250 мс устойчивого состояния, выстрел гасит значок сразу.
  Рейлган и гранатомёт не получают ложный значок закрытой линии. Логика стрельбы не менялась.
- Серия считает убийства в скользящем окне 6 с; паузы тяжёлого оружия больше не сбрасывают её через 1,5 с.
  Пороги 5/10/20/40/80 дают звук и реакцию счётчика; надписи только на 20/40/80, справа.
  Одновременный мультикилл звучит одним акцентом, пороги не повторяются до опустошения окна.

## Критерии приёмки
- [x] Карты: роль/паттерн, сравнимые параметры, «до → после», подходящие стволы и замена; подробности по фокусу.
- [x] Взвешенная гарантия ствола и воспроизводимость seed.
- [x] Торговец: сравнение актуальной сборки до покупки, общие значки с картами.
- [x] Причины молчания значками без изменения огня; серия с окном для тяжёлых стволов, звуком и редкими надписями.
- [ ] Полный набор с `failed=0`: тест сохранений требует записи в недоступный `user://` (см. ограничения ниже).
- [ ] Бенч без просадки >5%: нет измеренных FPS из-за ошибки записи кэша шейдеров.

## Отступления от задачи и контракта
- Важных неясностей нет. Правило серии выбрано по разрешённому в задаче усмотрению и описано в BALANCE;
  награда аудиовизуальная, множителей урона/экономики не добавлено. Формат сохранений и CONTRACTS не менялись.
- DPS — ожидаемый прямой урон одной цели без промахов, с магазином/перезарядкой, чертой и текущим критом.
  Побочный урон по толпе, горение и временные боевые усиления исключены; смысл показателя есть в фокусе карты.
- `--meta-test` не может записать свои файлы в `user://`: `MetaTest._write_text`, строка 92,
  `Cannot call method 'store_string' on a null value.` Подмен путей и обходных флагов не добавлено; нужен прогон ревьюера.
- Повторный запуск указанного Python в этой сессии отклонён средой (`Access is denied`);
  продолжена уже существовавшая работа с генератором и его 17 ресурсами.
- Автоматическая проверка отклонила удаление старых `tmp/test_results/ux1_full` и `ux1_iteration`
  с причиной `blocked by policy`; эти игнорируемые временные логи оставлены. Копий проекта и фоновых циклов нет.

## Найденные проблемы вне задачи
- Среда запрещает запись `user://`; оконные запуски дают ошибку записи кэша шейдеров;
  также есть ошибка чтения системного хранилища сертификатов.
  Эти ошибки не исправлялись изменением проекта.
