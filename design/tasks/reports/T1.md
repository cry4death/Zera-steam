## Сделано
- Сначала написан [UPGRADE_TREE.md](../../UPGRADE_TREE.md): исходные 10/30/60 вылазок, примеры метапрогрессии с источниками, темп, разделение дерева/мастерской/ящиков.
- 48 узлов, шесть веток, 12 взаимоисключающих пар; в билде максимум 36 узлов / 60 очков. Первые ключи по 1 очку, поздние усиления по 2–3. При 177 ДНК первые ключи на вылазках 3/7/13/19, 12 покупок за 20 вылазок. Сброс бесплатный с подтверждением.
- Казарма показывает всю схему, соединения, предметные пиксельные значки, числа и состояния. Наведение показывает описание справа; D-pad/стик перемещает фокус геометрически, A открывает, X/R сбрасывает. Посмотрены все четыре обязательных кадра; после первой итерации обновлены стоимость и состояние среднего профиля.
- Эффекты применяются в Player/Weapons: условия стояния, дистанции и HP, первый/последний патрон, перезарядка, гранаты, лечение, контроль, одно спасение. Нет новых массовых Node или обходов орды каждый кадр. Пролом проверяет дистанцию до поражённой цели, а не курсора; Кучность влияет и на нагрев.
- v1–v5 → v6: девять прежних покупок перенесены на те же id с прежними эффектами и ценой. ДНК, её накопленный счётчик, все очки, мастерская, модели, избранное и кампания сохранены. Проверены все пять версий и настоящий `cp1_v4_fixture.json`. Допуски за 5/10 вылазок и уничтоженный улей сохраняются, не выдают повторных наград.

## Отступления от задачи и контракта
- Вне списка: одна строка `scripts/meta_test.gd:424`. Полный пресет теперь содержит «Спринт» с КД 1,6 с, поэтому вместо старого `>1.9` проверяется точное равенство реальному `dash_cooldown`. Без этого корректный эффект ломал старый тест.
- `scripts/game.gd`: помимо тестов одна строка `_result_stats` применяет ДНК-множитель дерева к рапорту до начисления и кампании; иначе «Трофеи» либо не работали бы, либо рапорт расходился бы с банком. Meta повторно не умножает награду.
- Python по указанному пути недоступен (`Отказано в доступе`), доступного Python 3.12+ не найдено. PNG создан через System.Drawing из тех же встроенных пиксельных данных `tools/gen_art_t1.py`; Python/Pillow-генератор поставлен и выдаёт те же пиксели без RNG. Сам Python-прогон здесь не проверен.
- Для CONTRACTS §12 ревьюеру: `skill_points = level−1−tree_spent()`, шесть веток графа вместо трёх цепочек; новые `reset_tree()`, `tree_spent()`, `tree_gates`; API бонусов расширен. Сам CONTRACTS вне списка не менялся.
