# Отчёт B3b — финал и Генерал

**Исполнитель:** Codex, high · **Ветка:** `task/b3b` · **Коммит:** не создавался.

**Статус:** реализация и полные проверки готовы; критерий FPS не закрыт. Своих окон и фоновой очереди нет.

## Сделано

- Реализация предыдущего прогона сохранена. В продолжении 20.10 проверены кадры и журналы,
  исправлены оставшиеся подписи глобуса, повторены импорт/boss-test, пройден оконный base-test.
- Неровное живое кольцо: переменная толщина, выступы, дыхание, вросшие остовы. Статический mesh
  из 256 треугольников; форма кромки используется и проверкой урона. Пол заменён пятнами, слизью,
  кровью и капиллярами без регулярной сетки трещин. Сжатие и фазы сохранены.
- Концовка использует ZeraStyle, Russo One/Fira Sans Condensed, сталь/брезент, маркировку победы,
  пять итогов войны, затихание органа и очищение существующего 3D-глобуса. Главное действие «На базу».
- Подпись глобуса и цель карточки соответствуют выбранному улью; после Объекта-7 открыт путь к Сердцу.
  При продолжении исправлены также реально видимая верхняя подпись `globe_view.gd` и нижняя веха операций.
- Генерал: снимаемые каска/нагрудник/наплечники/направленный щит, AP модели/модуля/дистанции,
  физические детали и рикошеты Z2. Миномёт с фиксированными отметками, щитовой рывок, приказ
  подкрепления из военных Z2 через общий пул орды. Три фазы, HP/броня/интервалы описаны в BALANCE.
- Генерал обнаруживается на третьем ходу, доступен по квоте B2, необязателен для финала;
  добавочное давление 0. Пока O3 отсутствует, используется укреплённый карантинный пост.

## Отступления от задачи и контракта

- `scripts/weapons.gd` вне списка: девять добавленных строк передают AP оружия в существующий
  путь урона босса. Иначе нельзя обеспечить требуемое действие пробивающих стволов на Генерала.
  Общий трёхпараметровый API остальных боссов сохранён.
  Для CONTRACTS: `BossGeneral.take_armored_damage(amount, dir, at, penetration, explosive) -> bool`;
  стандартный `take_damage` остаётся совместимым. Сброшенные детали идут через `Horde.armor_detached`.
- `scripts/meta_test.gd` вне списка: одна константа 91 → 92; устаревшее ожидание уже в HEAD.
- Генератор `.js`, поскольку указанный Python 3.12 возвращает `Access is denied`; Node без пакетов,
  как в Z2. Генератор создаёт восемь текстур, без правок чужого арта.
- Отдельные PNG «до» скопированы из принятых B3: чистый worktree содержал именно эту версию.
- Автоматическая проверка отклонила удаление пустой оставшейся общей блокировки (`blocked by policy`).
  Обход не выполнялся; штатный скрипт продолжает обслуживать очередь.
- При продолжении автоматическая проверка также отклонила рекурсивную уборку (`blocked by policy`).
  Остались `design/tasks/reports/b3b_baseline/` (включая junction art/music/sfx) и `b3b_runtime/`;
  в сдаваемые ресурсы не входят. Обход запрета не выполнялся. Отдельные журналы и дублирующий
  `b3b_arena.png` удалены; своих процессов Godot/ожиданий нет.
