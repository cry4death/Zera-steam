# S6 — экран базы: казарма, мастерская, арсенал, склад ящиков

**Исполнитель:** Sonnet · **Уровень:** high · **Ветка:** `task/s6` (от main после S5)
**Контракты:** `CONTRACTS.md` §11–13. **Дизайн:** `MVP.md` §10, `GDD.md` §12.1, §13, `BALANCE.md` §11.
Стиль UI — как `level_up.gd`, `trader_ui.gd`, `run_results.gd` (рисуется в «игровых пикселях», шрифт
проекта, тёмные карточки, акценты редкости: обычная — белый, редкая — синий, прототип — оранжевый).

## Цель

Между забегами есть дом: видно, сколько ДНК, куда её потратить, что выпало из ящиков, с чем идти в бой.

## Сделать

1. **`scenes/base.tscn` + `scripts/base.gd`** — главная сцена (`run/main_scene`), поток по §13
   (тест-флаги сразу переходят в `main.tscn`). Фон — тёмная «казарма» (асфальт/бетон, приглушённый
   свет, следы крови — можно переиспользовать арт проекта), сверху: ДНК, уровень класса и полоса до
   следующего, очки навыков, ящики.
2. **Вкладки** (клавиши 1–4, клик, геймпад): 
   - **Казарма** — дерево 3 ветки × 3 узла: открыт / доступен / закрыт, стоимость 1 очко, описание,
     подтверждение. Узлы по порядку.
   - **Мастерская** — список моделей (только открытые), 4 стата × 5 уровней полосками, цена следующего
     уровня, покупка; превью «было → станет» для ключевых цифр (урон, темп, магазин, перезарядка).
   - **Арсенал** — 8 категорий: серийная и модель из ящика (закрытая — силуэт «???» и «из ящика»),
     черта модели, выбор избранной (★). Здесь же — эфф. DPS L1 для сравнения.
   - **Склад** — ящики: обычные и военные, кнопка «ВСКРЫТЬ»: анимация (ящик трясётся 0.8 с → крышка
     отлетает → вспышка цвета редкости → карточка результата: новая модель / ДНК / дубликат → ДНК).
     «Вскрыть все» — по очереди, можно пропускать анимацию.
3. **«В БОЙ»** — крупная кнопка (Enter/Space), переход в `main.tscn` с выбранными моделями.
   Экран итогов: «НА БАЗУ» (основная) и «ЕЩЁ РАЗ» (`run_results.gd` — две кнопки, сигнал `base_requested`).
4. Звук: щелчки интерфейса — переиспользуй механику (`weapons/pistol/dry`, `.../mag_in`), вскрытие —
   `casings/mag_drop` + `explosions/grenade` тихо; новых файлов не делать. Музыки нет.
5. **`--base-test`**: базовые сценарии с временным сохранением — купить узел, апгрейд, вскрыть ящики,
   выбрать избранную, перейти в бой и обратно; скриншоты всех 4 вкладок, середины анимации ящика,
   карточки редкой модели (`_barracks.png`, `_workshop.png`, `_arsenal.png`, `_crates.png`, `_crate_open.png`,
   `_crate_rare.png`). Посмотри сам — читаемо, не налезает, в стиле игры.

## Можно трогать

`scenes/base.tscn`, `scripts/base.gd` (новые), `project.godot` (main_scene), `scripts/run_results.gd`
(кнопки), `scripts/game.gd` (переход на базу), арт фона базы через новый `tools/gen_art_m6.py` → `art/base_*`
(если нужен), отчёт и `design/tasks/reports/s6_*`.
