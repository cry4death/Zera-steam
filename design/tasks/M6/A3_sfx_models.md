# A3 — звуки моделей из ящиков

**Исполнитель:** Sonnet · **Уровень:** medium · **Ветка:** `task/a3` (от main после W2)
**Контракт:** `CONTRACTS.md` §9 (формат, уровни), §11 (таблица моделей, колонка `gun`).

## Цель

У каждой модели из ящика — свой настоящий голос из той же CC0-библиотеки (Still North Media),
чтобы новая пушка звучала иначе, чем серийная.

## Сделать

Новый раздел `models()` в `tools/prep_sfx.py` (общие функции A1/A2 переиспользуй, остальные
разделы — не трогать, их файлы байт-в-байт). Для каждого `gun`:

| gun | Prepared (выстрел, near) | Raw-механика (опись `master_sheet.xlsx`) |
|---|---|---|
| `m4` | `AR-15/D_32P` | `D_*`: mag_out (detach), mag_in (insert loaded), rack (drop bolt / full rack), dry |
| `shkval` | `Model 12/K_22P` | `K_*`: rack (full cycle loaded, ≤ 0.4 с), shell_in (insert round / load mag), dry |
| `guard` | `Walther PPQ/X_39P` | `X_*`: mag_out, mag_in, rack (slide release), dry |
| `cowboy` | `Ruger Single Six/S_14P` | `S_*`: подбери по описи: открыть дверцу/выбить гильзу/зарядить → `cyl_open`, `eject`, `load`, `cyl_close`, `dry` (+ взвод курка, если есть — `hammer`) |
| `osa` | `Carl Gustav M45/G_31P` | `G_*`: mag_out, mag_in, rack, dry |
| `winchester` | `Marlin 336/I_22P` | `I_*`: rack (рычаг вниз-вверх, ≤ 0.45 с), shell_in, dry |
| `spear` | синтез: рельса A1 ниже и тяжелее (питч ~0.8, длиннее хвост) + низкий «удар» | — |
| `hive` | синтез: «Гром» A1 + мокрый «чпок» (прилипание), отдельно `weapons/hive/stick_*` | — |

- Выстрелы: 3–4 варианта, хвост по контракту §9 (автоматические — коротко, как у АК/ППШ),
  уровни по ощущению калибра (впиши в таблицу уровней скрипта).
- Механика: 2–3 варианта, ФВЧ как у W2, уровни −12 дБ к выстрелу. Архив не распаковывай целиком
  (на диске мало места) — только нужные дорожки во временную папку, потом удалить.
- `sfx/CREDITS.md` — дополнить. Метрики и `design/tasks/reports/a3_waveforms.png` — посмотреть самому.

## Проверка

```
python tools/prep_sfx.py               (затем --out <tmp> — побайтово то же)
сравнить хэши всех прежних sfx/*.wav с main — без изменений
godot --headless --path . --import
```

## Можно трогать

`tools/prep_sfx.py` (новый раздел и его вызов), `sfx/weapons/<новые gun>/**`, `sfx/CREDITS.md`,
`sfx/manifest.json`, отчёт `design/tasks/reports/A3.md` и `a3_*`.
