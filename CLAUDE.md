# CLAUDE.md — Opus в проекте Zera

- Правила проекта и исполнителя — `AGENTS.md` (единый источник; Codex читает его же). Процесс задач и роли —
  `design/tasks/README.md`, доска — `design/tasks/BOARD.md`, стыки — `design/tasks/CONTRACTS.md`.
- Проверки, GdUnit4 и Godot Editor MCP — `design/tasks/TOOLING.md`.
- Opus пишет задачи, проверяет и сливает ветки `task/<id>`; код задач делает Codex в своём worktree.
- Приёмка задачи: дифф `git diff main...task/<id>`, `tools/test_project.ps1 -Suite full` в worktree задачи
  (строка `ZERA_TEST … failed=0`), `-Suite bench` если задача трогает производительность, скриншоты.
- Визуальный плейтест в окне (через блокировку Godot) — когда задача меняет видимое в игре: арт, UI, эффекты,
  читаемость боя, ощущение оружия. Логику без визуала проверяют тесты.
- Godot Editor MCP — только у Opus. Нужен, чтобы увидеть сцену и узлы в живом редакторе или коротко
  проиграть сцену; для чтения кода, правок и проверок сдачи — файлы и CLI. Редактор открывать скриптом
  `tools/godot_editor.ps1` (берёт общую блокировку) и закрывать сразу после работы.
